# 보고서가 모이는 하나의 작업 기록실

결과를 읽기 쉽게 제출하고, 이전의 판단과 근거까지 다시 찾을 수 있도록 보고서 관리 구조를 만들었습니다.

## 이번에 달라진 점
- 최종 보고서는 디자인된 HTML로 제출하도록 전역 지침을 추가했습니다.
- 모든 보고서와 사이트 파일은 리포트 폴더에 모았습니다.
- 게시물은 Markdown 원본으로 작성하고 같은 이름의 HTML을 생성합니다.
- 메인 화면에서 분류와 검색으로 보고서를 찾을 수 있습니다.
- 기존 버전을 지우지 않고 새 파일로 기록을 추가합니다.

## 파일 구성
```
리포트/
  index.html
  build.mjs
  assets/
  posts/날짜-작업명-v1.0.0.md

```

## 검증과 상태
- 이 문서는 최초 구현 기록입니다. 최종 실행 검증과 동기화 결과는 별도의 완료 보고서에 기록합니다.
- 인터넷 공개 배포는 수행하지 않았으며 로컬 HTML 파일로 사용할 수 있습니다.
- 원격 글꼴을 불러오지 못하면 시스템 글꼴로 표시됩니다.
