# TurnRoom release catalog

This HTTPS JSON catalog contains confirmed public release versions only. An empty products array means no version has been confirmed here, not that installed products are current.

Schema: `schemaVersion: 1`, `products: [{ id, version, downloadUrl? }]`. IDs: templete, designdatatable, pixora, pixelcamera, entityforge. Versions use SemVer including optional prerelease/build identifiers; links must be HTTPS. Add an entry only after checking the actual public release. A candidate, pending store submission or local package is not proof of a public release.
