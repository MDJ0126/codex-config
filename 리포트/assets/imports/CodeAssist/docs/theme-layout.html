테마·레이아웃 통합 변경 — 0.0.77

실제 VA의 Find Symbol 화면과 제공된 Options·Welcome 화면을 기준으로 변경했습니다. 전체 VA 화면이 완전히 동일하다는 완료 보고는 아닙니다.

  • Welcome의 고정 다크 색상을 제거하고 VS 테마에 반응하는 배경·카드·본문·보조 글자·브랜드 색상을 연결했습니다.
  • 공통 버튼과 목록·헤더·선택 행을 다크·라이트에 맞게 처리했습니다. 테마 변경 시 열린 뷰도 갱신됩니다.
  • 탐색 창을886×396 기본 크기, 위쪽 검색·필터, 중앙 심볼/정의2열, 아래 이동·참조·취소 구성으로 변경했습니다.
  • 솔루션만·퍼지 검색·클래스 필터를 실제 검색에 연결하고 종류 아이콘을 표시합니다.
  • Options 기본 크기890×676, 사이드바 간격, 편집 옵션 순서와 세로 간격을 조정했습니다. 기존 옵션을 재배치했으며 미구현 옵션을 구현했다고 표시하지 않습니다.
  • 다크 심볼 기본값: 타입#FFD700, 함수#FF8000, 변수#BDB76B, 매크로#BD63C5. 라이트 색상은 대비를 위한 자체 선택이며 VA 공장 초기값과 동일하다고 인증하지 않았습니다.

검증

통합 빌드·VSIX 검사, 회귀247개, 두 테마6개 뷰 렌더와 각 뷰의 테마 전환 검사를 통과했습니다. 실제 실험 IDE에서 새 열·필터·오버로드 검색·이동을 확인했습니다. 클래스 필터18→4, Axr 퍼지 검색0→1, 이동 버튼으로 FixtureActor.cpp15행을 확인했습니다. 마지막 RGB·PNG 조정 전의 실행 캡처와 최종 빌드의 렌더·설치 해시를 구분해 원자료에 기록했습니다.

비교용 Exp 프로필에0.0.77을 배포했습니다. 일반 프로필은 VA 대조를 위해 이전처럼 VA 활성·CodeAssist 비활성입니다. 로드 중 제거된 이전 폴더를 참조하던 오류는 UpdateConfiguration 후 실제 재실행으로 해소를 확인했습니다.
