One API. Three ways to use it.

Use MCP, JSON CLI or the dependency-free Python client. Each adapter calls the same Unity editor engine; it does not automate the desktop or duplicate spreadsheet parsing.

Connect once

python Assets/DesignDataTable/Integrations/AI/ddt_cli.py --ai-info --pretty
python Assets/DesignDataTable/Integrations/AI/ddt_cli.py --project C:/Projects/MyGame --mcp-config --pretty

Copy the returned mcpServers object into your MCP client's documented configuration. The command only prints configuration. Restart/reconnect that client to discover tools. A portable local plugin and skill are in Integrations/AI; use Python 3.10+ and an explicit project path or DDT_PROJECT for a cached plugin.

Clients discover tools/list, tool schemas and startup instructions. An AI without this server or project instructions cannot be forced to discover them.

MCP tools

ToolPurpose
ddt_helpDiscover the supported engine operations, all batch actions, limits and required workflow. No running Unity needed.
ddt_search_tablesFind original workbook paths and sheets by table name. Global Enum providers return sourceGuid. Default 20 results; includeWorkbooks scans at most 200 other project workbooks.
ddt_inspectRead saved worksheet names, registered column names/types/descriptions and local/global Enum choices. Supply path or a registered game table. Never reads an open unsaved draft.
ddt_read_tableRead game records by literal Int32 Id and exact field names. Default 20 rows; specify fields and pagination to reduce output.
ddt_read_rangeRead a bounded A1 range as input and calculated-display matrices. Protected hidden formulas are omitted. Maximum 10000 cells.
ddt_batchValidate up to 100 edits in ONE workbook before committing once. Read expectedRevision first; preview a dryRun, then commit. Table actions use recordId and values. Schema actions use name/type/description. enum.set retains existing omitted numbers. Any failure rejects the batch. preview returns a native image of range.
ddt_renderRender a saved A1 range with the editor cell/shape/chart painters; returns a PNG without activating a document window. Maximum 2000 cells and 4096 pixels per side. Requires graphics-enabled Unity.
ddt_request_statusCheck a timed-out request before retrying a mutation. Does not re-enqueue and works when Unity is closed.

A small, safe workflow

  1. Search the table name, then inspect schema and revision.
  2. Read only needed records or ranges.
  3. Run a dry-run batch, inspect diagnostics and its image.
  4. Commit the same actions with dryRun:false and unchanged expectedRevision.
  5. Read back. On timeout, inspect request status before retrying.

Limits that matter

Unity must be open, idle and outside Play Mode. Saved project-contained XLSX/CSV files are supported; an unsaved human editor draft blocks mutations. CSV supports cell operations, not XLSX formatting. Formula Ids cannot use Id addressing. Each atomic batch edits one workbook. Shared Enum changes also validate dependent registered tables.

Read results are paginated. Schema responses cap columns and Enum definitions; check truncated. Requests are at most 1 MiB. Native preview requires a graphics-enabled editor. Formatting and objects follow the editor's supported subset, not complete Excel compatibility.

Requests, responses and images are local under Library/DesignDataTable/Automation and may contain cell values. They are not sent to a service by this integration. MCP clients decide how returned content is used. Official Python MCP SDK 2.3.0 interoperability was exercised on Windows with protocol 2025-11-25; other clients/platforms remain unverified.

Legacy inspect/schema/read/dry-run/write/validate-game operations and the Scripts/Editor/ddt_cli.py entry point remain available. A timeout now requests cancellation of work that has not committed; inspect its retained status because an already-running commit may finish.
