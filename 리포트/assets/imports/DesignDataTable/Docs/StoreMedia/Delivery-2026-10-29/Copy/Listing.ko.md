# Design Data Table – Spreadsheet & Game Data Editor

Unity 안에서 스프레드시트를 편집하고 게임 데이터와 로컬라이징으로 연결합니다. 2D·3D 게임 예제 24개를 제공합니다.

## 주요 기능

- MCP·CLI·Python으로 테이블 검색, Id·범위 편집, 스키마·Enum 관리, 배치 검증과 실제 엔진 PNG 미리보기를 사용할 수 있습니다.

| 기능 | 설명 |
| --- | --- |
| 스프레드시트 | XLSX·CSV 편집, 서식·필터·지원 수식·차트·도형 |
| 게임 데이터 | 시트 등록 후 C# 테이블과 바이너리 데이터 생성 |
| Summary | 컬럼 이름·타입·설명을 원본과 양방향 동기화 |
| Enum | 로컬·글로벌 정의, 값 선택 팝업, 잘못된 값 경고 |
| 로컬라이징 | enum 기반 GetString으로 언어별 문자열 조회 |
| 게임 예제 | 독립된 2D 12개·3D 12개 씬, 데이터 파일 버튼, 선택형 자동 플레이 |
| AI 연동 | MCP·CLI·Python 공통 API, 검증 후 저장, 이미지 확인 |
| 코드 안내 | 예제 XML 설명, 인식 가능한 소스 주석의 언어 갱신 |
| 오프라인 문서 | 9개 언어, 일반 엑셀·게임 데이터 두 탭 구성 |

## 게임 데이터로 사용하기

1. Assets 안에 XLSX 파일을 만들거나 엽니다.
2. Game Data → Use as Game Data Table을 선택합니다.
3. 컬럼 이름과 타입을 확인하고 시트를 등록합니다.
4. 저장한 뒤 생성된 C# 테이블을 사용합니다.

## 지원 범위

- 검증 환경: Windows, Unity 6000.0.83f1. 예제는 Built-in Render Pipeline을 사용합니다.
- 의존성: Unity UI(uGUI), 스프라이트 예제용 2D Sprite 패키지.
- AI 기능: Python 3.10+와 열린 Unity 편집기가 필요하며 Play 밖에서 작동합니다. MCP 클라이언트 연결은 별도로 설정합니다.
- Excel 전체 호환을 의미하지 않습니다. 미지원 기능은 편집·표시하지 못할 수 있습니다.
- 외부 파일은 열 수 있지만 등록은 Assets 내부 원본에 한합니다.
- 게임 데이터·로컬라이징·로컬/글로벌 Enum 파일은 Play 중 읽기 전용입니다.
- 예제는 데이터 활용 학습용이며 완성된 상용 게임이 아닙니다.
- 다른 Unity 버전·운영체제·렌더 파이프라인·빌드 백엔드는 별도 검증이 필요합니다.

## 라이선스·제작 안내

코드·문서·번역·일부 예제 시각 에셋 제작에 AI 보조를 사용했습니다. 외부 에셋과 글꼴의 라이선스는 Third-Party Notices.txt 및 동봉 파일을 따릅니다. Inter·Pretendard는 수정 없이 SIL OFL 1.1로 포함했습니다.

영문 원고의 내부 검토용 번역입니다. 포털 입력 기준은 ListingSource.json이며 2.0.2는 아직 업로드·제출하지 않았습니다.
