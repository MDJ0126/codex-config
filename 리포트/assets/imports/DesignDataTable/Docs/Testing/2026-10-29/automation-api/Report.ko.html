발견 후 수정한 문제

문제수정·재검증
같은 값을 재전송해도 저장 처리세션의 실제 변경 여부를 비교합니다. no-op의 파일 리비전 유지와 committed:false 확인.
헤더 채우기와 글자 대비 누락ARGB 색상 해석·영역 클리핑 수정. 실제 Unity PNG와 문서 화면 확인.
잘못된 MCP 도구 이름·취소 Id가 서버를 중단시킬 가능성입력 타입 검사. 손상 요청 후 정상 도움말·ping 응답 확인.
네이티브 미리보기 임시 EditorWindow 해제 누락Container·Host·EditorWindow를 각각 해제합니다. 수정 전 30회에 창 30개 잔류 → 수정 후 60회에 0개. RenderTexture는 30·60회 모두 16개로 추가 증가 없음.
시험 코드가 취소 결과를 0.8초만 기다림실제 결과 파일을 최대 15초까지 확인하도록 시험 대기를 수정했습니다. 만료된 요청이 뒤늦게 저장되지 않고 request-expired로 끝난 것을 확인.

실제 결과 이미지

영문 Unity 6000.0.83f1의 범위 전용 엔진 출력입니다. 전체 스프레드시트 창 캡처가 아닙니다. 다른 UI 언어의 레이아웃을 검증한 것으로 간주하지 않습니다.

사용 방법·제한

MCP·CLI·Python 참조 · 전체 도구·작업 목록 · MCP 실행 근거 · 60회 자원 검사 · 반복 호출 시간 · 9개 언어 문서 검사

Unity가 열려 있고 Play 밖이어야 합니다. 한 배치는 한 워크북에 한정됩니다. 미저장 사용자 초안이 있으면 편집을 거부합니다. 타임아웃 후에는 요청 Id 상태를 먼저 확인합니다. 이미 진행 중인 커밋은 완료될 수 있습니다. 이미지·서식은 현재 편집기의 지원 범위를 따릅니다.

MCP 클라이언트 설정을 자동 설치하지 않았습니다. --mcp-config로 출력한 설정을 연결하면 도구 목록을 발견할 수 있습니다. 연결하지 않은 모든 AI에 강제 적용할 방법은 없습니다. 다른 MCP 클라이언트 및 macOS/Linux 실행은 미확인입니다.
