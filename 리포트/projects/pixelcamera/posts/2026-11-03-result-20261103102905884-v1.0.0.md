## 작업 결과

부드러운 톤을 목표로 셰이더·프리셋·세 예제 소스를 변경했습니다. 실제 화면이 목표 품질에 도달했다고 확인한 상태는 아닙니다. 픽셀 격자와 점 필터는 유지하며 블러를 추가하지 않았습니다.

## 변경 내용

### 적용 내용

|변경|적용|
|---|---|
|툰 명암|Light transition softness .8, diffuse wrap .15,5단계.0 soft/0 wrap이면 기존 hard band 계산 사용|
|그림자|툰 기본 tint를(.48,.56,.64)로 변경|
|예제 시작|전체 불투명 메시를 private soft Toon으로 비교. V로 저장된 원본 재질 복원. 투명/cutout 보존|
|픽셀·외곽선|기본4/8→2/4px, 색상 외곽선 alpha .42, O on/off 유지|
|장면|3테마 주변광·배경을 밝히고 재질 색·금속·광택 대비 완화|
|프리셋·문서|9프리셋의 팔레트 .28·색단계256·기본 디더OFF.9언어 soft-tone 안내 추가|

예제 재생성 도구도 같은 픽셀/외곽선/주변광 기본값으로 맞췄습니다. 기존 씬·오브젝트 ID·형상·애니메이션·버튼 이벤트는 보존했습니다.

## 검증

현재 소스6어셈블리 정적 컴파일 통과.18셰이더 항목 중17FXC 통과; 기존 vendor instancing 매크로 실패1개는 동일 input SHA로 실제 Unity DXC 정적 컴파일 통과. 실패 로그 보존.3씬을 허용된 설정 줄을 제외하고 변경 전과 완전히 대조해 ID·형상·애니메이션 연결 보존 확인.3UI프리팹은 정적 문구만 변경하고 이벤트 동일.9프리셋 값 검사.528528점 CPU 명암 수학 참조의 유한성/범위/단조성 검사. 이는 실제 GPU 이미지 평가가 아닙니다.
