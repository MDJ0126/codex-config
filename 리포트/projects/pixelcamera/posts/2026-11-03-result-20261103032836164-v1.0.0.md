## 작업 결과

기능 종류는 상당 부분 갖췄으나 ProPixelizer와 동급의 렌더링 완성도·제품 검증 수준이라고 판단할 근거는 없습니다. 기능명 개수에 임의 가중치를 부여한 개발률 백분율은 제시하지 않습니다.

|기능군|Pixel Camera 현재 상태|
|---|---|
|전체/선택 물체 픽셀화|구현, 최신 native 렌더 검증 미완료|
|물체별 픽셀 크기·외곽선|구현: 화면/월드/비율과 색·두께·on/off|
|팔레트·디더 저작|추출·RGB/HSV·LUT·2/4/8/custom 구현, preset 기반. 물체별 재질 통합은 ProPixelizer와 다름|
|단계 애니메이션|클립 복사 베이크·수동 Animator clock 구현, native 상태/루트모션 QA 미완료|
|움직임 안정화|루트 스냅·회전 단계·원근 앵커·잔여 이동 재투영. 교차/재노출/뼈 안정화 한계|

|툰·조명·edge bevel|기본 툰·ramp·림·방향성 화면 외곽선. 경쟁사 normal 기반 bevel·광범위 표면 입력과 다름|
|투명 물체 합성·후처리 호환|현재 미지원/미검증 범위|
|호환성과 성능|Built-in/URP17 구현, 최신 fresh import/native 플랫폼 성능 인증 없음|

## 변경 내용

### 적용 내용

이번 회차는 비교 검토이며 제품 코드·씬·설정은 수정하지 않았습니다. 우선순위는1.Pixel Expansion/교차 안정화2.투명 합성·후처리3.Graph SubTarget4.실제 설치·렌더·성능 회귀입니다.

## 검증

공식[개요](https://propixelizer.github.io/docs/usage/overview/)·[Pixel Expansion](https://propixelizer.github.io/docs/usage/pixelization/)·[ShaderGraph](https://propixelizer.github.io/docs/usage/shadergraph/)·[Uber shader](https://propixelizer.github.io/docs/technical/ubershader/)를 현재 조회했습니다. 현재 README,PixelCameraObject,ObjectFrame,Toon.shader,ShaderGraph 가이드와 SubmissionStatus를 대조했습니다.11월1일 기록은6source/7customer assemblies·24187알고리즘 assertion·31shader 항목의 당시 정적 검사이며, 이번에 재실행하거나 최신 native 통과로 취급하지 않았습니다.

## 남은 사항

동일 씬·카메라·모델에서 두 제품을 실행한 화질/FPS 비교는 미실행입니다. 경쟁사 설명은 공식 기능 문서 기준이며 경쟁사 내부 소스 검토가 아닙니다. 현재 소스 검토 작업이므로 실제 실행 화면을 새로 만들거나 과거 화면으로 대체하지 않았습니다. 제출 후보의 submissionReady=false이며 최신 소스와 후보의 최종 대조가 필요합니다. 교훈 검토: 기능 존재와 동등성·실행검증을 분리하는 기존 지침으로 충족, 전역 변경 없음.
