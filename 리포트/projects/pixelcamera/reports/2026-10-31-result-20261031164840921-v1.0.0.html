TurnRoom 안에 Tidewatch Outpost 맵 샘플 2개 추가

검증 대기

기존 단순 기능 씬을 맵 샘플과 구분하고, 실제 TurnRoom Assets에 항구·도로·건물·모델이 있는 맵 씬 2개를 저장했습니다. 실행 검증은 보류입니다.

2026년 11월 1일 오전 1:48 KSTv1.0.0수정사항

작업 결과

C:/Projects/TurnRoom/Assets/TurnRoom/PixelCamera/Samples/Scenes에 11-TidewatchOutpost.unity와 12-OutpostStreet.unity를 직접 작성했습니다. 앞서 만든 01~10 씬은 모델과 도형을 배치한 작은 기능 테스트 씬이며 맵 샘플이 아니었습니다. 이전 보고에서 이를 충분히 구분하지 않은 점을 정정합니다. 새 맵은 파일·정적·컴파일 검사까지 완료했고 Unity 임포트·실행은 미실행입니다.

변경 내용

적용 내용

  • 동일한 항구 전초기지를 전체 조망 카메라와 거리 카메라로 볼 수 있는 씬 2개를 추가했습니다. 각 씬에 메시 오브젝트 126개와 Pixora 모델 프리팹 인스턴스 6개를 저장했습니다.
  • 항구·방파제·부두, 두 도로와 광장, 창문 개구부가 있는 건물 3채, 전망탑, 화물, 가로등, 식재를 구성했습니다.
  • ClockworkKingfisher, CourierDrone, SurveyorKit, TidewatchObservatory를 사용했습니다.
  • 맵용 프리셋 3개와 WASD/방향키·높이·우클릭 시점·프리셋 선택·효과 우회·초기화 샘플 컨트롤을 추가했습니다. 커서 잠금과 앱 포커스 제어 코드는 넣지 않았습니다.
  • Unity가 새 파일을 임포트하면 TurnRoom > Pixel Camera > Samples에서 맵 씬을 열 수 있도록 메뉴를 추가했습니다. 자동으로 씬이나 창을 여는 시작 코드는 없습니다.
  • 맵 전용 안내를 9개 언어로 추가했습니다. 기존 사용자 씬과 EditorBuildSettings는 수정하지 않았습니다.

검증

  • 씬 정적 검사 JSON: 씬당 직렬화 레코드 649개, 로컬 fileID 연결, 외부 GUID 23개, 단위 회전, 양수 크기, 프리팹 참조 및 해시 검사 통과.
  • 컴파일 기록: 설치된 Unity 6000.0.83f1 어셈블리를 참조하여 신규 컨트롤·메뉴와 기존 카메라 런타임 소스를 .NET 컴파일러로 검사했습니다. 오류 0개·경고 0개입니다. Unity 에디터의 임포트·컴파일 실행과는 구분합니다.
  • 9개 맵 가이드의 언어·씬 링크 검사 통과. 새 맵의 렌더·이동 입력·프리셋 전환은 테스트하지 않았습니다.
  • 자동 갱신 관련 저장 설정을 읽었을 때 kAutoRefreshMode=1이었습니다. Unity 6.0 공식 소스는 Enabled=1로 정의합니다. 저장 설정은 켜짐이며, 현재 에디터 반영 지연의 정확한 원인은 미확인입니다.
  • 화면 포커스를 가져가지 말라는 지시를 지켜 Unity·플레이어·디자인 앱을 실행하거나 화면을 조작하지 않았습니다. 따라서 새 맵의 실제 화면 캡처는 없습니다. 이전 테스트 씬 이미지를 새 맵 검증 이미지로 재사용하지 않았습니다.

남은 사항

  • 새 맵의 Unity 임포트·실제 렌더링·네이티브 조작·스크린샷은 미검증입니다. 기존 54개 검사와 과거 게임 뷰 화면은 새 맵 검증 근거가 아닙니다.
  • 기존 0.1.0-preview.unitypackage는 새 맵 추가 전 버전입니다. 새 맵은 실제 TurnRoom Assets 폴더에 직접 추가했으며 Unity 패키지 재내보내기는 실행하지 않았습니다.
  • 교훈 검토: 전역 지침 변경 없음. 기존 완료 범위·검증 구분 원칙을 적용하고, 단순 테스트 씬과 맵 샘플의 차이 및 실제 제작·검증 위치는 이 프로젝트 보고서에 기록했습니다.

작업 시간

  • 제안 시간: 15~25분, 2026-11-01 01:37:08 KST 시작.
  • 실제로 완료된 시간: 맵 파일·정적·컴파일 검사 기준 2026-11-01 01:48:00 KST, 10분 52초. 공개 보고서 배포 진행 중. 새 맵의 전체 완료 시각은 미정(임포트·실행 검증 보류).
  • XERJ: 미사용 — 알려진 씬·프리팹·설정·소스 파일을 직접 읽어 새 맵을 작성했으며 심볼 검색은 불필요했습니다.
