작업 결과

남은 주요 기능을 기존 제품 구조에 추가하고 소스/고객 후보 컴파일과 실제 공유 알고리즘 실행, 셰이더·에셋·문서·포장 검사를 마쳤습니다. 업로드 가능한 최종 제출 준비 완료 상태는 아닙니다. 사용자의 포커스 금지와 가격 보류를 지켜 native 실행·미디어·판매자 게이트를 남겼습니다.

변경 내용

적용 내용

기존 Runtime/Editor/Integrations/Samples/Documentation 구조를 재사용하고 기존 FullCamera enum0 기본값을 유지했습니다. Full Camera shader의 최소 요구를3.5로 명시했으며 Selected Objects와Toon은4.5입니다. 현재 지원 확인 환경/호환 한계를 listing에 구분했습니다. URP Toon SubShader의 첫 선언에 PackageRequirements17.x를 넣어 패키지 없는 Built-in 프로젝트에서는 해당 서브셰이더를 제외하고 fallback을 사용할 수 있도록 작성했습니다. 이 ShaderLab import 자체의 native 검증은 남아 있습니다.

원본 재질과 프리셋의 저장 에셋을 보존하는 private toon/material/preset 비교를 추가했습니다. 배치·스타일·정적 문구·버튼 연결은 각 테마의 편집 가능한 ShowcaseGuide.prefab에 저장했고 런타임 UI 생성은 없습니다. 기존13개 및 추가1개(천문대 투시) 이벤트의 참조를 정적으로 확인했습니다. 현재 스크린샷을 새로 찍지 않고 과거 캡처/소스 해시는 보존했으며 모든 번역 가이드에 미촬영 상태를 표시했습니다.

source0.6.0-preview, submission candidate1.0.0을 갱신했습니다.611에셋 unitypackage와 실제 현재 검증 JSON·listing·AI disclosure·SUBMISSION-GATES.md를 포함한 ZIP을 작성했습니다. 과거 스크린샷·키이미지·예전 검증 인증서는 새 ZIP에서 제외했습니다. 실제 Asset Store 업로드/심사 제출은 하지 않았습니다.

검증

전체 준비 검사 — source6개 C#어셈블리와 고객 패키지/공통 템플릿7개 컴파일 exitCode0, 현재 소스 해시 대조. 원본 소스 컴파일도 별도 보존합니다. 기존 Unity compiler response/reference를 사용한 정적 검사이며 깨끗한 프로젝트 설치 검사는 아닙니다.

공유 순수 C# 알고리즘 실행:24,187개 assertion 통과. RGB/HSV seam·입력 불변·알파 제외·결정적 추출·Bayer 순위/평균·LUT 팔레트 인덱스·어두운 선형값 보존·시간표/할당한도·화면/월드/비율/줌·셀 중심·잔여 오차와 실제 공유 TemplatePickerPolicy를 검사했습니다. Native Unity API를 실행한 증거는 아닙니다.

합성/전체 카메라13개 엔트리, 툰/Graph18개 중17개는 FXC 경로로 정적 컴파일했습니다. 하나의 vendor instancing macro는 표준 전처리와 맞지 않아 실패 기록을 유지했고 Unity-bundled DXC legacy expansion으로 동일 입력을 컴파일했습니다. 총31개 엔트리를 두 경로로 커버했습니다. 초기 parameterless macro 실패도 남겼습니다. 실패를 숨기거나 모든 FXC가 성공했다고 쓰지 않습니다. DXC의 unsigned-DXIL 경고는 테스트 결과에 그대로 있으며, 테스트 bytecode/DXIL은 고객 파일에 넣지 않았습니다.

Native 직렬화 파일 검사:4/8px·시작회전·overlay·CanvasRenderer·13/13/14개 이벤트 대상/메서드·내부fileID 통과. 추가로 고객 GUID참조946개와 문서 로컬 링크1134개,9언어 저작 페이지를 확인했습니다. 실제 native import/레이아웃/클릭 검증은 아닙니다.

611개 asset/meta 전체 바이트 대조: GUID중복·개발파일·old FBX 제외,3씬·3clip·9chapter preset+3palette와 새기능/9저작 가이드 포함, 최대 경로97자. Unitypackage SHA-256 1f9baa4218778159ab1813eeee7be9bfda173095cc842b20ebb885bdaace80de. 현재 후보 ZIP CRC/바이트 대조도 통과했습니다. 새 설치/Asset Store Tools 현재 버전 검증을 대신하지 않습니다.

실제 화면 캡처 미실행: 사용자의 컴퓨터 조작 중지 요청 때문에 새 렌더·에디터/Graph/애니메이션/팔레트 화면을 촬영하지 않았습니다. 과거 이미지나 가짜 화면을 새 기능의 검증처럼 첨부하지 않았습니다.

Affinity 전용 CLI 문서를 읽고 doctor/status를 조회했습니다. 기본 샌드박스 EACCES 후 허용된 loopback 조회만 재시도해 ECONNREFUSED를 확인했습니다. 현재 서버/버전/문서 연결은 확인되지 않았고 앱을 켜거나 설정·포커스를 바꾸지 않았습니다. 이는 예술 이미지 작업을 다른 도구로 대체한 것이 아닙니다. LUT는 shader colour-data 기능이며 실제 2D아트는 제작하지 않았습니다.

공식 계약 대조: Unity6 PackageRequirements, Graph17.0.4 Custom Function, Unity6 Texture3D 구현, Microsoft DXC API를 대조했습니다.

교훈 검토: tool 전처리 오류와 실제 shader 결함을 최소 재현·다른 실제 compiler로 분리했고, LUT의 선형 팔레트 출력은float32 data로 보존했습니다. 세부 사실은 해당 프로젝트 QA에 남겼으며 전역의 근거·미확인/헤드리스·포커스 규칙으로 이미 포괄되어 전역 지침 추가·통합 변경 없음.
