## 작업 결과

이전에 실제로 발생한 공개 빌드 실패를 버그 보고서로 등록합니다. 원문 백업은 보존했고 편집 게시물의 줄바꿈을 통일해 검사와 배포를 통과시켰습니다.

## 변경 내용

### 재현 조건

Windows 작업 PC, Git autocrlf, Ubuntu GitHub Actions, Node.js 24.

### 재현 순서

1. CRLF가 섞인 편집 Markdown의 로컬 바이트 해시를 기록했습니다.
2. Git에 커밋해 Linux Actions에서 같은 파일의 해시를 검사했습니다.

### 기대 동작

편집 후 파일과 커밋·CI의 파일 해시가 같아야 합니다.

### 실제 동작

Actions 실행 40872561810의 verify-editorial.mjs 단계에서 실제 해시와 기대 해시가 달라 실패했습니다.

### 원인

실제 git show 바이트가 로컬 파일을 LF로 정규화한 결과와 같음을 확인했습니다. Git 줄바꿈 변환으로 로컬·CI 바이트가 달랐습니다.

### 적용 내용

.gitattributes의 프로젝트 posts Markdown에 text eol=lf를 지정하고 정규화했습니다. 원문 백업은 변경하지 않았습니다.

## 검증

보완 커밋 0fcf663 및 Actions 실행 40872895161에서 원문·편집 해시·자동 검사와 공개 배포가 통과했습니다. https://github.com/MDJ0126/codex-config/actions/runs/40872895161

## 남은 사항

전체 과거 제품 테스트의 재실행 결과를 의미하지 않습니다.
