## 작업 결과

단계 선택 해제 동작과 라이트·다크 카드 전체 배경색을 구현했습니다.

## 변경 내용

### 재현 조건

Tracefolio 보드 단계 카드

### 재현 순서

접수 등 단계를 선택한 뒤 같은 단계를 다시 누르거나 모든 단계를 누릅니다.

### 기대 동작

단계 선택이 해제되고 결과·버그 전체 목록으로 돌아갑니다. 프로젝트와 검색은 유지합니다.

### 실제 동작

같은 카드 재클릭으로 해제되지 않았으며 모든 단계도 버그 그룹·유형 필터를 남겼습니다.

### 원인

단계 클릭 핸들러는 해제 토글을 구현하지 않았고 all 선택 시 group과 type을 초기화하지 않았습니다.

### 적용 내용

선택 상태 전환을 공통 chooseStage 함수로 분리했습니다. 같은 단계 재클릭 및 모든 단계는 stage=all,group=all,type=전체로 복원하며 프로젝트·검색을 보존합니다. 선택 전부터 카드 전체에 파랑·노랑·초록·회색을 적용하고 선택 카드는 테두리로 구분합니다. app.js에는 내용 기반 버전을 붙여 기존 캐시와 구별합니다.

## 검증

상태 전환 회귀 테스트 3개와 기존 테스트를 포함한 17개 테스트 통과. 재클릭 원복·모든 단계 잔여 필터 해제·다른 단계 전환을 확인했습니다. 빌드와 273개 글·8,702개 내부 링크 검사 통과. 공개 배포 이후 실제 클릭·배경색 확인은 최종 안내에 기록합니다.

## 남은 사항

프로젝트와 검색 조건은 의도적으로 유지됩니다. 모든 조건 해제는 필터 초기화를 사용합니다.
