## 작업 결과

- Affinity 같은 전문 디자인 도구를 가능하면 활용하도록 전역 AGENTS.md에 추가했습니다.
- CLI, 공식 API·SDK, 스크립트, MCP, 헤드리스 실행을 우선하고 GUI 조작은 필요한 경우에 사용하도록 명시했습니다.
- 설치 버전과 실행 결과로 포커스 비간섭을 검증하도록 명시했습니다.
- 비대화형 처리가 어려우면 Inkscape CLI, ImageMagick, 적합한 코드 기반 편집으로 진행하도록 추가했습니다.
- 설치된 전역 지침과 저장소를 동기화하고 Sync.ps1 -Direction Push를 실행했습니다. 커밋: 01cf5c4. 원격 main 푸시 성공을 확인했습니다.

## 화면 제어 없이 가능한 방법

- Inkscape: SVG 편집·변환·내보내기를 CLI로 자동화할 수 있으며 대부분의 관련 옵션은 GUI 없이 실행됩니다. [공식 문서](https://wiki.inkscape.org/wiki/Using_the_Command_Line)
- ImageMagick: 크기 변경, 자르기, 합성, 포맷 변환 등을 명령줄로 처리합니다. [공식 문서](https://imagemagick.org/command-line-processing/)
- 현재 Affinity 공식 사이트는 앱 내부 스크립팅과 스크립트 가져오기·내보내기를 안내합니다. 설치된 사용자 버전의 지원 및 완전한 헤드리스·포커스 비간섭은 미확인입니다. [공식 문서](https://www.affinity.studio/features/scripting)
- Codex 자체도 codex exec 비대화형 실행을 지원합니다. 디자인 도구의 GUI 필요 여부는 별도로 확인해야 합니다. [공식 문서](https://learn.chatgpt.com/docs/non-interactive-mode)
