## 작업 결과

기존 글 261개에 공통 게시물 형식을 적용했고, 이전 안내 중심이던 글 230개는 실제 원문 내용을 같은 페이지에서 읽을 수 있게 정리했습니다. AI용 작성 기준과 두 가지 템플릿을 사이트에 공개했습니다.

[사이트 작성 가이드](../../../guide/index.html) · [AI용 Markdown 가이드](../../../guide/authoring.md)

## 변경 내용

- 프로젝트·유형 → 제목 → 요약 → 상태 → 날짜·버전 → 목차·본문 → 원본 저장 순서로 정리했습니다.
- 표, 코드, 이미지 설명과 문단 간격을 공통 스타일로 적용했습니다. 과거 기록의 중복 안내와 제목 반복을 줄였습니다.
- 편집 전 Markdown은 프로젝트별 editorial-originals에 보존했습니다. 기존 원문·자료 백업은 변경하지 않았습니다.
- 새 글은 tracefolio-v1 형식, 명시적 state와 공통 H2 순서를 사용합니다. 버그에는 재현 조건·기대 동작·실제 동작·원인을 기록합니다.
- 작성 가이드 링크를 사이트 헤더와 게시물 하단에 넣었습니다. 결과·버그 템플릿과 JSON 스키마를 내려받을 수 있습니다.
- 새 글의 형식 오류와 과거 예외의 무단 사용은 빌드에서 차단합니다. 작성 기준을 전역 지침에도 연결했습니다.

## 검증

| 확인 항목 | 결과 |

| 편집 이력 | 편집 전 Markdown 261개와 편집 후 파일 해시 통과 |
| 원문 보존 | 원문 230개·연결 자료 4,211개 해시 통과 |

| 공개 배포 | 보완 커밋 0fcf663의 Actions 실행 40872895161에서 전체 검사와 배포 성공 |
| 실제 가이드 화면 | 제목·유형 표·메타데이터 예제·템플릿 링크 확인 |
| 실제 과거 글 | 대표 CodeAssist 글의 단일 H1, 표 2개, 목차 7개와 실제 본문 표시 확인 |
| 이미지·콘솔 | 대표 글의 두 로고 정상 로드, 브라우저 콘솔 오류 없음 |

첫 공개 빌드에서 Windows와 Linux 사이 줄바꿈 차이로 편집 후 해시 검사가 실패했습니다. 실제 커밋 바이트가 로컬 파일의 LF 변환 결과와 같음을 확인하고, 게시물 줄바꿈을 LF로 통일해 다시 통과시켰습니다. 원문 백업의 바이트는 바꾸지 않았습니다.

## 남은 사항

모든 과거 글의 기술적 결론과 제품 실행 결과를 다시 검증한 작업은 아닙니다. 원문에 없는 성공·원인·작업 시간을 만들지 않았습니다. 실제 화면 확인은 대표 데스크톱 페이지를 대상으로 했으며 모든 글·모바일 화면의 전수 육안 검증을 뜻하지 않습니다.
