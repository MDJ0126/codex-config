## 작업 결과

기존 규칙에 짧은 행동 원칙을 통합하고 사용자의 최신 간결한 보고·수정 범위별 전후 캡처 지침을 보존했습니다.

## 변경 내용

### 적용 내용

초기값 주입과 동일 값 이벤트가 UI 재구성 콜백에 재진입하지 않도록 하고 실제 저장·닫기·재열기로 확인하도록 기존 Unity UI 규칙에 통합했습니다. 프로젝트별 오류 경위는 Pixora 버그 보고서에 분리했습니다.

## 검증

설치본과 설정 저장소 AGENTS.md 해시 일치 확인. Sync.ps1 -Direction Push 실행·커밋·브랜치 푸시 성공. 실행 화면이 없는 지침 수정이므로 장식 스크린샷은 만들지 않았습니다.

## 남은 사항

기존 실행 중인 다른 대화의 자동 적용은 주장하지 않습니다.
