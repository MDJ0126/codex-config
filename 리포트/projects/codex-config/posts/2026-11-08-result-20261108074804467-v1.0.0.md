## 작업 결과

전역 지침과 [작성 가이드](../../../guide/index.html)를 갱신하고 설치본을 동기화했습니다. 이번 보고서에도 대화 기록을 포함했습니다.

## 변경 내용

### 적용 내용

- 발언자와 실제 대화 순서대로 핵심 내용을 정리합니다.
- 중요한 문구는 원문 인용으로 보존하고, 요약과 구분합니다.
- 본문은 짧게 요약하고 긴 대화는 같은 프로젝트의 별도 기록으로 연결합니다.
- 인증정보·개인정보·무관한 개인 대화는 제외하거나 마스킹합니다.

### 대화 기록

1. 사용자(원문): “앞으로 대화기록도 같이 보고서에 기록하도록 해줘”
2. AI(요약): 작업 관련 대화와 핵심 인용을 보존하도록 지침·가이드를 업데이트하겠다고 안내했습니다.
3. 반영 결과: 대화 기록 의무와 원본 세션 로그 전체 덤프 제외 기준을 함께 정리했습니다.

앞으로 작성하는 보고서에 적용하는 지침 변경입니다. 과거 보고서 전체의 대화를 소급 수집하지 않았습니다. 문서 작업으로 실행 화면을 만들지 않았고 GUI·브라우저·보조 서버를 실행하지 않았습니다.

교훈 검토: 통합 — 사용자 요청에 따라 대화 기록 보존을 추가하고 기존 원본 세션 로그·인증정보 보호 규칙과 충돌하지 않도록 통합했습니다.
