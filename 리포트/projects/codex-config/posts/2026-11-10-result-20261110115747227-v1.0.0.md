## 작업 결과

공통 가이드 4개를 86,118바이트에서 61,870바이트로 줄이고, 프로젝트별 예외와 코드·Mermaid 기준을 보존했습니다.

## 변경 내용

### 적용 내용

실행·QA는 실행 메뉴얼, 게시물 형식과 작성은 작성 가이드, 버그 상태·토론은 처리 가이드, 도구와 보고 근거는 작업별 지침에 두었습니다. 전역 파일에서 필요한 시점에 해당 문서만 읽도록 안내하고 코드·Mermaid 요약을 직접 표시했습니다. 고유 규칙을 담은 프로젝트 지침 20개는 유지했습니다.

### 대화 기록

- 사용자 요청 — “그 파일들 다 읽으면 힘들지 않나? 압축할래?”
- 적용 — 공통 가이드에서 중복 설명을 제거하고 역할별 링크로 연결했습니다.

교훈 검토 — 공통 규칙 통합, 프로젝트 전용 지침 변경 없음.

## 검증

파일 바이트와 중복 절의 대응을 대조했습니다. 코드 예시 최소 단위와 Mermaid 적용 조건은 작업별 지침에 보존했습니다. 문서 작업이므로 실행 화면은 해당하지 않습니다.

## 남은 사항
