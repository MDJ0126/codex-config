Codex 설정설정

제품별 고유 로고 제작 및 동일 다큐먼트 파비콘 적용 의무화

완료

새 제품마다 로고를 새로 만들고 모든 언어 문서 파비콘에 동일하게 적용하도록 전역·프로젝트 지침을 통합했습니다.

2026년 11월 4일 오후 11:57 KSTv1.0.0설정

작업 결과

새로운 제품군·제품을 만들 때 고유 로고를 새로 제작하고 제품 UI와 모든 지원 언어의 다큐먼트 파비콘에 동일한 확정 로고를 적용하도록 명시했습니다.

변경 내용

적용 내용

  • 전역 AGENTS.md: 기존 디자인 참고 규칙에 제작·동일 로고 적용·검증 의무를 통합했습니다. 타 제품의 심볼·캐릭터·실루엣 복제 금지 규칙은 유지했습니다.
  • TurnRoom AGENTS.md: 기존 신규 제품 로고 항목에 모든 지원 언어의 파비콘을 추가했습니다.
  • TempleteRoadmap.md: 로고 항목의 완료 기준에 실제 브라우저 탭 표시와 라이트/다크·작은 크기 가독성 확인을 포함했습니다.

신규 제품군·제품을 만들 때마다 기존 제품과 구별되는 고유 로고를 새로 제작하고, 확정한 동일 로고를 제품 UI와 모든 지원 언어의 다큐먼트 파비콘에 적용한다.

아이콘 링크·배포 자산·실제 브라우저 탭 표시를 확인하고, 기존 템플릿·다른 제품의 로고가 남거나 적용이 누락되면 제품 제작을 완료 처리하지 않습니다.

검증

설치 전역 지침과 기본 설정 저장소의 파일 해시가 같은지 확인했습니다. 실제 프로젝트 지침·체크리스트 문구를 대조했고, 기존 Affinity 제작·편집 원본 보관·다른 제품 심볼 복제 금지 규칙을 보존했습니다. 별도 체크아웃의 원격 최신 지침과 설치본 차이는 이번 로고·파비콘 문장 하나였음을 확인했습니다. Sync.ps1 -Direction Push로 설치본을 동기화하며 이번 승인 범위만 커밋·게시합니다.

현재 전역 지침 원문

교훈 검토: 사용자의 명시적 지속 요구를 기존 디자인 참고 규칙에 통합했습니다. 중복 규칙을 추가하지 않았습니다. 적용 범위는 앞으로 만드는 제품군·제품입니다.

남은 사항

이번 작업은 지시사항 업데이트이며 기존 제품의 로고·파비콘을 실제 제작·교체한 작업이 아닙니다. 화면 변화가 없는 문서 수정이므로 실행 화면을 새로 만들지 않았습니다. GUI·브라우저·편집 앱·서버를 새로 실행하지 않았고 CLI 실행 종료를 확인합니다. 이미 실행 중인 다른 대화가 변경 지침을 자동으로 읽었다고 주장하지 않습니다.
