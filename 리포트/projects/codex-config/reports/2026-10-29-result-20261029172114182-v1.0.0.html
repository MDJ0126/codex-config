턴룸 프로젝트의 공통·제품별 소항목 구성

완료

턴룸 아래 공통·통합 작업, Pixora, Design Data Table 소항목을 구성하고 기존 보고서의 합산·개별 조회를 연결했습니다.

2026년 10월 30일 오전 2:21 KSTv1.0.0수정사항

작업 결과

사이드바의 상위 묶음과 소항목, 접기·펼치기, 작성 폼 그룹과 AI 작성 가이드를 구현했습니다.

변경 내용

적용 내용

기존 통합 작업 보고서를 근거로 턴룸을 상위 묶음으로 표시합니다. 소항목은 공통·통합 작업(turnroom), Pixora(pixora), Design Data Table(designdatatable)입니다. 상위 버튼은 세 소항목 보고서를 합산하며, 소항목 버튼은 해당 프로젝트만 표시합니다. 결과·버그·5단계·검색 필터를 함께 사용할 수 있습니다. 작성 폼도 같은 그룹으로 표시하고 사람과 AI는 기존 JSON project ID를 사용합니다. 보고서 상세에는 상위 묶음과 소항목을 표시합니다. project-groups.json에서 묶음과 표시 이름을 관리하며 기존 글·폴더·URL은 보존합니다.

검증

첫 배포 Actions 40920149393 성공. 실제 브라우저에서 상위 묶음 115건, Pixora 13건과 해당 프로젝트만 표시됨을 확인했습니다. 접기 버튼의 aria-expanded=false와 다시 펼치기를 확인했습니다. 회귀 테스트는 소항목 필터 조합·중복/미등록 ID 거부·중복 없는 메뉴·공통 표시 이름의 원래 ID 유지 등을 검사합니다. 빌드·링크·원문 230개·연결 자료 4,211개·편집 백업 261개 보존 검사를 통과했습니다. 최종 턴룸 이름·공통 항목과 작성 폼은 최종 배포 후 공개 화면에서 추가 확인합니다.

남은 사항

턴룸의 확인된 공식 로고는 등록되지 않아 기존 미등록 표시를 유지합니다. 상위 항목은 조회용 묶음이며 JSON project에는 소항목 ID를 기록합니다.
