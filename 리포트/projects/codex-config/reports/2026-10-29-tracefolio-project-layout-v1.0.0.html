구조 변경·로컬 검증 완료

보고서·첨부자료·원문을 프로젝트별 하위 폴더로 통합하고 사이트 이름을 Tracefolio로 정리했습니다. 기존 공유 주소는 이동 안내로 유지합니다.

2026년 10월 29일 오후 9:00 KSTv1.0.0보고서 관리

보고서와 이슈의 근거를 프로젝트별로 이어서 남긴다는 의미로 Tracefolio라는 이름을 적용했습니다. 주황색 문서 보관함 심벌은 유지하고 헤더의 워드마크·설명·강조색을 새 이름에 맞췄습니다. 이름의 상표 등록 여부나 독점 사용 가능성을 검증한 것은 아닙니다.

프로젝트별 파일 관리

리포트/projects/<project>/
  posts/       Markdown 원본
  reports/     HTML 보고서
  assets/      로고·첨부파일·이전 자료
  originals/   바이트 그대로 보존한 원문 백업
  • 기존 보고서 256개를 project 메타데이터에 따라 7개 프로젝트 폴더로 옮겼습니다.
  • 프로젝트별 로고·화면 캡처·이전 자료와 원문 백업도 해당 프로젝트 아래로 이동했습니다.
  • 공통 CSS·JavaScript·Tracefolio 로고는 공용 assets에 남겼습니다.
  • 신규 보고서는 projects 아래 해당 프로젝트의 posts에 작성합니다. 폴더와 project 값이 다르면 빌드가 중단됩니다.
  • 빌더·링크 검증·이전 해시 검증·Pages 패키징·전역 지침을 새 구조로 변경했습니다.

기존 주소와 자료 보존

  • 기존 HTML 공유 주소에는 새 프로젝트 경로로 이동하는 안내를 생성합니다.
  • 기존 공개 Markdown 원문 경로에는 새 위치 링크를 담은 안내를 둡니다.
  • 이전 매니페스트의 destination·originalBackup·post 경로를 새 위치로 갱신했습니다. 원문 SHA-256과 자료 바이트는 바꾸지 않았습니다.
  • 공통 migration 메타데이터와 주소 호환 파일은 실제 보고서 원본과 구분합니다.

검증 근거

  • 구조 변경 후 Markdown/HTML 256쌍, 로컬 링크 3,089개와 프로젝트·유형·검색 조합 검증을 통과했습니다. 이 보고서 추가 후 다시 검사합니다.
  • 원문 230개와 공개 연결 자료 4,211개의 해시를 재확인했습니다.
  • 기존 HTML 주소용 이동 안내 572개를 생성했습니다. 백업 원문의 옛 위치 안내는 웹 패키지에 포함하지 않습니다.
  • Git 속성에서 새 프로젝트별 원문·이전 자료의 줄바꿈 자동 변환이 꺼진 것을 확인했습니다.
  • 공개 사이트의 새 이름·새 경로·이전 주소 동작은 푸시 후 실제 배포에서 확인합니다. 로컬 구현을 배포 완료로 대신 보고하지 않습니다.
