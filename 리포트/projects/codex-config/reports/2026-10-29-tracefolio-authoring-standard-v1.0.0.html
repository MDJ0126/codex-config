본문 정리·가이드·자동 검사 구현 완료

기존 글 261개를 공통 게시물 화면으로 정리하고, 원문 링크 중심의 글 230개에는 본문·표·코드를 반영했습니다. AI용 가이드·템플릿·형식 검사를 추가했습니다.

2026년 10월 29일 오후 9:19 KSTv1.0.0보고서 관리

작업 결과

기존 글의 내용과 원문 근거를 보존하면서 공통 게시물 형식을 적용했습니다. 사이트 상단의 작성 가이드에서 AI용 Markdown, 결과·버그 템플릿과 메타데이터 스키마를 내려받을 수 있습니다.

변경 내용

영역 적용한 내용
기존 글 261개 Markdown 편집, 편집 전 원본을 프로젝트별 editorial-originals에 보존
이전 글 230개 원문의 실제 본문·표·코드·이미지를 게시물에 반영하고 원문 시점임을 표시
상세 화면 프로젝트·유형, 단일 제목, 요약, 상태, KST 날짜, 버전, 목차, 본문, 원본 저장 순서
표·코드·이미지 표의 가로 스크롤, 코드 블록, 이미지 설명, 문단 간격과 좁은 화면 스타일

자동 검사 새 글의 필수 제목·순서·상태·시간·XERJ 표기와 과거 예외 무단 사용 검사

AI용 작성 자료

  • 사이트 작성 가이드
  • AI용 Markdown 원문
  • 결과 보고 템플릿
  • 버그 보고 템플릿
  • 메타데이터 스키마

새 글은 작업 결과 → 변경 내용 → 검증 → 남은 사항 → 작업 시간 순서로 작성합니다. 제목은 메타데이터에서 생성하며 본문에 H1을 다시 넣지 않습니다. 과거 글은 legacy-v1로 표시하지만 새 글이 이 예외로 검사를 우회할 수 없도록 등록된 과거 파일 목록과 대조합니다.

검증

  • 기존 보고서 261쌍과 로컬 링크 7,211개, 프로젝트·유형·검색 조합 검증 통과.
  • 편집 전 Markdown 261개의 SHA-256과 편집 후 파일 해시 검증 통과.
  • 이전 원문 230개와 연결 자료 4,211개의 해시 검증 통과. 원문 백업 바이트는 변경하지 않았습니다.
  • 표·코드·이미지·목차 렌더링, raw HTML과 실행 URL 차단, 버그 필수 항목, 코드 안의 Markdown 제목, 템플릿 2종에 관한 자동 검사 6개 통과.
  • 대표 CodeAssist 기록의 표, 247·108 등의 원문 수치와 미측정 제한 문구가 게시물에 남아 있는지 대조했습니다.
  • 원문에 연결된 비공개·미보존 참조 84개는 공개 링크로 위장하지 않고 텍스트로 표시했습니다.
  • Markdown 처리는 설치된 런타임의 Marked 17.0.5 배포본을 라이선스와 함께 보관해 사용합니다. 빌드가 외부 패키지를 내려받지 않습니다. 렌더러의 raw HTML·URL 정책을 별도로 검사합니다.

남은 사항

과거 제품의 테스트를 이번 편집에서 재실행하지 않았습니다. 원문에 없던 원인·성공·완료 시각은 추가하지 않았습니다. 모든 과거 기록의 문장이나 기술적 판단을 재검증한 작업은 아닙니다. 공개 배포와 대표 화면 확인은 이 기록을 푸시한 뒤 수행하며 결과는 최종 안내에 구분해 보고합니다.
