중앙 아카이브 Pages 배포 복구와 공개 본문 검증

해결

공식 Pages 액션과 회차별 고유 산출물로 전환 후 중앙 아카이브 배포 및 공개 HTML/첨부 바이트 검증에 성공했습니다.

접수→검토→진행→해결→종료
2026년 11월 7일 오전 3:41 KSTv1.0.1버그 추적

작업 결과

Actions42272026120 성공. 공개32개 보고서/첨부 HTTP200·포장본 SHA256 일치,9언어18문서 본문 확인.

변경 내용

재현 조건

GitHub Actions / GitHub Pages / Node24

재현 순서

GrowingCity 결과 보고서 푸시 후 실행42267356845와42268488536(2회)에서 검사/포장/업로드 성공 뒤 Deploy 실패. 개별 HTML404를 확인.

기대 동작

최신 개별 보고서와9언어 문서가 중앙 공개 HTTPS에서 정상 응답

실제 동작

Pages API deployment_failed. 서버 상세 사유 응답은 status 하나뿐. GitHub 연결 재실행403, 기존 Git 인증의 비대화형 API 재실행201 후에도 실패.

원인

최초 실패는 Pages API의 deployment_failed이며 서버 상세 원인은 미공개입니다. 산출물 크기·심볼릭 링크 제한 위반은 확인되지 않았습니다. 기존 자체 배포/고정 산출물 이름을 공식 지원 경로·회차별 고유 이름으로 교체한 후 동일 보고서/문서 콘텐츠 배포가 성공했습니다. 이 결과만으로 비공개 서버 내부 원인을 단정하지 않습니다.

적용 내용

공식 actions/deploy-pages@v5.0.1(Node24) 사용, 업로드/배포 양쪽 산출물 이름을 report-pages-${{ github.run_id }}-${{ github.run_attempt }}로 일치. 자체 상태 조회·취소 코드를 제거했습니다. 배포 이후 verify-public.mjs가 최신5개 보고서와 직접 연결된 로컬 첨부를 공개 HTTPS에서 가져와 포장본 SHA256과 대조합니다. HTTP200이어도 오래된 내용이면 실패하고404도 통과시키지 않습니다. 게임 소스·외부 에셋은 변경하지 않았습니다.

검증

공식 액션 action.yml·deployment.js 및 업로드 액션의 name 입력을 확인했습니다. 독립4개 검사(동일 바이트,200이지만 오래된 본문 거부,404거부,전파 지연 후 정상본문 재검사) 통과. 기존1240개 Markdown/HTML·42534개 로컬링크 검사 통과. 패키지11054파일/762252321바이트/심볼릭링크0/1GiB미만을 확인했으므로 알려진 크기·링크 제한을 원인으로 단정하지 않았습니다. 공식 배포 액션 · 공식 액션 입력 교훈: 기존 전역 공개 HTML 확인 의무를 적용하고 CI가 실제 본문까지 대조하도록 합니다. 기존 규칙과 중복되어 전역 지침 추가 없음. 실제 화면 변화 없는 배포 코드 작업으로 스크린샷은 없고 브라우저/Unity는 실행하지 않습니다. 실제 실행42272026120 / 커밋361b2f361792e4971cc7c42e744cd4c03c126abe는 공식 배포 및 후속 공개검사까지 성공했습니다. CI에서 공개32개 파일의 HTTP200·포장본 SHA256 일치를 확인했습니다. 요청한 GrowingCity 개별 보고서와9언어 HTML/README18개를 인증 없이 직접 GET하여 언어·420초 성장·100초 쿨타임 본문을 대조했습니다. Windows 재생성본 최초 대조는 CSS 파일 줄바꿈 때문에 버전 해시가 달라 실패했습니다. 실제 CSS를 Git LF로 대조하면 공개 해시2afda73e18c8과 일치했고, Git LF 기준으로 계산한 CSS 해시가 공개본과 일치함을 확인했습니다. 로컬 별도 재생성본 전체는 실제 CI 포장본과 구분했습니다. 전역 Git 설정과 사용자의 다른 체크아웃은 수정하지 않았습니다. 실제 배포 무결성의 근거는 CI가 같은 실행에서 생성·업로드한 포장본과 공개본32개를 대조한 결과이며, Windows 별도 재생성본의 전체 바이트 일치를 주장하지 않습니다. 공개 게임 보고서 · 성공 실행

남은 사항

배포·공개 본문 검증은 완료했습니다. 최초 서버의 비공개 실패 사유는 여전히 미확인입니다. 브라우저 시각 렌더와 Unity Play는 이번 배포 복구 범위에서 실행하지 않았습니다.
