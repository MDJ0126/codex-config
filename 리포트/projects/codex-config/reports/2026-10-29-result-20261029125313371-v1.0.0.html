검증

공개 보드의 해결 필터에서 실제 TF-1만 표시됨을 브라우저로 확인했습니다. 작성 폼의 빈 제목 거절, 버그 전용 입력, 해결 단계 근거 누락 거절과 근거 입력 후 JSON v2 미리보기 통과를 확인했습니다. 브라우저 오류 로그는 없었습니다. 11개 단위 테스트와 빌드·링크·이관·편집 보존 검사가 통과했습니다. GitHub Actions 40876242039 및 실제 접수 배포 40876317567이 성공했습니다. 실제 등록: https://github.com/MDJ0126/codex-config/issues/1
