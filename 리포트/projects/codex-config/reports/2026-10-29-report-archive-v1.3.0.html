프로젝트별 보고서와 버그·수정사항 분류

구현·로직 검증 완료

기존 보고서 20개를 5개 프로젝트로 분류하고 실제 로고를 반영했습니다. 모든 작업 결과를 이 아카이브에 등록하도록 전역 지침을 적용했습니다.

2026년 10월 29일 오후 8:33 KSTv1.3.0시스템

프로젝트 분류와 별도 보고 유형 필터 구현, 기존 게시물 메타데이터 분류, 최초 디자인 예제 삭제 및 전역 지침 적용을 완료했습니다.

분류한 프로젝트

  • Pixora: 시제품, 사용 예제, 보조 창, 설정 팝업 관련 보고서 5개.
  • Design Data Table: 에디터 아이콘, 파일별 사용 예제, 게임 데이터 문제 목록 관련 보고서 4개.
  • EngineMigrator: 외부 의존성 진단과 QA 관련 보고서 3개.
  • Affinity CLI: 개발 견적과 구현 보고서 2개.
  • Codex 설정: 아카이브, 디자인 지침, 도구 비교 관련 기존 보고서 6개와 이번 보고서.

구현한 내용

  • Markdown front matter에 필수 변수 project와 type을 추가했습니다. category는 세부 분야로 유지했습니다.
  • 프로젝트 선택과 작업 결과·버그·수정사항·검토·설정 유형을 별도로 선택할 수 있습니다. 검색을 함께 적용할 수 있습니다.
  • 프로젝트 선택 버튼에 건수를 표시하고 목록과 보고서 상단에 프로젝트명·로고·보고 유형을 표시했습니다.
  • projects.json에 등록되지 않은 프로젝트나 잘못된 보고 유형은 빌드를 중단합니다.
  • 최초 design-example v1.0.0과 v1.1.0의 Markdown·HTML 총 4파일을 삭제했습니다. 실제 제품의 사용 예제 구현 보고서는 보존했습니다.
  • 앞으로 모든 프로젝트의 결과·실패·보류·버그·수정 보고를 이 아카이브에 등록하도록 전역 지침을 적용했습니다. 새 프로젝트의 등록·로고 출처·검증 절차도 추가했습니다.

실제 로고

  • Pixora의 Design/Brand/Pixora-Symbol.png, Design Data Table의 에디터 DesignDataTableLogo.png, EngineMigrator의 docs/assets/enginemigrator-logo.png를 복사했습니다.
  • 이미지 3개를 직접 열어 확인했습니다. 원본과 복사본의 SHA-256 일치, PNG 크기와 바이트를 검증했고 assets/logos/sources.json에 출처를 남겼습니다.
  • Codex 설정과 Affinity CLI는 확인된 전용 로고가 없어 null로 등록했습니다. 첫 글자 대체 표시는 공식 로고가 아니며 미등록 상태임을 접근성 텍스트로 표시합니다.

검증 근거

  • 기존 보고서 20개의 Markdown과 HTML 쌍 및 로컬 링크 162개 검사 통과.
  • 실제 app.js를 최소 DOM 모형에서 실행해 모든 프로젝트·유형 필터를 검증했습니다.
  • Pixora + 수정사항 + v1.1.2 조합에서 해당 보고서 1개 표시를 확인했습니다.
  • 검색 결과 없음, 전체 초기화, 예제 제거, PNG 로고 파일 검사 통과.
  • 전역 지침을 백업하고 설치 파일과 저장소의 SHA-256 일치를 확인했습니다.
  • 이 문서를 추가한 뒤 전체 재빌드·검증과 커밋·푸시를 진행합니다. 원격 완료 결과는 채팅에서 안내합니다.

미확인·남은 사항

  • 실제 브라우저 화면 배치와 클릭은 미확인입니다. 기존 로컬 파일 접근 정책을 우회하지 않았습니다.
  • Affinity CLI doctor와 status는 EACCES를 반환했습니다. 기존 HTML/CSS 직접 수정이 적합한 작업이므로 앱 재시작이나 GUI 조작 없이 구현했습니다. Affinity 문서 작업을 실행했다고 보고하지 않습니다.
  • 다른 작업에서 수정 중인 affinity-cli 코드 2파일은 이번 변경에서 제외합니다.
  • 인터넷 공개 사이트를 새로 배포한 것은 아닙니다. 이 설정 저장소의 로컬 아카이브를 갱신합니다.
