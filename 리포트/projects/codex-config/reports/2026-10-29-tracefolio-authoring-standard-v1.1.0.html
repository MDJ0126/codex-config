변경 내용

  • 프로젝트·유형 → 제목 → 요약 → 상태 → 날짜·버전 → 목차·본문 → 원본 저장 순서로 정리했습니다.
  • 표, 코드, 이미지 설명과 문단 간격을 공통 스타일로 적용했습니다. 과거 기록의 중복 안내와 제목 반복을 줄였습니다.
  • 편집 전 Markdown은 프로젝트별 editorial-originals에 보존했습니다. 기존 원문·자료 백업은 변경하지 않았습니다.
  • 새 글은 tracefolio-v1 형식, 명시적 state와 공통 H2 순서를 사용합니다. 버그에는 재현 조건·기대 동작·실제 동작·원인을 기록합니다.
  • 작성 가이드 링크를 사이트 헤더와 게시물 하단에 넣었습니다. 결과·버그 템플릿과 JSON 스키마를 내려받을 수 있습니다.
  • 새 글의 형식 오류와 과거 예외의 무단 사용은 빌드에서 차단합니다. 작성 기준을 전역 지침에도 연결했습니다.
