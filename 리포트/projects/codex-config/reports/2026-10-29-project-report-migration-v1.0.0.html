기존 프로젝트 보고서 이전 현황

보고서 230개의 로컬 이전과 해시 검증을 완료했습니다. GitHub Pages 활성화와 자동 배포 구성도 준비했지만, 공개 파일 업로드는 승인 대기 중입니다. 기존 프로젝트의 원본 보고서는 아직 삭제하지 않았습니다.

확인한 보고서

  • CodeAssist: 작업·비교·검증 보고서 137파일.
  • Design Data Table: 테스트·검증 보고서 90파일.
  • EngineMigrator: 개발 현황·빌드 캐시 정리 기록 2파일.
  • WindowsFolderSize: 설치 보안 검증 보고서 1파일.
  • Pixora, MOA, Fantasya 및 나머지 조사한 프로젝트에서는 추가로 이전할 독립 작업 보고서를 찾지 못했습니다. 제품 사용 설명서와 계획 문서는 이전 대상으로 간주하지 않았습니다.

보존·등록한 결과

  • 기존 원문은 originals 폴더에 SHA-256과 함께 바이트 단위로 보존했습니다.
  • 공개용 원문과 연결 자료는 assets/imports에 프로젝트별 원래 경로를 유지해 복사했습니다.
  • Markdown 등록 글 230개를 생성해 원문을 중앙 목록에서 열 수 있도록 했습니다. 원문의 기존 제품 버전·실행 결과를 이번 이전 결과로 새로 검증했다고 주장하지 않습니다.
  • 연결 자료 포함 총 4,211파일, 289,805,256바이트입니다.
  • HTML 169, Markdown 100, PNG 3,682, JPG 236, SVG 13, PDF 4, CSS 2, JavaScript 2, 글꼴 3파일입니다.
  • 원래 누락됐거나 공개 웹 자료가 아닌 로컬 참조는 공개용 HTML에서 비활성 표시합니다. 원본 백업은 수정하지 않았습니다.
  • CodeAssist와 WindowsFolderSize의 로고도 실제 프로젝트에서 복사해 원본 해시와 이미지를 확인했습니다.
  • 삭제 후 남을 프로젝트 문서 20개에서 160개의 링크를 외부 아카이브 주소로 바꿀 계획을 작성했습니다. 아직 원본 프로젝트에는 적용하지 않았습니다.

검증 근거

  • 기존 보고서 230개의 원문 백업 SHA-256 검사 통과.
  • 공개용 파일 4,211개의 해시와 등록 Markdown 존재 검사 통과.
  • 기존 중앙 글과 통합한 251개 Markdown/HTML 쌍, 로컬 링크 2,009개와 프로젝트·유형·검색 조합 검증 통과. 이 상태 보고서 추가 후 다시 검증합니다.
  • 이전할 텍스트 파일에서 일반적인 GitHub/API 비밀 키 형식은 검출되지 않았습니다. 이미지와 문서 전체가 비민감하다고 보장한 결과는 아닙니다.
  • 원래 보고서에 기록된 제품 빌드·엔진·테스트를 재실행하지 않았습니다.

공개 설정과 승인 제한

  • GitHub Pages API에서 workflow 배포 방식 활성화를 확인했습니다.
  • 공개 예정 주소: https://mdj0126.github.io/codex-config/
  • 공식 GitHub Pages Actions로 보고서 파일만 포장·배포하도록 구성했습니다. 설정 파일, 도구, 이전 매니페스트와 원문 백업은 Pages 배포 폴더에서 제외합니다. 중앙 Git 저장소 자체가 공개 저장소이므로 커밋되는 원문 백업은 저장소에서 읽을 수 있습니다.
  • 자동 승인 검토가 연결 자료 4,211개 전체의 공개 범위는 별도 승인이 필요하다며 공개 저장소 푸시를 거부했습니다. 업로드를 우회하지 않았습니다.
  • 과거 화면 캡처·개발 현황·연결 문서를 누구나 볼 수 있게 됩니다. 전체 공개 또는 보고서 본문만 공개 중 사용자의 승인을 요청한 상태입니다.
  • 원본 삭제와 프로젝트 문서 링크 수정은 원격 보존·공개 확인 후 수행합니다. 현재 원본은 모두 보존되어 있습니다.
