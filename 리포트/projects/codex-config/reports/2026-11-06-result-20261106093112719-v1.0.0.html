Unity UI 폰트·정적 설정의 씬 저장 원칙 통합

완료

기존 Unity UI 항목을 강화해 런타임 폰트 할당과 UI 생성 도구 재실행에 의한 설정 덮어쓰기를 금지했습니다.

2026년 11월 6일 오후 6:31 KSTv1.0.0설정

작업 결과

사용자 지시에 따라 기존 Unity UI 규칙 한 항목을 통합 수정하고 설치본·기본 설정 체크아웃·원격 main에 반영했습니다. 다른 대화의 자동 재적용은 주장하지 않습니다.

변경 내용

적용 내용

폰트·배치·스타일·정적 문구·버튼 연결은 씬·프리팹과 Inspector 이벤트에 직접 저장합니다. 명시 요청 없이 UI 생성·재구성 코드, 런타임 폰트 할당, Start·Awake의 정적 UI 덮어쓰기를 금지합니다. 코드는 동적 데이터와 동작 연결만 담당하고, 저장·재열기와 실제 표시 검증을 구분합니다. 새 중복 항목을 추가하지 않고 기존 Unity UI 항목을 교체했습니다.

검증

설치본과 기본 설정 저장소의 AGENTS.md SHA-256 동일성을 확인했습니다. 기존 미게시 전역 변경은 양쪽에 보존했습니다. 깨끗한 별도 동기화 저장소에 승인된 UI 규칙만 준비하고 Sync.ps1 -Direction Push를 실행했습니다. 커밋6e3249dbd1a016221995d58700d791ab446578e1은 AGENTS.md 한 파일의 한 줄 교체이며 원격 main 푸시 성공을 확인했습니다.\n\n사용자의 명시적 선호를 기존 항목에 통합한 교훈입니다. 프로젝트별 코드·폰트 근거는 성장하는 도시 보고서에 분리했습니다. 지침 수정은 실행 화면이 없어 스크린샷을 만들지 않았습니다.

남은 사항

이미 실행 중인 다른 대화가 새 규칙을 자동으로 다시 읽는지는 확인하지 않았습니다. 기존의 다른 미게시 변경은 이번 커밋에 포함하지 않았습니다.
