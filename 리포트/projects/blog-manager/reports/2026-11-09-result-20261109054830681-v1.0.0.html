미미로 블로그 매니저수정사항

블로그 소유자 확인과 검색 API 설정 바로가기 0.11.1

검증 대기

네이버 블로그 소유자로 확인된 경우에만 원고 기능을 표시하고, 확장 팝업에 검색 API 설정을 추가했습니다.

2026년 11월 9일 오후 2:48 KSTv1.0.0수정사항

작업 결과

확장 팝업의 검색 API 설정에서 설치형 관리자의 Client ID·Client Secret 입력란을 열 수 있습니다. 비로그인 또는 소유자 확인 실패 시 원고와 자동 예약 등록이 차단됩니다.

변경 내용

적용 내용

  • 소유권 확인 전 원고를 읽거나 게시 작업을 시작하지 않습니다. 이미 열린 화면에서 소유권을 잃으면 네이버 원래 목록이나 본문을 복원합니다.
  • 확장 팝업에 검색 API 설정을 추가하고 관리자 입력란에 네이버 공식 키 발급 안내를 연결했습니다.

검증

설치형 앱 0.11.1의 런타임 49개 파일 해시 및 원고 불변 확인. 회귀 검사 69개 통과. 갱신 후 실제 로그인 Chrome에서 + 카드 1개와 로컬 원고 카드 3개 확인. 실제 익명 네이버 응답 및 격리 검사에서 원고 목록 접근과 자동 예약 작업 요청 차단 확인.

남은 사항

실제 Chrome에서 로그아웃을 실행하는 검증은 미실행입니다. 팝업 클릭 대신 설정 주소를 직접 열어 입력란과 공식 링크를 확인했습니다. 검색 API 키 미등록 상태로 실제 인증 요청은 미실행입니다. 비공개 원고가 포함된 캡처는 공개 대상에서 제외했습니다. 전역 지침은 기존 규칙과 중복되어 변경하지 않았습니다.

대화 기록 요약(개별 시각 미기록). 사용자 “로그인 안 했을 때는 기능 꺼줘” → 사용자 확장 팝업에 검색 API 설정 링크 요청 → AI 0.11.1 설치와 갱신 안내 → 사용자 “두 곳 새로고침 완료” → AI 로그인 Chrome 카드 개수 확인.
