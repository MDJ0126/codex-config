예약 원본 수정 저장·검증 후 원고 동기화 0.10.3

검증 대기

확장에서 예약 원본을 편집하고 기존 시각을 유지해 저장한 뒤 원고 파일에 반영하는 코드를 구현했습니다. 사용 중인 화면 보존 지시에 따라 설치·실제 네이버 수정 저장은 미실행입니다.

2026년 11월 8일 오후 11:51 KSTv1.0.0수정사항

작업 결과

예약 수정 저장과 검증 후 로컬 동기화 구현·0.10.3 설치본 생성. 사용자 화면 사용 중이므로 설치·크롬 활성화·실제 수정 제출은 수행하지 않았습니다.

변경 내용

적용 내용

  • 기존 코드는 예약 원본을 여는 데서 끝났습니다. 이제 원본에서 제목·본문·사진을 편집한 뒤 확장의 예약 수정 저장을 누르는 경로를 추가했습니다.
  • 저장 전 원고 버전과 기존 예약 시각을 재확인합니다. 다른 곳에서 시각이 바뀌었으면 제출하지 않습니다.
  • 네이버 응답의 같은 접수번호와 예약 목록의 제목·시각을 확인하고 원본을 다시 열어 본문·사진을 대조한 뒤 로컬 Markdown/파일 묶음을 갱신합니다. 이전 파일은 백업합니다.
  • 결과 확인에 실패하면 재시도 시 재제출하지 않고 결과만 확인합니다. 편집 세션이 열려 있을 동안 새 자동 예약 작업을 시작하지 않습니다.
  • 기존 사진은 가능한 경우 원본 로컬 이미지 경로로 매핑합니다. 표 등 미지원 요소는 제출 전에 중단합니다.

검증

실행 중인 기존 앱을 포함한 회귀 검사 62/62 통과, 건너뜀 0. 새 수정 기능은 그중 5개 격리 검사로 원본 추출·링크/소제목/사진 보존·예약 ID/시각/수정 버전 충돌·본문 불일치·중복 제출 방지를 검증했습니다. 별도 포트·가상 원고만 사용하는 실제 HTTP 서버에서 잘못된 수정 결과 4건 HTTP400/상태 불변, 정상 수정 1건의 같은 예약 ID·시각·원고 파일·백업을 확인하고 임시 서버를 정상 종료했습니다. 이 검증은 실제 네이버 수정 제출을 대신하지 않습니다. 0.10.3 설치본 159840590바이트, SHA256 34CD0CBA00B2C4CD2FD476442B1881CA439F4A2391AB91528F57040D887FF479. 고정된 패키지 60파일·소스47파일 해시 일치를 확인했습니다.

남은 사항

설치·현재 크롬 반영·실제 네이버 예약 수정 저장과 전후 화면 검증은 미완료입니다. 사용자 사용 중인 크롬과 앱을 재시작하지 않았습니다. 태그는 기존 값을 로컬에 보존하며 Native 태그 변경의 별도 동기화는 이번 구현에 포함하지 않았습니다. 본문 표·동영상 등 미지원 컴포넌트는 저장 전 중단합니다.

대화 기록(개별 시각 미기록): 사용자 “예약된 글을 확장프로그램으로 수정하면 수정되게 처리해줘” → AI 10~20분 예상·원본 수정과 예약 유지 검증 제시 → AI가 기존 네이버 탭에서 예약 원본을 열어 구조 확인 → 사용자 “나 쓰고 있다 누가 쓰래” → AI 화면 조작 중단, 본문 수정·저장은 하지 않았음을 설명 → 사용자 “크롬 통해서 충분히 조작되는데 컴퓨터 유즈 쓰지마셈” → AI OS 컴퓨터 유즈 금지 및 현재 사용 중인 크롬 보존, 코드·격리 검사만 진행.

이번 화면 확인에서는 예약 원본 열기만 수행했으며 본문 변경·최종 저장은 하지 않았습니다. 중단 지시에 따라 실제 전후 화면 캡처를 추가하지 않았고 UI 검증 통과로 기록하지 않았습니다.

교훈 검토: 예약 원본 수정은 검증 후 로컬 반영하며 사용 중인 화면은 보존한다는 프로젝트 지침을 추가했습니다. 전역은 기존 화면 비간섭 원칙과 중복돼 변경하지 않았습니다. OS 컴퓨터 유즈는 사용자 지시 이후 사용하지 않았으며 이후 크롬 조작도 수행하지 않았습니다. 새 GUI·브라우저 탭을 만들지 않았고 임시 서버는 종료했습니다.
