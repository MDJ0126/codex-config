# 프로젝트 폴더 안내

**예제를 보려면 `Sample/Scenes`, 엑셀을 보려면 `Sample/Data`로 가시면 됩니다.**

| 찾으시는 내용 | 위치 |
|---|---|
| 사용자 가이드 | `Assets/DesignDataTable/Documentation/UserGuide.ko.html` |
| 게임 예제 씬 | `Assets/DesignDataTable/Sample/Scenes` |
| 예제 엑셀 전체 | `Assets/DesignDataTable/Sample/Data` |
| 게임별 코드 | `Assets/DesignDataTable/Sample/Games` |
| 여러 게임이 함께 쓰는 코드 | `Assets/DesignDataTable/Sample/Shared` |
| 이미지·모델·머티리얼·폰트 | `Assets/DesignDataTable/Sample/Art` |
| 기존 예제의 데이터 확장 코드 | `Assets/DesignDataTable/Sample/Runtime` |
| 예제 생성·복구 도구 | `Assets/DesignDataTable/Sample/Editor` |
| 예제 학습·코드 스타일 문서 | `Assets/DesignDataTable/Sample/Documentation` |

제품 코드는 `Assets/DesignDataTable/Scripts`, 자동 생성된 코드는 `Generated`에 있습니다. `Resources`와 `ThirdParty`는 제품이 사용하는 설정·의존 자료입니다.

## 개발·작업 자료

| 폴더 | 용도 |
|---|---|
| `Docs/Testing` | 검토한 테스트 결과와 증거. 과거 기록의 경로는 당시 기록을 유지합니다. |
| `Docs/Store` | 스토어에 작성할 문안의 원본 |
| `Docs/StoreMedia` | 검토한 스토어용 이미지와 원본 |
| `Tools` | 개발·촬영·검증 스크립트 |
| `WorkFiles` | 복구본·백업·작업용 캡처·로그·생성한 배포 파일 |

`Library`, `Temp`, `obj`, `Logs`, `UserSettings`와 루트의 `.csproj` 파일은 Unity·개발 도구가 관리합니다. 예제를 찾을 때 살펴보실 필요가 없습니다.
