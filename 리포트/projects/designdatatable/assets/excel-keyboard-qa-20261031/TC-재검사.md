## 실패와 수정 이력

- 첫 일반 .NET 저장 검사: Unity ECall 호출로 중단. 제품 오류로 판정하지 않고 격리 Unity에서 실제 저장을 재검사했습니다.
- 도형 반복 검사: 고정된 테스트 파일명으로 기존 파일 충돌. 매 실행 고유 파일명으로 수정 후 .NET/Unity 반복 검사를 통과했습니다.
- 단축키 도움말 검사: Ctrl+B 추가 전의 빈 도움말 기대값이 남아 실패. 실제 새 바인딩의 Windows/Mac 표시를 검사하도록 수정 후 684개 단언을 통과했습니다.
- 격리 프로젝트 1·2차: 비교용 샘플 누락으로 일부 검사 중단. 의존 파일 사전 검사를 추가하고 원본과 동일한 샘플을 복사한 뒤 재검사했습니다.

## 실제 화면 QA — 차단 / 미실행

컴퓨터 유즈 사용은 승인됐지만 현재 세션에는 스킬이 필수로 요구하는 node_repl 도구가 없습니다. 다른 방식으로 화면을 조작해 우회하지 않았습니다.

| 실제 사용자 절차 | 기대 결과 | 상태 |
|---|---|---|
| Workbook·Scene·Project에서 각각 Ctrl+D/P/Shift+P/B/S | 해당 창 명령만 실행 | 미실행 |
| 빠르게 abcd 입력 → Enter·Tab → Undo·Redo | 누락 없이 값 저장·이동 | 미실행 |
| 한글 IME·검색·팝업·수식란에서 편집키 | 텍스트 입력 우선 | 미실행 |
| 실제 F4 및 수식 참조 클릭 | 절대/혼합 참조 전환과 색상 표시 | 미실행 |
| 최소화·카드 호버·복원·다른 앱 전환 | 다른 문서 동반 표시·포커스 탈취·깜박임 없음 | 미실행 |
| ArcadeText 스크롤·입력과 장시간 창 유지 | 실제 화면 렉·키 누락 없음 | 미실행 |
| 실제 닫기 대화상자 저장·취소·버리기 | 파일명 표시·결정 일치 | 미실행 |

캐시 시간은 데이터 조회 측정이며 화면 FPS나 스크롤 성능 보증이 아닙니다. 전체 Excel 탭 동등성 및 27개 원래 작업의 완료도 아닙니다.
