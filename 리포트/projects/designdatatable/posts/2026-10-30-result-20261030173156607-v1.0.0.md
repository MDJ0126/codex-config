## 작업 결과

Unity 엔진 회귀 검증은 통과했습니다. 실제 키 입력·포커스·시각 QA는 아직 실행하지 못해 전체 완료로 판정하지 않았습니다.

## 변경 내용

### 적용 내용

반복 도형 검사가 이전 테스트 파일과 충돌하지 않도록 실행별 고유 파일명 사용. Ctrl+B 추가 전의 도움말 기대값을 새 Windows/Mac 바인딩에 맞게 수정. 격리 Unity QA 준비 도구에 샘플 의존성 사전 검사를 추가했습니다. 제품 오류가 확인되지 않은 부분을 임의로 바꾸지 않았으며 이번 회차의 수정은 검증 도구에 한정했습니다.

닫기 취소·저장 실패80회 반복, 인라인/수식 초안의 지연 저장, 실제 ArcadeText 캐시/편집/Undo 검사를 추가했습니다. 실패한 실행 기록을 보존한 뒤 원인을 확인하고 재실행했습니다.

## 검증

Unity6000.0.83f1을 -batchmode -nographics로 격리 프로젝트에서 실행했습니다. 제품 소스281개가 복사본과 바이트 일치하며 실행 어셈블리 해시를 기록했습니다. 실제 GUI를 클릭한 검사가 아닙니다.

| 검증 | 관찰 결과 |
|---|---|
| 저장 중인 파일 잠금·실패·재시도 | 원본·복구·Undo/Redo 상태 유지, 잠금 해제 후 저장 성공 |
| 닫기 취소·저장 실패80회 | 초안·Dirty·파일명 안내·복구본·원본 바이트 유지 |
| 인라인·수식 초안의 지연 저장 | 재열기한 파일에 실제 초안 저장 |
| CR/LF/CRLF·한글·일본어 | 저장·재열기·복구·Undo/Redo 일치 |
| 수식 참조·표·삽입·스키마·Enum·게임 값 | 엔진 검사 통과 |
| 187종 도형 교체2회 | 텍스트·객체 ID·도형 외 XML 유지 |
| ArcadeText 실제 데이터 조회 | 50,400회 직접/캐시 조회 결과 일치, 편집·Undo 후 무효화 |

16개 그룹3550개 단언은 반복 검사와 개별 비교를 포함하며3550개 사용자 TC를 의미하지 않습니다. 별도 .NET 검사에서 단축키2106개 메타데이터/모델 단언, 도움말684개, 최소화 호버151개, 상태 배치92개 단언도 통과했습니다. 모델 정책 검사는 실제 네이티브 키 입력을 대체하지 않습니다. 최종 컴파일 오류0개, 기존 Templete XML 주석 경고8개.

## 남은 사항

사용자가 이번에 실제 QA를 승인했으나 현재 세션에는 컴퓨터 유즈 스킬의 필수 node_repl 도구가 제공되지 않습니다. 스킬과 도구 목록을 확인했으며 다른 방식의 화면 자동화로 우회하지 않았습니다. 실제 abcd 연속 입력·Enter/Tab·IME·Excel↔Unity↔다른 앱 포커스·Play/Pause 충돌·F4·최소화/미리보기/복원·깜박임·실제 렉·닫기 대화상자의 시각 검증이 남았습니다. 실제 화면 캡처도 미실행입니다. 따라서 완벽 또는 전체 QA 완료로 판정하지 않습니다. 기존 스크린샷을 새 결과로 재사용하거나 소스 해시만 갱신하지 않았습니다.

전체 Excel 탭27개 원래 작업이나 모든 게임의 QA 완료 보고가 아닙니다. 실제 키 입력 도구가 제공되는 세션에서 남은 한국어 TC를 이어서 실행해야 합니다. 교훈 검토: 반복 QA의 독립 파일·의존 샘플 검사와 엔진/GUI 증거 구분을 검증 도구와 TC에 반영했습니다. 기존 전역의 실제 검증·미실행 표시 지침으로 충분하여 전역 지침 변경 없음. 결과 보고서는 로컬 생성이며 공개 배포하지 않았습니다.

## 작업 시간

- 제안 시간: 30~50분 — 실제 화면 QA 포함 1차 예상
- 실제로 완료된 시간: 첫 시각 기록 기준 15분 59초, 2026-10-31 02:31:56 KST — 엔진 검증 결과 기록. 실제 화면 QA는 미완료이며 전체 완료 시각이 아닙니다.
- XERJ: 사용 — XERJ 서버 상태 확인 후 숨김 검색 서버를 통해 HandleCopy 후보를 검색하고 현재 WorkbookViewer·편집·단축키 소스와 대조했습니다.
