## 변경 내용

### 적용 내용

Version 2.0.2 update to the existing Design Data Table product. This release refines shared editor controls, selectors and asset Inspectors, improves workbook creation and recovery, adds direct maximize/restore, and restores the document shelf below the Unity console/status line. The package edits XLSX/CSV spreadsheets and typed game tables, with validation and C# class/runtime-data generation. Samples and offline guides are included in nine languages. Tested scope: Unity 6000.0.83f1 on Windows, Built-in samples. Samples require Unity uGUI and 2D Sprite; Addressables is optional and installed separately. Spreadsheet support is a documented subset; XLS, macros and encrypted workbooks are not supported. Please refer to the bundled guide and Third-Party Notices for limits and asset attribution. AI assistance is disclosed in the listing.

## 남은 사항

심사 사유는 열린 제출 창에 입력된 상태입니다. 제출 전 서버 저장 여부는 미확인으로, 창을 닫거나 새로고침하면 사라질 수 있습니다. 바이너리 재업로드·재검증은 이번 요청 범위에 포함하지 않았습니다. 교훈 검토: 초안 저장과 제출 창 입력 상태를 구분하는 기존 지침 적용, 전역 변경 없음.
