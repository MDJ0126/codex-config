## 작업 결과

소스 수정과 정적 컴파일은 완료했습니다. 최종 동작·성능 검증은 미실행이며 해결 완료로 처리하지 않습니다.

![사용자가 제공한 수정 전 실제 검색창](../assets/title-search-20261101/user-search-before.png)

## 변경 내용

### 재현 조건

Unity6000.0.83f1·Windows·ChartGallery 실제 검사

### 재현 순서

제목 검색창에서 긴 문자열을 입력하고 Backspace·Delete로 지웁니다.

### 기대 동작

삭제와 입력이 검색창에 적용되고 문서·선택 객체는 유지.

### 실제 동작

삭제 후 길이가 줄지 않으며200입력3459.8ms. 최종 수정안은 아직 실제 재검증하지 않음.

### 원인

문서 컨텍스트에 일반 삭제 키가 등록되고 키 이벤트를 재구성하는 경로를 확인했습니다. 검색 포커스 분리·삭제 문자 보존을 수정했으나 최종 실제 원인·해결 여부는 미확인입니다.

### 적용 내용

제목 검색을 EditorGUI 텍스트 편집기로 연결하고, 일반 Backspace/Delete의 Unity 단축키 등록을 그리드 컨텍스트로 옮겼습니다. 제목 입력 포커스를 기록해 셀·객체 단축키와 분리하고 삭제 문자를 보존합니다. 네이티브 키보드 포커스 조회는 GUI 이벤트당 한 번으로 묶고 검색 스타일을 재사용합니다. 측정에서 더 느린 셀·차트 표시 생략 시도는 최종 코드에서 제거했습니다.

## 검증

수정 전200입력: 총3459.8ms·중앙16.12ms·p95 27.05ms. Backspace 후 검색어 길이 미변경. 중간 수정200입력: 총4972.2ms·중앙23.91ms·p95 32.77ms, 삭제 미해결. 해당 표시 생략 시도는 제거했습니다. 최종 소스3어셈블리 정적 컴파일 exit0. 공유 템플릿의 기존 obsolete경고3건은 별도입니다. 최종 타이핑·성능·IME 검증은 사용자의 화면 조작 금지에 따라 실행하지 않았습니다. 기존38TC는 과거 회차 결과입니다.

## 남은 사항

전체 요청은 미완료입니다. 컴퓨터 사용이 다시 허용되면 최종 검색창 Backspace/Delete·Ctrl+A 삭제·한영 IME 실제 조합·붙여넣기·Enter 검색·객체/시트 보존을 검증하고 같은 조건으로200/반복 입력을 재계측해야 합니다. 성능 개선율을 주장하지 않습니다. 새 최종 실행 화면과 문서 재촬영도 미실행입니다. 기존 문서·도형 정렬·창 복원 잔여는 유지합니다. 교훈 검토: 실패한 최적화를 제거하고 사용자 화면 사용 제한을 지키는 기존 전역 지침 적용, 전역 변경 없음.
