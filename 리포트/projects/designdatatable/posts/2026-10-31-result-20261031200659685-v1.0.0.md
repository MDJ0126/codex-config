## 작업 결과

레이아웃·아이콘·영역·단축키 전체 구현을 지속 목표로 등록했습니다. 전체46개 항목과 기존 미구현/미실행을 그대로 보존합니다. 이번 추가 구현과 실제 검증은 홈 중심이며, 나머지 탭의 원본과 다른 구성을 계속 수정해야 합니다.

## 변경 내용

### 적용 내용

홈7개 그룹의 폭·컨트롤 배치와 통합문서 전용 리본 높이를 조정했습니다. 다른 제품의 일반 리본 높이는 별도 유지합니다.

서식 복사·개별 셀 글꼴 크기·들여쓰기·소수점 편집은 네이티브 XLSX 서식을 보존하고 한 번의 Undo로 복구합니다. 채우기/글자색, 표시 형식, 붙여넣기 분할 메뉴를 실제 명령에 연결했습니다.

Affinity3.3.1에서 추가 아이콘16종을 편집하고 ExtrasV11/WhiteV11 원본과 출력물을 프로젝트 중앙 ColorIcons에 보관했습니다. 전체 아이콘 일치 완료를 의미하지 않습니다.

Microsoft 원본의40개 Home 접근 키와 키 팁 크기·좌표를 연결했습니다. Windows 보조 문자 이벤트가 셀 입력으로 새는 문제를 실제 키 이벤트로 확인해 수정했습니다. 포커스 검사와 마우스 취소를 적용했습니다.

## 검증

실제 실행 환경: Unity6000.0.83f1, Windows, 격리 QA 프로젝트. 정적 컴파일과 네이티브 실행을 구분합니다.

|검증|실제 결과|근거|
|---|---|---|
|홈 API·실제 GUI 클릭·Undo·저장|111통과,0실패(R4)|home-api-r4.json|
|최신 실제 물리 키 입력|13통과,0실패(R11)|home-physical-r11.json|
|Unity Scene 실제 Ctrl+D|5통과,0실패(R11)|unity-scope-r11.json|
|실제 표시 형식 메뉴|5통과,0실패(R1)|home-number-r1.json|
|실제 NoFill 메뉴|6통과,0실패(R1)|home-no-fill-r1.json|
|현재 탭 화면 촬영|20장 촬영,기능 통과 아님(R7)|capture-r7.json|

Unity Scene에서 실제 Ctrl+D 후 오브젝트1→2, Workbook owns=false, 셀 값 Source 유지, 문서 clean을 관찰했습니다. 최신 물리 키 검증은 조합 문자 누수 방지·글꼴 증가·맞춤·들여쓰기·각 Undo를 포함합니다. 한글 IME 전체 스트레스 검증을 통과했다고 주장하지 않습니다.

최초 R9 재실행은 도메인 리로드 뒤 관찰기가 이름이 바뀐 임시 문서를 찾지 못해 실패했습니다. QA 관찰기의 복구 이름 조건을 수정한 뒤 새 문서에서 R10/R11을 통과했습니다. 실패 기록도 보존합니다.

## 남은 사항

전체46TC의 레이아웃·아이콘·영역·단축키 최종 구현과 전수 실행 검증이 남아 있습니다. 이번 통과 수를46TC 통과 수로 합산하지 않습니다.

차트 빠른 레이아웃·행/열 전환·종류 변경·이동, 도형 맞춤/그룹, 표 이름/범위/총합 행 및 미구현 전용 탭을 구현 대상으로 유지합니다. 전체 입력/IME·반복 저장/닫기·9개 언어 문서·최종 제품 패키지 검증도 남았습니다.

제품 변경 커밋·푸시/배포와 이 보고서의 공개를 구분합니다. 지속 목표는 active이며 완료로 바꾸지 않습니다.

교훈 검토: 전역 변경 없음. 실행 증거와 촬영 성공을 구분하고 미실행을 통과로 쓰지 않는 기존 규칙을 유지합니다. 이번 도메인 리로드 관찰기 복구는 QA 프로젝트에만 해당하는 근거로 기록했습니다.
