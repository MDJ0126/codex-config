## 발견하여 수정한 문제

- 등록 원본 GUID가 유효하지 않을 때 빈 경로 비교 예외: 원본 경로 존재 여부를 먼저 확인합니다.
- 검증 설명의 {0} 자리표시자가 보이던 문제: 지역화된 서식 인수를 적용합니다.
- 오류 목록 검색 입력이 셀로 전달될 가능성: 검색 포커스와 키 입력 경로를 분리하고 실제 연속 입력으로 확인했습니다.
- GUI 흐름 종료 예외가 일반 실패처럼 표시되던 경로: 직접·래핑된 ExitGUIException을 다시 전달합니다. 중첩 예외 단위 검증을 수행했습니다.

## 검증 범위와 한계

- 오류 수정 후 재검사, 중복 Id 두 위치, 숫자 범위, 잘못된 Enum·삭제된 Enum, 번역 중복 키·빈 번역을 검사했습니다.
- 11,000개 오류의 전체 건수 및 10,000개 표시 제한, 분할 실행을 검사했습니다. 실제 사용자 ArcadeText 파일의 프레임 시간 측정은 이번 범위가 아닙니다.
- 9개 언어의 실제 패널을 캡처했습니다. 영어·한국어 주요 화면을 직접 육안 검토했습니다. 나머지는 렌더 캡처와 레이아웃 증거를 보관했습니다.
- ExitGUI 원인 경로는 소스 및 중첩 예외 실행으로 검증했습니다. 모든 팝업을 수동 클릭한 것으로 보고하지 않습니다.
- 최초 실패 기록 Error.txt와 SupplementError.txt는 역사 증거이며 최종 성공 결과는 Results.json/Complete.txt입니다.
