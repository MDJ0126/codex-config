적용 내용

DDT의 실제 DesignDataTableLogo.png를 UserGuide·Entries·단축키·자동화 안내의 헤더 또는 첫 제목에 연결하고 파비콘에도 사용합니다. base href가 있는 Entries는 유효한 기준 경로로 해석했습니다. 본문·기능·제품 메뉴·씬·설정은 변경하지 않았습니다. 기존 두 문서 생성기의 마지막에도 반영했습니다.

검증

DocumentFavicon.py를 실제 실행해30개 페이지의 로고/파비콘 경로를 검사했습니다. 삽입한 태그를 제거한 내용이 이전 내용과 같음을 assert했고 원문 바이트의 줄바꿈을 보존하는 원자적 저장을 사용합니다. Python 구문 검사도 통과했습니다. 스크린샷 교체를 하지 않아 캡처 출처를 최신화하지 않았습니다.

실제 브라우저 화면·작은 화면·마우스/키보드·탭 파비콘 표시와 후 캡처는 미실행입니다. 기존 화면 조작 중단 및 file URL 브라우저 보안 정책 거부를 유지했고 우회·다른 브라우저·서버 실행을 하지 않았습니다. 열린 문서의 실제 표시를 갱신했다고 보고하지 않습니다. 확인하려면 기존 문서 탭 새로고침이 필요합니다. ScreenshotManifest의 촬영 시각·소스 해시는 바꾸지 않았습니다.

실제 문서 헤더와 탭 아이콘 표시 검증이 남아 있습니다. 변경 원칙은 기존 고유 로고/파비콘 지침으로 포괄돼 전역 변경 없음.
