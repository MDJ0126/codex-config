작업 결과

구현·비대화형 검증을 마쳤습니다. 사용자가 삭제 요청한 이전 녹색 여섯 칸 로고 PNG와 메타 파일을 제거하고 활성 코드·문서·검증 참조를 현재 문서형 아이콘으로 바꿨습니다. 실제 Project 브라우저 화면 검증은 사용자 화면 조작 금지에 따라 미실행입니다.

변경 내용

적용 내용

프로젝트의 XLSX 아이콘 뒤에 색상 사각형을 칠하던 경로를 생략합니다. 가져오기에서 현재 테마의 투명 아이콘을 네이티브 썸네일로 등록하여 Unity가 README와 같은 방식으로 선택 배경을 처리합니다. 같은 아이콘을 두 번 겹쳐 그리지 않습니다. 가져오기 버전을 6으로 올려 기존 캐시를 갱신합니다. 색상 변경은 지연 재가져오기로 반영하고 같은 색상은 다시 가져오지 않습니다. 숨긴 썸네일은 프로젝트 하위 항목을 추가로 노출하지 않습니다. 기존 CSV 등 비-XLSX 경로는 유지했습니다. 삭제 파일: Assets/TurnRoom/DesignDataTable/Scripts/Editor/Assets/Icons/DesignDataTableLogo.png 및 .meta. 현재 기준: WorkbookAssets.StatusIconTexture와 WorkbookDocumentIcon.png. 공개 사이트 프로젝트 로고도 현재 문서형 아이콘으로 교체했습니다.

검증 결과 JSON · 현재 아이콘 PNG

위 PNG는 실제 importer에서 추출한 아이콘이며 Project 브라우저 스크린샷이 아닙니다. 화면·마우스·키보드 조작 및 새 UI 캡처를 하지 않았습니다. Affinity CLI doctor/status는 ECONNREFUSED를 반환했으며 앱 실행·전환은 하지 않았습니다. 현재 코드 기반 아이콘을 재사용했습니다.

남은 사항

실제 Unity Project 창의 목록·큰 아이콘·선택·포커스·Ping 상태는 재촬영하지 않았습니다. 관련 문서 이미지의 소스 해시도 최신 캡처처럼 갱신하지 않았습니다. 전역 교훈 검토: 기존의 실제 아이콘·원본 대조 및 화면 미검증 명시 규칙을 적용했습니다.
