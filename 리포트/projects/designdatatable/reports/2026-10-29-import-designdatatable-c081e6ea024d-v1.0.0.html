에디터 아이콘 개선 결과

리본·설정·파일 메뉴의 아이콘 개선과 Unity 적용, 필수 검증을 완료했습니다.

변경 결과

  • 60종의 기존 아이콘을 교체하고 전용 기능 그림을 추가해 총 85종의 투명 PNG와 SVG 원본을 만들었습니다.
  • 각진 번역 갱신 그림을 둥근 순환 화살표와 언어 표시로 교체했습니다. 생성 데이터와 기본 언어는 별도 그림으로 구분했습니다.
  • 설정의 언어·화면·편집·테이블 목록·단축키·코드 주석을 각기 다른 아이콘으로 표시합니다.
  • 파일 메뉴의 글자 기호를 PNG 이미지로 교체했습니다.
  • 선 굵기와 모서리·여백을 통일했습니다. 기능 아이콘은 문서 강조색을 따르고 제목줄 조작 아이콘은 흰색을 유지합니다.
  • 기존 아틀라스 GUID를 유지했습니다. 실행 중에는 공유 아틀라스 2장을 사용하며 버튼마다 개별 PNG를 로드하지 않습니다.

검증 근거

  • 전체 C# 빌드: 경고 0, 오류 0. 실제 Unity QA 코드도 수정 후 컴파일·렌더링을 확인했습니다.
  • 아이콘 전용 native 검사: 296개 통과. 명령 키 140개, PNG 85종의 경계 검사도 통과했습니다.
  • 기존 기능 회귀: Play 잠금 33개, 상황별 리본 208개, 게임 리본·Summary 346개 통과. 합계 883개의 native 검사 조건입니다.
  • 현재 가이드 이미지 37장 중 영향을 받은 32장을 실제 Unity에서 재촬영했습니다. 교체 전 이미지와 기록은 보존했습니다.
  • 9개 언어 가이드 검증 오류 0, 브라우저 검사 140개 통과. 공유 가이드 이미지는 영어 UI입니다. 설정 화면은 9개 언어별로 별도 촬영했습니다.

검증의 범위와 남은 사항

  • 실제 Unity native HostView와 Affinity에서 화면을 확인했습니다. 사용자 주 프로젝트에서 모든 기능을 수동으로 다시 클릭했다고 보고하지 않습니다.
  • 이번 작업은 아이콘 개선입니다. 전체 게임이나 스프레드시트의 전 기능 QA로 확대하지 않습니다.
  • 파일 메뉴 추가 캡처용 QA 코드에서 읽기 전용 속성과 초기 GUI 스타일 문제를 발견해 수정한 뒤 실제 캡처를 완료했습니다. 실패 시도는 최종 통과 결과와 구분했습니다.
  • 구현·원본 저장·필수 검증·문서 갱신에 남은 항목은 없습니다. Git 푸시·스토어 업로드·인터넷 게시는 이번 작업에서 수행하지 않았습니다.
