표 전용 탭·차트 스타일·삽입 도형 목록 수정

검증 대기

ChartGallery 실제 표 등록과 리본 목록을 적용했습니다. Unity730건 통과, 실제 화면 검증과 차트 효과 썸네일은 남아 있습니다.

2026년 10월 31일 오후 11:00 KSTv1.0.0수정사항

작업 결과

표·차트·도형 목록 구현 및 배치 검증은 끝났습니다. 화면 검증은 미실행입니다.

변경 내용

적용 내용

ChartGallery A5:C11을 MonthlyRewards 실제 Excel 표로 등록했습니다. 기존 표 인식은 실제 표 메타데이터만 확인하므로 등록되지 않은 원본에서는 전용 탭이 없었습니다.

차트 디자인에1–48번 스타일 스크롤 목록과 현재 선택 표시를 연결했습니다. 기존 편집 API를 사용합니다.

삽입 탭에187종 도형 스크롤 목록을 표시하고, 기존 팝업과 동일한 삽입 준비 동작을 공유했습니다. 도형 서식에서의 변경 동작과 구분합니다.

9개 언어 가이드와 진입 문서에 사용 방법·미리보기 제한을 반영했습니다. 기존 캡처를 새 캡처로 표시하거나 소스 해시를 갱신하지 않았습니다.

검증

Unity6000.0.83f1 -batchmode -nographics에서 최신 소스를 컴파일하고730검사 통과: 표 내부21셀·외부 경계·C11 컨텍스트,48스타일 적용/Undo/Redo/저장 후 재열기,187도형의 삽입 준비/기존 개체 선택 해제/데이터 무변경.

원본 ZIP 비교: sheet1.xml·시트 관계·Content_Types만 변경하고 table XML1개 추가. 기존 차트 XML은 바이트 동일. 소스 diff --check 통과.

Microsoft 공식 기능 설명과 메뉴 경로를 확인했습니다: 도형 삽입, 차트 디자인. 실제 Excel 스크린샷과 나란히 대조한 검증은 아닙니다.

자동 검사 결과 · 워크북 패키지 변경

남은 사항

실제 앱 화면에서 클릭·스크롤·좁은 창 배치·잠금 상태 검증과 재촬영은 미실행입니다. 사용자 화면을 조작하지 않는 조건을 유지했습니다. 따라서 실제 화면 캡처를 첨부하지 않았고 시각 QA 통과로 보고하지 않습니다. 차트 목록은 번호 선택이며 Excel 효과 썸네일 갤러리는 미구현입니다. 제품 저장소 커밋·푸시는 이번 회차에서 수행하지 않았습니다.

교훈 검토: 목록의 버튼 연결·API 검사만으로 화면 갤러리 QA를 통과 처리하지 않습니다. 기존 전역 지침에 이미 있으므로 전역 변경 없음.
