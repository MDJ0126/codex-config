TurnRoom Excel 전체 탭 기능 대조·구현 메뉴얼

작업 중

공식 Excel 명령 목록을 기준으로 기본·전용 탭과 게임 데이터 리본을 항목별 대조하고 순서대로 구현·검증합니다.

목표와 완료 기준

Excel 탭별 실제 기능과 진입 경로를 대조·보완하고 게임 데이터 상태도 동일한 완성도와 일관된 디자인으로 구성합니다.

공식4926개 명령 기록을 탭별 분류하고, 각 항목의 지원/부분/미지원/미확인을 근거와 함께 기록합니다. 전체 탭과 전용 탭의 필요한 동작 및 게임 데이터 상태를 검증하고 탭별 실제 화면 비교·9개 언어 문서·최종 QA를 마칩니다. 미구현을 완료로 바꾸지 않습니다.
