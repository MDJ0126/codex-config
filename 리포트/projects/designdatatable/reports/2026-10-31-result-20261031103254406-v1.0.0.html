Unique 타입과 게임·Enum·로컬라이징 중복 진단

검증 대기

기본·Enum unique 타입, 중복 양쪽 셀과 상대 주소 로그 구현. 23개 워크북 Id 전환 및 화면 없는 Unity 재검증 통과.

2026년 10월 31일 오후 7:32 KSTv1.0.0작업 결과

작업 결과

구현과 비대화형 검증을 마쳤습니다. 기본 타입과 로컬·글로벌 Enum 타입에 (unique)를 선택할 수 있습니다. 게임 데이터 중복값, Enum 정의의 이름·숫자 중복, 로컬라이징 Id 중복을 양쪽 셀 진단과 오류 목록에 연결했습니다. 사용자 컴퓨터 사용으로 화면 검증·촬영은 하지 않았습니다.

변경 내용

적용 내용

타입 표기는 int / int(unique), string / string(unique), Local.Element / Local.Element(unique)처럼 제공합니다. Id는 int(unique)로 정규화합니다. 같은 unique 열은 파싱된 타입 값으로 비교하므로 1과 01, true와 TRUE도 중복입니다. 일반 string은 대소문자를 구분합니다. 일반 Enum 게임 값의 반복은 허용하며 Enum(unique)에서만 금지합니다. Enum 정의 자체의 중복 이름·숫자는 항상 검사합니다. 각 진단은 Data!B3 = Data!B4처럼 상대 위치를 포함하고 기존 붉은 셀 경고·오류 목록으로 전달됩니다. CSV·XLSX 선언 저장과 기본 C# 타입은 유지합니다.

Unity는 -batchmode -nographics 및 Hidden으로 실행했습니다. 창 활성화·마우스·키보드·스크린샷 도구를 호출하지 않았습니다. 9개 언어 문서 본문은 갱신했지만 스크린샷 검사기는 기존 소스 해시 변경·촬영 대기로 미통과했습니다. 이미지 해시를 새 것으로 바꾸지 않았습니다.

남은 사항

실제 Unity 화면에서 붉은 경고 박스·팝업 선택·오류 목록의 배치를 확인하고 9개 언어 가이드의 관련 이미지를 재촬영해야 합니다. 사용자 화면 조작 금지에 따라 미실행입니다. 이 보고서에는 오래된 스크린샷을 새 결과처럼 첨부하지 않았습니다. 전역 교훈 검토: 웹사이트 링크만 전달한다는 최신 지침이 설치본·설정 저장소에 이미 반영되어 있어 중복 추가하지 않았습니다.
