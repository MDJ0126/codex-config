TurnRoom 이전의 DataTable 원본 대조 검증

검증 대기

DataTable UI 구현을 유지한 채 공통 창 계약에 연결했습니다. 기존 전체 회귀 결과가 원본과 일치합니다.

2026년 10월 29일 오후 11:56 KSTv1.0.0검토

작업 결과

WorkbookViewer는 공통 ToolWindow를 상속하며 기존 TryCloseDocument와 UI·아이콘·최소화 엔진을 어댑터로 사용합니다. 판매 작업 브랜치에 병합하지 않았습니다.

변경 내용

적용 내용

제품 폴더를 Assets/TurnRoom/DesignDataTable로 옮겼습니다. 공개 네임스페이스·어셈블리·기존 메뉴를 유지하고 최소화 목록의 창 계약만 일반화했습니다. 기존 TimeManager와 SceneTemplate 사용자 변경은 커밋에서 제외하고 원래 SHA-256을 보존했습니다.

검증

원본과 통합 복제본: 160개 묶음·성공 13,770개·동일한 7개 실패. 보정된 런타임 검증: 257개 통과. 기존 설치 업그레이드: GUID 1,353개 보존, 누락·변경 없음. C# diff 검사는 통과했습니다. 전체 Unity YAML의 기존 공백은 원본 보존을 위해 변경하지 않았습니다.

남은 사항

실제 최소화·복원 및 미저장 문서 UI 검증은 사용자가 화면 조작을 보류해 미실행입니다. 문서 9개 언어는 빌드했으나 기존 캡처와 소스 해시의 불일치가 남아 있습니다. 캡처 없이 해시를 갱신하지 않았습니다. 기존 회귀 검증 검토

작업 시간

  • 제안 시간: 60–100분. 공통 창 분리, Pixora 이전, 개별·동시 설치 및 필수 검증 기준.
  • 실제로 완료된 시간: 공통 작업: 2026-10-29T22:36:55+09:00 → 2026-10-30T00:00:26.005+09:00, 83분 30초. 구현·비GUI 검증·통합 브랜치 푸시·최종 문서 점검 기준 종료 시각입니다. UI 검증은 사용자 요청으로 보류했습니다. 중앙 보고서 생성·검사·공개 배포 확인은 별도로 진행합니다.
  • XERJ: 사용 — 기존 DataTable 최소화 목록을 XERJ로 검색하고 현재 소스와 대조했습니다. 광범위 색인의 frozen-mapping 오류 후 공통 7개·DataTable 234개·Pixora 34개 에디터 C# 소스를 독립 색인해 ToolWindow 통합 검색을 실행했습니다. 런타임·스타일·문서는 rg로 확인했으며 자동 watcher는 시작하지 않았습니다.
