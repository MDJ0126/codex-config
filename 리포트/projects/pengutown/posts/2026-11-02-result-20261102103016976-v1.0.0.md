## 작업 결과

**제안하는 월드 구성 — 아직 구현하지 않은 설계입니다.**

시작 해안 → 넓은 평탄 빙원과 펭귄 무리 → 경사 미끄럼 구간 → 절벽 다이빙과 수중 통로 → 크레바스 → 밤의 오로라 관찰 지점을 연결하는 구성이 적합합니다. 2×2km부터 확장하는 방안이며, 특정 판매 패키지의 검증된 맵 크기라는 뜻은 아닙니다.

육지 무리는 [Unity AI Navigation](https://docs.unity3d.com/Packages/com.unity.ai.navigation@2.0/manual/index.html)의 경로 탐색에 리더 추종·서로 벌어지기를 결합하고, 수영·비행에는 3D 군집 이동을 별도로 적용하는 방안을 제안합니다. 멀리 있는 무리에는 LOD와 갱신 빈도 조절이 필요하며 몇 마리까지 가능한지는 실측 전입니다.

현재 엔진을 유지하려면 [Unity 6.0 인접 Terrain](https://docs.unity3d.com/6000.0/Documentation/Manual/terrain-CreateNeighborTerrains.html)+CC0 눈 재질+별도 빙산 모델이 후보입니다. 고품질 8K 패키지를 선택한다면 먼저 별도 검증 브랜치에서 Unity 6.3와 URP/HDRP의 지형·수면·캐릭터를 대조해야 합니다.

## 검증

현재 ProjectVersion·GraphicsSettings를 직접 확인했습니다. Unity Asset Store의 최신 요구사항·호환표, Fab 판매자 본문, 날씨·오로라 공식 문서를 대조했습니다. 8K 패키지의 과거 6000.0 호환 행과 최신 v2의 6.3 요구사항을 구분했습니다. 판매자 성능 주장이나 넓은 지형 구성을 실제 프로젝트 성능으로 보고하지 않았습니다.

## 남은 사항

리소스 구매·다운로드·엔진 업그레이드·패키지 적용은 하지 않았습니다. 눈보라 가시거리·마찰·수면 부력·지형 스트리밍·군집 수는 적용 후 실측해야 합니다. HDRP 전환 시 Weather Maker를 그대로 사용할 수 없습니다.
