## 작업 결과

실녹음 사운드 후보 3종과 비행·액세서리·말풍선의 후속 구현 조건을 조사했습니다. 사운드 파일을 구매하거나 게임에 넣지는 않았습니다.

## 변경 내용

### 적용 내용

[A Sound Effect EULA](https://www.asoundeffect.com/license-agreement/)는 구매 음원을 게임 같은 다른 매체와 결합해 배포하는 사용을 허용하며 원본 음원 라이브러리 재배포는 제한합니다. [Free To Use Sounds EULA](https://www.freetousesounds.com/license-agreement)는 유료 Bandcamp 제품의 상업 게임 사용·평생 프로젝트 사용을 명시하지만 5인 초과 조직과 앱 개발 회사 등의 별도 문의 조항이 있으므로 해당 조건을 구매 전 대조해야 합니다. 무료 음원의 출처 표기 조건을 유료 제품에 혼동하지 않았습니다. 가격·세금·개별 제품 예외는 결제 전 재확인이 필요합니다.

실제 게임 사운드는 근접 개체 울음 / 멀리 있는 군집 웅성거림 / 눈 발걸음 / 배 미끄럼 마찰 / 입수·기포 / 수중음 / 바람을 분리하는 방안을 제안합니다. 울음마다 거리·대기시간·변형을 두고 군집 전체가 동시에 같은 소리를 내지 않도록 해야 합니다. 청음·루프 편집·게임 믹싱은 아직 실행하지 않았습니다.

추천 진행 순서는 리얼 펭귄 선정 → 빙하·수면의 시각 기준 확정 → 날씨·사운드 → 무리 행동 → 장비·말풍선 → 판타지 비행입니다.

## 검증

제작자·판매처의 녹음 수·종·가격·포맷과 공식 EULA를 확인했습니다. 기능 확장은 구현 결과와 구분해 제안으로 기록했습니다. 사운드 플레이어의 실제 청음 및 Unity 재생은 미실행입니다.

## 남은 사항

개별 음원 품질과 종별 울음을 직접 청음해 최종 선정해야 합니다. 비행·액세서리·말풍선은 이번 조사에서 구현하지 않았습니다. 교훈 검토: 종별 녹음과 모델 종을 일치시킬 필요는 프로젝트 상세에 기록했으며 일반 검증 규칙과 중복되는 전역 지침 추가는 없습니다.
