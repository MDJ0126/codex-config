넓은 빙하·오로라·눈보라·펭귄 군집 리소스

완료

고품질 빙하 최신 패키지는 Unity 6.3 URP/HDRP가 필요합니다. 현재 Unity 6.0 Built-in을 유지하는 경로도 함께 정리했습니다.

2026년 11월 2일 오후 7:30 KSTv1.0.0검토

작업 결과

빙하·눈 재질·날씨·오로라·군집 이동 후보와 현재 프로젝트의 호환 차이를 확인했습니다. 실제 지형과 날씨를 게임에 적용한 결과는 아닙니다.

적용 내용

현재 프로젝트는 Unity 6000.0.83f1, GraphicsSettings의 m_CustomRenderPipeline 값이 비어 있는 Built-in입니다.

용도 리소스·가격 확인 내용과 제한

빙산·틈새·얼음 아치 Low Poly + Realistic Glacier 16개 모델, 리얼 버전 978~5,786 tris·2K PBR, FBX/GLB. 제공 Unity 설정은 6.2+ 요구. 현재 버전 수동 임포트는 미검증입니다. 가격 미확인.
무료 눈 재질 ambientCG Snow013, 무료 사진 기반 PBR, 최대 8K. CC0. 완성 지형이 아니라 재질입니다.

오로라 별도 후보 Skybox Plus 공식 FAQ Unity 2022.3+ 및 Unity 6 지원, Aurora Intensity 제공. 현재 프로젝트의 실제 렌더링·가격은 미확인입니다.
오로라 직접 구현 참고 Roy Theunissen 기술 해설 Built-in의 raymarching 접근을 설명합니다. 무료 완제품 라이선스가 확인된 패키지로 소개하지 않습니다.
군집 이동 Swarm BOID/Fish/Bird Framework, $15/seat Unity 6000.0.24 Built-in, Jobs 기반 군집·웨이포인트. 경사진 육지 펭귄의 길찾기를 자동으로 해결하는 제품은 아닙니다.

제안하는 월드 구성 — 아직 구현하지 않은 설계입니다.

시작 해안 → 넓은 평탄 빙원과 펭귄 무리 → 경사 미끄럼 구간 → 절벽 다이빙과 수중 통로 → 크레바스 → 밤의 오로라 관찰 지점을 연결하는 구성이 적합합니다. 2×2km부터 확장하는 방안이며, 특정 판매 패키지의 검증된 맵 크기라는 뜻은 아닙니다.

육지 무리는 Unity AI Navigation의 경로 탐색에 리더 추종·서로 벌어지기를 결합하고, 수영·비행에는 3D 군집 이동을 별도로 적용하는 방안을 제안합니다. 멀리 있는 무리에는 LOD와 갱신 빈도 조절이 필요하며 몇 마리까지 가능한지는 실측 전입니다.

현재 엔진을 유지하려면 Unity 6.0 인접 Terrain+CC0 눈 재질+별도 빙산 모델이 후보입니다. 고품질 8K 패키지를 선택한다면 먼저 별도 검증 브랜치에서 Unity 6.3와 URP/HDRP의 지형·수면·캐릭터를 대조해야 합니다.

검증

현재 ProjectVersion·GraphicsSettings를 직접 확인했습니다. Unity Asset Store의 최신 요구사항·호환표, Fab 판매자 본문, 날씨·오로라 공식 문서를 대조했습니다. 8K 패키지의 과거 6000.0 호환 행과 최신 v2의 6.3 요구사항을 구분했습니다. 판매자 성능 주장이나 넓은 지형 구성을 실제 프로젝트 성능으로 보고하지 않았습니다.

남은 사항

리소스 구매·다운로드·엔진 업그레이드·패키지 적용은 하지 않았습니다. 눈보라 가시거리·마찰·수면 부력·지형 스트리밍·군집 수는 적용 후 실측해야 합니다. HDRP 전환 시 Weather Maker를 그대로 사용할 수 없습니다.
