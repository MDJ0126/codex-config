# 개발된 기능과 사용법

## 편집과 실행

- 진입 씬은 `OverdoxSplash`, `OverdoxLobby`, `OverdoxArena`입니다. 최신 고정 Windows 검증본은 `VerificationBuilds/Build20/Overdox.exe`이며 새 로비 맵 변경은 아직 포함되지 않았습니다.
- 로비 복원 메뉴는 `OVERDOX > Restore > Restore animated lobby map and camera transitions`입니다. Play를 중지하고 편집 중인 씬을 먼저 저장합니다. 도구는 프로젝트 소유 로비 파생 루트를 교체하므로 해당 루트의 수동 변경은 재실행 전에 보존합니다.
- Excel 계산 확인 메뉴는 `OVERDOX > Data > Verify Excel formula and DDT roundtrip`입니다. 메모리에서 수식을 변경해 기존 DDT 쓰기·읽기를 확인하고 XLSX 원본은 보존합니다.
- 정적 UI 위치·폰트·버튼 이벤트는 에디터에서 씬에 저장합니다. 런타임 코드에는 선택값·능력치·입력·전환처럼 동적으로 바뀌는 동작을 둡니다.

## 구현과 확인 범위

| 기능 | 확인한 범위 | 남은 범위 |
| --- | --- | --- |
| 로비·장비 UI | Build19 실제 Windows 선택·복귀·무기 변경 | 목록 스크롤, 미연결 메뉴, 원작 전체 배치 일치 |
| 전투 HUD·스틱 | Build20 실제 전투와 HP 변화·스틱 조작 | 미니맵, 버프, 결과 화면, 조작감 전체 일치 |
| 애니메이션 로비 맵 | 에디터 복원 로그 14개 뼈, 실제 Play에서 바닥 표시 | Windows 빌드, 왕복 카메라와 배경 재생 검증 진행 중 |
| Excel→DDT | 무기 10750의 계산값 120→132, DDT 재조회 132, 원본 불변 | 저장한 XLSX 변경부터 Windows 화면까지의 전체 연결 검증 |

원작 로비 셰이더 본문은 확보 자료에서 복구되지 않아 자체 셰이더로 대응했습니다. 맵과 텍스처가 원작 자산이라는 사실만으로 원작 재질 표현과 같다고 판정하지 않습니다. 10시간 검증은 이전 고정 빌드의 결과이며 새 UI·카메라 변경까지 검증한 결과가 아닙니다.
