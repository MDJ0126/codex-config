# OVERDOX 복원 프로젝트 지침

전역 지침은 [공통 지침](../../guide/global-instructions.html)을 따릅니다. 아래는 이 프로젝트에서 실제 검증한 자산·버전 조건입니다.

- 재현 프로젝트는 Unity6000.0.83f1, 원작 자료는 Unity2018.4.31f1입니다. 원작 파일은 보존하고 수정은 프로젝트 소유 어댑터·파생 에셋에 적용합니다. 원작 스크립트·서비스 연결을 재사용하지 않습니다.
- 공개 main81 OBB와 APK87의 MonoScript 경로 ID가 서로 다른 클래스로 해석되는 사례를 확인했습니다. 두 자료를 조합한 추출 결과의 MonoBehaviour 클래스 이름을 그대로 신뢰하지 않습니다. 사용한 표·모델·메타데이터 버전을 출처에 각각 기록하고 실제 필드·화면으로 대조합니다.
- 원작의 최적화된 SkinnedMeshRenderer는 뼈 목록이 비어 있을 수 있습니다. 원작 Avatar의 경로·포즈와 메시 bone hash를 대조하여 프로젝트 소유 리그를 구성합니다. 남녀 장비 모두 실제 렌더로 확인합니다.
- 원작 AnimationClip을 런타임에서 legacy로 복제하는 것만으로 실제 재생되지 않은 사례가 있습니다. 이 프로젝트에서는 에디터에서 AnimationUtility의 바인딩·커브·이벤트를 새 legacy 클립으로 옮겨 실제 전투 포즈를 확인했습니다. 원본 클립은 변경하지 않습니다.
- 원작 scene YAML을 확장자만 prefab으로 바꾸면 참조가 손상됩니다. 에디터에서 별도 씬으로 열고 PrefabUtility.SaveAsPrefabAsset으로 프로젝트 소유 프리팹을 저장합니다.
- 장시간 검증은 실행 파일과 전체 데이터 폴더를 고정 사본으로 분리합니다. 이후 빌드가 실행 중인 검증 사본을 덮어쓰지 않게 하고, 소스 수정 후 빌드 결과와 이전 장시간 검증 범위를 구분합니다.
- 장비 명령 실행 커버리지, 실제 명중, 원작 규칙 일치는 별개의 검증입니다. 무기38종·방어구81종의 참조 성공만으로 모든 능력과 서버 계산이 동일하다고 보고하지 않습니다.

근거: [2026-11-13 중간 결과](posts/2026-11-13-result-20261113044127119-v1.0.0.md)의 실제 실행 화면, EditMode XML 및 Blender 재열기 결과. 전체 완료 판정은 최종 검증 보고에서 별도로 수행합니다.
