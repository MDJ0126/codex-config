植被調色盤

Tools / TurnRoom / Pixora Studio / Foliage

儲存調色盤，選擇植物，再於地面繪製。

開始調色盤

按開始調色盤並於專案內儲存。儲存後顯示編輯區，取消則留在開始頁。安裝Samples後會加入五張植物卡。選取卡片並指定地面碰撞體，按使用所選地面，再啟用場景筆刷或填滿區域。新增植物會展開來源設定，請指定設定檔；沒有Samples時新增自己的設定檔。

混合已啟用項

權重表示相對頻率，不保證最終數量。先安排大植物再安排草；間距、坡度、表面與排除區域可能減少數量。單種繪製請關閉混合並選取一列。

邊界與排除區域

僅編輯此畫布。原植被區域須明確匯入才會修改。矩形與橢圓使用畫布局部XZ尺寸；點擊地面並按Enter完成多邊形。排除範圍採碰撞體的世界XZ包圍邊界。

儲存畫布場景

位置與圖層儲存在場景中，組合與筆刷設定儲存在Editor專用調色盤資產中。須分別儲存。每個完成筆劃對應一組復原，Esc取消目前筆劃。原生輸入須在編輯器驗證。

依調色盤重建畫布

使用目前調色盤取代此畫布全部植被。復原可還原原配置，其他畫布不變。

放置設定

每次筆刷蓋章最多新增512個實例；畫布預設上限20,000，最高可設100,000。間距或表面條件可能使數量低於目標。更多幾何會增加繪製成本，並非已測量的執行階段最佳化。

屬性

已驗證Unity Physics、復原/重做、儲存/重開與九語言更新。實際Scene拖曳及Windows Ctrl+Z/Ctrl+Y/Ctrl+S也已驗證。Alt/Shift細節、快顯鍵盤/取消、明暗與九語言完整版面待驗證。

拖曳繪製，Shift擦除，Alt操作攝影機，[ / ]調整大小，Esc取消目前筆劃並停止。
