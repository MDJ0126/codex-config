Palette de végétation

Tools / TurnRoom / Pixora Studio / Foliage

1. Choisissez une palette. 2. Créez un canevas sur le sol. 3. Activez le pinceau dans Scene.

Nouvelle palette

Choisissez MeadowMix, FlowerGarden ou WoodlandEdge dans Samples/Palettes, ou créez une palette. Sélectionnez un sol avec TerrainCollider ou MeshCollider et créez un canevas. Aucune scène ne s’ouvre automatiquement.

Mélanger les types actifs

Les poids sont des fréquences relatives, sans garantie de quantité. Les grandes plantes passent avant l’herbe ; espacement, pente et exclusions réduisent parfois le résultat. Désactivez le mélange pour un seul type.

Contour et exclusions

Seul le canevas est édité ; une parcelle existante nécessite une reprise explicite. Rectangle et ellipse utilisent XZ local. Tracez le polygone au clic puis Entrée. Les exclusions utilisent les limites XZ mondiales des colliders.

Enregistrer la scène

Positions et couches sont dans la scène ; types et réglages sont dans la palette réservée à l’Editor. Enregistrez les deux. Un trait terminé forme un groupe Annuler ; Échap annule le trait courant. Vérifiez les entrées natives séparément.

Reconstruire le canevas depuis la palette

Remplace toute la végétation de ce canevas. Annuler restaure la disposition ; les autres canevas restent inchangés.

Réglages de placement

Maximum512 plantes par tampon, limite initiale20,000 et maximum100,000. Espacement et surfaces invalides peuvent empêcher la densité cible. La géométrie augmente les coûts ; aucune optimisation mesurée n’est annoncée.

Propriétés

Implémentation, tests de distribution et compilation vérifiés. Souris, clavier, sauvegarde/réouverture et documentation visuelle nécessitent une validation séparée.

Glisser : peindre. Maj : effacer. Alt : caméra. [ / ] : taille. Échap : annuler le trait et arrêter.
