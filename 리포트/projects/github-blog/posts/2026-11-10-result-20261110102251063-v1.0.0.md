## 작업 결과

검색창을 데스크톱에서 310px에서 250px로, 좁은 화면에서 최대 156px로 줄였습니다. 모션 감소 설정에서는 즉시 전환합니다.

## 변경 내용

### 적용 내용

사용자는 탑바 축소 애니메이션과 더 작은 검색창, 원래 제목이 사라진 다음에 나타나는 작은 제목을 요청했습니다. 이전에는 탑바 축소와 작은 제목 표시가 동시에 시작됐습니다. 검색창의 너비와 안쪽 여백을 전환하고, 원래 제목의 아래쪽 경계와 탑바 아래쪽 경계를 비교하도록 변경했습니다.

```js
const headingHidden = articleHeading &&
  articleHeading.getBoundingClientRect().bottom <= utility.getBoundingClientRect().bottom;
page.toggleAttribute('data-reading-title', Boolean(scrolled && headingHidden));
```

## 검증

Chrome에서 데스크톱 검색창 너비 310px, 전환 중 약 271px, 전환 후 250px을 확인했습니다. 원래 제목이 보이는 상태에서는 작은 제목이 숨겨졌고, 더 내리면 나타났습니다. 빌드에서 게시물 154개와 이미지 참조 214개를 확인했습니다.
