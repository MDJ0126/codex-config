0.0.86 · VS2019~2026 대응과 VA 동기화 분석

0.0.86 · 두 작업 결과

1. Visual Studio 2019~최신 버전 대응

최신 정식 버전은 Visual Studio 2026 18.11.0 (2026-10-13)입니다. 실행 코드가 있는 확장은 2019와 2022의 SDK/비트수 차이를 고려해 별도 바이너리로 빌드했습니다. 설치 대상 범위만 늘린 동일 바이너리가 아닙니다.

대상 설치 파일 검증 상태
2019 CodeAssist.VS2019.vsix · SDK16.0 · x86 전체 소스 컴파일·별도 manifest·어셈블리 참조·패키지 6개 해시 통과. 실제 IDE 미설치로 설치/실행 미검증.
2022 CodeAssist.vsix · SDK17 · amd64 17.14.38 실험 인스턴스 설치, 실제 편집기14개 및 MVID 대조 통과.
2026 CodeAssist.vsix · SDK17 · amd64 Microsoft의 API17 호환 모델에 맞춘 [17.0,) 대상. 실제 IDE 미설치로 실행 미검증.

2019의 Shell.Task 이름 충돌과 32비트 HWnd 차이를 수정했습니다. 같은 소스를 SDK별로 빌드하며 중간 산출물은 분리합니다. ARM64 대상은 이번에 포함하지 않았습니다. 세 버전 모두 실사용 검증 완료 상태는 아닙니다.

2. VA 동기화 분석

108개 전체 기록을 현재 소스 경로/해시와 대조해 기능별 지원 범위와 다음 비교 항목을 정리했습니다. 전체 유사도는 아직 산정할 근거가 부족합니다. 이번 실제 실행은 현재 Core와 보존된 VA2630 관찰값의 비교이며 원본 프로그램을 이번에 다시 실행한 대조는 아닙니다.

  • 파일 검색 결과: 원본 관찰 10개 질의 중 10개 일치(이 사례 범위의 결과 일치율100%).

  • 심볼 집합: 원본19개와 현재19개가 이름·중복 개수까지 일치.

  • 현재 소스 회귀267개 통과, 실제 VS2022 편집기14개 통과. 테스트 수를 유사도로 환산하지 않습니다.

  • 전체108개: 부분 코드 대응108개, 모든 검증 기준을 통과한 전체 기능0개. 전체 유사도 미측정.

다음 수정 우선순위

  • 참조 검색·Rename·시그니처·필드 캡슐화의 전체 참조 갱신 및 Undo.

  • 자동 완성 Enter·템플릿·오버로드·취소·VS 기본 색상·양 테마.

  • 부동 빠른 작업·추가 검사기·AI/에이전트·GPU 전용 기능의 미지원 범위.

  • 범용 C/C++ 및 Unreal의 VA 대비 초기/증분 분석·타이핑·검색·CPU·메모리.

  • 실제2019·2026 IDE에서 기능 회귀 검증.
