## VA-F066 Print in Color

different — 양쪽의 실제 인쇄 명령으로 Microsoft Print to PDF 출력을 만들고 PDF를 렌더링·분석했습니다. 두 프로그램 모두 색상 출력은 작동하지만 VA는 키워드 파랑·주석 초록·메서드 적갈색과 파일명/행 번호를 출력했고, CA는 키워드·주석 검정·클래스 노랑·메서드 주황이며 머리말/행 번호가 없습니다. 실제 사용자 전경 창과 입력 데스크톱은 유지되었습니다. 선택 영역의 문맥 제한까지 인증한 것은 아닙니다.

- VA 실행 증거·해시

- CA 실행 증거·해시
