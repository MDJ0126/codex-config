# VA·CA 반복 검증 지속 목표

VA와 CA의 UI 레이아웃·디자인·기능·실제 단축키 동작을 반복 비교하고, 발견한 차이를 수정한 뒤 재검증하여 검증된 일치율을 100%에 최대한 가깝게 높입니다.

- Computer Use 연결을 복구하고, 검사 프로필에 최신 보관 CA를 적용한 후 설치 버전과 바이너리 일치를 확인합니다.
- 동일한 입력·프로젝트·화면 크기·테마 조건에서 VA와 CA를 직접 실행 대조하고 화면·버퍼·커서·선택·Undo 등 적절한 근거를 수집합니다.
- 발견한 차이를 수정하고 같은 시나리오와 관련 회귀 항목을 다시 검사합니다.
- UI 레이아웃, 기능 대표 결과, 실제 단축키 검증을 구분하여 일치 개수/검사 개수와 백분율을 기록합니다.
- 실패·미판정·미실행·양쪽 무반응·실행기 정상 종료를 기능 통과로 계산하지 않습니다.
- 기존 기록과 이번 실제 실행, 대표 시나리오 일치와 기능 전체 인증을 구분합니다.
- 남은 차이와 검증 근거를 유지하며, 미완료 상태를 완료로 보고하지 않습니다.

사용자 추가 지시: 2026-10-22 (Asia/Seoul). 현재 대화의 활성 지속 목표에 적용되는 보완 기준입니다.
