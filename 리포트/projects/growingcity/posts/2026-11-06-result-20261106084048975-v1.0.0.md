## 작업 결과

건물 하나로 시작해 인접 구역으로 자동 성장하고, 클릭한 곳을 폭파해 점수를 얻으며 빈자리를 자동 재건하는 첫 시제품 코드를 작성했습니다. 전용 씬은 Assets/Scenes/City Prototype.unity입니다. 실제 게임 화면·브라우저 동작은 아직 검증하지 않았습니다.

## 변경 내용

### 적용 내용

- 자동 성장: 약 1.15초 간격, 주택에서 중층·고층 에셋까지 단계적으로 등장. 구역 테두리의 도로를 공유합니다.\n- 등장 효과: 약 0.65초의 커졌다가 안착하는 애니메이션.\n- 카메라: 살아 있는 건물·외곽을 투영해 부드럽게 확대·축소. 가운데만 비고 외곽이 남으면 전체 시야는 유지합니다.\n- 파괴: 일반 폭탄과 핵폭탄, 건물 단위 붕괴, 상한이 있는 물리 잔해·충격파·버섯구름 연출·합성 타격음. 실제 구조 파괴 물리와는 구분합니다.\n- 점수: 건물 등급과 동시 파괴 수로 계산하며 같은 폐허에는 중복 지급하지 않습니다.\n- 재건: 약 4.5초 뒤부터 빈자리를 우선 복구. 전멸해도 복구하며 점수는 유지합니다.\n- UI: 씬에 편집 가능한 Canvas·Text·Button 25개 GameObject와 5개 Inspector 이벤트. 1/2 무기 선택, Space 일시정지, 1배/3배, 초기화. UI 런타임 생성 코드 없음.\n- Core·Runtime·Editor 어셈블리 분리. 웹 빌드 메뉴를 추가했으며 기존 Build Settings 씬 목록은 보존합니다.\n- 외부 에셋 원본을 수정하지 않고 생성된 인스턴스에만 필요한 머테리얼 대체를 적용합니다.
