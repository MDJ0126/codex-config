## 작업 결과

최종 파괴 시 +획득량 G가 건물 위치에서 HUD로 떠올라 이동하고, 총 골드가 차오르며 짧은 획득음을 재생하도록 연결했습니다. 체력은100→150→225이고 피해가 누적되면 작은 건물로 퇴화합니다. 피격 빨강·흔들림·건물 폭발과 카메라 셰이크도 적용했습니다.

## 변경 내용

### 적용 내용

- 기본 체력100, 진화 단계마다×1.5. 일반 폭탄60·핵150 피해이며 Inspector에서 조절합니다. 남은 체력이 이전 단계의 최대 체력 이하가 되면 실제 조합 전신으로 퇴화합니다. 예: 상위225에60씩 피해 →165 유지 →105 아파트 →45 주택 →최종 파괴. 강한 피해로 체력이0이면 즉시 최종 파괴할 수 있습니다.
- 퇴화 시 남은 체력과 원래 보상 가치를 보존합니다. 점유는4→2→1칸으로 줄고 비워진 구역은 회복 지연 후 재건합니다. 피해를 받은 건물은 즉시 재조합해 체력을 채울 수 없도록 했습니다.
- 최종 파괴 때만 기존 누적 점수를 GOLD로 지급합니다. 피격·퇴화에는 골드가 없고 잔해 중복 보상도 없습니다. 진화 건물을 퇴화시켜도 원래 진화 등급의 보상 가치는 최종 파괴까지 유지됩니다.
- 6개 골드 보상 Text와 어두운 Outline은 씬에 폰트·색·크기·초기 위치를 직접 저장했습니다. 코드는 +획득량·HUD 이동·일시적 확대·투명도·숫자 카운트만 갱신합니다. 총 GOLD 라벨도 씬에 저장했으며 런타임 UI 생성·폰트 대입은 없습니다.
- 피격 시 인스턴스 MaterialPropertyBlock을 붉게 바꾸고0.28초 동안 모델을 흔든 뒤 원래 색/프로퍼티 블록·위치·회전으로 복원합니다. 외부 원본 재질은 변경하지 않습니다.
- 최종 파괴와 퇴화 시 불꽃·먼지·회전 파편을 추가했고 건물 전용 효과는 동시에8개로 제한했습니다. 일반 피격·퇴화·파괴·핵 순으로 카메라 충격을 구분했습니다. 기존 폭격 사운드에 짧은 골드 획득음을 추가했습니다.

## 검증

독립83개 시나리오 통과: 기존64개와 신규19개(100/150/225 체력, 다중 칸 중복 피해 방지, 비치명 피해 무보상, 두 단계 퇴화와 점유 축소, 발전도 감소, 원래 보상 보존, 최종 단일 지급, 잔해 중복 지급 방지, 재건, 강한 비치명 피해의 다단계 퇴화, 피해 건물 즉시 재진화 방지, 정확한0 체력, 잘못된 피해 거부,250회 피해/성장 불변식).
설치된 Unity6000.0.83f1 실제 참조 어셈블리 대상으로 Runtime·Editor C# 컴파일 통과. 씬155개 오브젝트·319개 로컬 참조·96개 외부 참조·5개 버튼 이벤트, 골드 Text6개·Outline6개·GOLD 라벨·피해값60/150·기존 UI 배치 보존을 정적으로 확인했습니다. 영문 Text19개와 한글 라벨 글리프 검사 통과. 외부 원본5840개 파일 해시 변경0건입니다.
기존 폭격 QA는 전체 RectTransform 목록이 같아야 한다는 조건 때문에 새 HUD6개 추가에서 실패했습니다. 기존 UI의 좌표와 순서는 계속 대조하고, 명시된 새 골드 Text/Canvas 자식 참조만 허용하도록 QA 범위를 갱신한 뒤 재검사 통과했습니다. Outline도 실제 설치 패키지의 GUID를 확인해 참조 검사 대상에 추가했습니다. 변경 근거는 QA/Combat/qa-adjustment.json에 기록했습니다.
컴퓨터 유즈·GUI 실행·Play·전후 캡처는 사용자 조건으로 미실행입니다. 실제 화면을 촬영하지 못했으므로 가짜 화면으로 대체하지 않았습니다.
교훈 검토: 기존 UI 직접 저장·원본 보존·검증 범위 구분 규칙으로 충분하여 전역 지침 변경 없음.

실제 Play의 HUD 가독성·골드 획득 이동·카운트·효과음, 피격 빨간색과 원상복구·건물 흔들림·폭발·퇴화 전환·카메라 셰이크 체감, 프레임 성능·씬 재열기·웹 실행·전후 화면은 미검증입니다. 실제 화면 검증으로 보고하지 않습니다. 별도 체력 바·자동 회복은 추가하지 않았습니다.
