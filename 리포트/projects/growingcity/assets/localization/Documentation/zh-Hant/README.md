# GrowingCity 原型

[English](../en/README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [Deutsch](../de/README.md) · [Français](../fr/README.md) · [Español](../es/README.md) · [Português](../pt/README.md)

轟炸自動成長的城市。相鄰建築會合併升級，被摧毀的區域會重建。

使用 Unity 6000.0.83f1 / URP 17.0.4 開啟 Assets/Scenes/City Prototype.unity。目前為 Unity 原型，瀏覽器執行尚未驗證。

在城市上拖曳並放開即可依方向派出編隊。飛機從螢幕外飛入並飛出。1：炸彈，2：核轟炸，Space：暫停/繼續，Esc：取消拖曳。

每架飛機初始每秒投彈1發。可升級投彈速度、載彈量、範圍、火力、編隊數量、速度、裝甲和生命值，下次出擊生效。城市成長不再需要手動購買升級。

城市按遊戲時間自動加速成長：初始1倍，60秒2倍，420秒達到上限8倍，HUD顯示目前倍率。僅3級及以上建築發射飛彈。每12次建造出現一種特殊建築：黃色燃料庫、紅色彈藥庫或青色發電站。摧毀後造成周圍額外傷害，可引發其他特殊建築連鎖爆炸。連鎖金幣統一結算一次，並減少發展度、留下可重建廢墟。

每架飛機抵達固定增加50%普通出擊充能。兩架提供一次機會，多餘次數可保留。普通自然充能需要10秒遊戲時間，最多補充一次。

核轟炸有獨立的100秒冷卻。有效命令被接受時開始，包括排隊命令，初始即可使用。不消耗普通出擊次數。抵達獎勵和3倍速不會縮短冷卻。暫停時停止計時，新城市會重設。

建築發射隨等級增強的有限追蹤飛彈。飛機會受傷或被擊落。升級建築生命值更高，受傷後可能降級。摧毀獲得金幣並降低城市發展度。

首次執行預設跟隨系統語言。語言按鈕循環切換系統及9種語言，手動選擇會儲存在本機。不支援的系統語言回復為英語。
