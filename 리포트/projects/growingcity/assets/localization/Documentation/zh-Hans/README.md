# GrowingCity 原型

[English](../en/README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [Deutsch](../de/README.md) · [Français](../fr/README.md) · [Español](../es/README.md) · [Português](../pt/README.md)

轰炸自动成长的城市。相邻建筑会合并升级，被摧毁的区域会重建。

使用 Unity 6000.0.83f1 / URP 17.0.4 打开 Assets/Scenes/City Prototype.unity。当前为 Unity 原型，浏览器运行尚未验证。

在城市上拖动并松开即可按该方向派出编队。飞机从屏幕外飞入并飞出。1：炸弹，2：核轰炸，Space：暂停/继续，Esc：取消拖动。

每架飞机初始每秒投弹1发。可升级投弹速度、载弹量、爆炸范围、火力、编队数量、飞行速度、装甲及生命值。城市成长升级可加快新建筑生成。升级适用于下一次出击或新建筑。

每架飞机抵达固定增加50%普通出击充能。两架提供一次机会，多余次数可保留。普通自然充能需要10秒游戏时间，最多补充一次。

核轰炸有独立的100秒冷却。有效命令被接受时开始，包括排队命令，初始即可使用。不消耗普通出击次数。抵达奖励和3倍速不会缩短冷却。暂停时停止计时，新城市会重置。

建筑发射随等级增强的有限追踪导弹。飞机会受伤或被击落。升级建筑生命值更高，受伤后可能降级。摧毁获得金币并降低城市发展度。

首次运行默认跟随系统语言。语言按钮循环切换系统及9种语言，手动选择会保存在本机。不支持的系统语言回退为英语。
