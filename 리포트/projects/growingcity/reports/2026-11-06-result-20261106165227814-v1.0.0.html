성성장하는 도시작업 결과

초당 투하·V자 편대·대공 미사일과 고정50% 연속 출격

검증 대기

기체당 기본1발/초, V자 편대, 건물 대공 미사일과 기체 생존 강화를 구현했습니다. 도착1대당 고정50% 출격분을 누적하며 독립161개 검사는 통과했습니다. 실제 Play는 미검증입니다.

2026년 11월 7일 오전 1:52 KSTv1.0.0작업 결과

작업 결과

폭격 속도와 V자 기체 추가, 넓은 기본 반경, 건물 단계별 제한 추적 미사일을 연결했습니다. 기체는 체력·방어력·속도와 격추 처리를 갖고, 도착한 기체마다 고정50%를 회복해 두 대당 한 번 더 출격할 수 있습니다. 준비 상태의 도착 보상도 남겨 연속 사용합니다.

변경 내용

적용 내용

  • 기본 투하는 기체당1발/게임초(1배속 기준)입니다. DROP RATE는350G부터, 단계당0.5발/초를 추가해 최대6발/초입니다. 기존 폭탄 수 강화는 BOMB CAPACITY로 유지하며 탄약 상한을 늘립니다. 실제 투하 수는 통과 시간·속도·투하율·탄약 상한으로 결정됩니다. 기체가 빨라지면 통과가 짧아지며 투하 간격은 유지됩니다.
  • ADD AIRCRAFT는800G부터 한 대씩 추가합니다. 선두→왼쪽1→오른쪽1→왼쪽2→오른쪽2 순으로 V자 편대를 늘리며 최대7대입니다. 각 기체가 자기 위치에서 폭격하고 격추된 기체는 이후 투하를 중단합니다. 이미 떨어진 폭탄은 계속 착탄합니다. 기본 일반 반경은1.05→1.5칸, 핵은2.65→3.5칸으로 넓혔고 기존 범위 강화도 적용합니다.
  • 기체 기본 체력100, 속도 강화450G부터 단계당+12%, 방어력500G부터 단계당+15, 체력550G부터 단계당+25입니다. 각각 최대10단계입니다. 방어는 피해×100/(100+방어력), 체력 소진 시 피격 색·폭발·회전 추락과 투하 중단을 연결했습니다. 속도/체력/방어와 기존 공격 수치는 출격 시 고정합니다.
  • 모든 건물은 단계에 맞는 대공 미사일을 발사합니다. 단계1/2/3 피해12/18/27, 속도2.5/3/3.5칸/초, 폭발 반경0.25/0.375/0.5칸입니다. 추적은1.2초, 선회는35도/초로 제한하고 이후 마지막 목표 지점으로 향합니다. 최대 수명6초이며 연속 구간 충돌과 공중 범위 피해를 적용합니다. 자동으로 끝까지 따라붙거나 순간 회전하지 않습니다.
  • 최신 사용자 지시에 따라 고정50% 출격 회복입니다. 한 대 도착마다0.5회분, 두 대면 즉시1회분, 네 대면2회분을 누적합니다. 전원 생존 조건이나 남은 시간 절반/기본 시간 영구 절반 방식은 사용하지 않습니다. 기체별 도착은 한 번만 인정하고 격추 기체는 도착하지 않습니다. 기본 자연 재충전10초는1회분까지만 채우며 도착 보상은 준비된 상태에서도 누적합니다.
  • 연속 사용 요청은 사용권을 소비해 순서대로 보존합니다. 동시 표시 기체42대·미사일24개를 유지하고 추가 출격 요청은 대기열에 남깁니다. 전투 효과/잔해의 기존 제한도 유지합니다. NEW CITY는 강화·체력·사용권·미사일·대기열을 초기화합니다.
  • 투하율/기체 추가/속도/방어/체력 버튼5개,42개 체력 바와 출격 게이지/상태를 씬에 직접 저장했습니다. 글꼴·색·배치·버튼 이벤트는 편집 가능한 네이티브 오브젝트이고 코드는 값과 동적 표시만 갱신합니다. UI 생성·폰트 대입은 없습니다. 기존2D 드래그 표시선도 유지합니다.

검증

독립161개 시나리오 통과: 기존127개와 신규34개. 기본1초 간격, 향상된 투하율, 속도와 투하율 분리, 단발 통과, 마지막 착탄 후 정리, V자 대칭/확장/7개 고유 위치, 새 강화 비용·잔액 부족·상한·초기화, 방어 피해 감소·체력 소진·도착 단일 인정·탈출 후 면역, 고정50%·두 대1회·네 대2회·여분 보관·자연 충전 상한, 미사일 단계별 피해/속도/반경·선회 상한·정해진 속도·추적 종료·수명·연속 충돌 거리를 확인했습니다. 설치된 Unity6000.0.83f1 실제 참조 대상으로 Runtime·Editor 컴파일 통과. 씬632개 오브젝트·1398개 로컬 참조·240개 외부 참조·14개 버튼 이벤트를 검사했습니다. 새 구매 버튼5개·체력 바42개·출격 게이지·반경1.5/3.5와10초 충전을 직렬화된 씬으로 확인했습니다. 영문 Text38개62종 글리프 누락0, 외부 원본5840개 파일 해시 변경0건입니다. 체력/출격 바는 별도 스프라이트 없이 사용할 수 있는 Simple Image의 가로 길이를 동적 상태로 갱신합니다. 설치된 UGUI Image.cs의 activeSprite==null 분기를 확인해 Filled 설정에만 의존하지 않았습니다. 기존 2D 표시선·구매·방향 비행 소스 연결 검사도 통과했습니다. 컴퓨터 유즈·Unity 실행/Play·씬 재열기·전후 캡처는 사용자 조건으로 미실행입니다. 독립 모델 검사를 실제 공중전·추적·화면·성능 검증으로 보고하지 않으며 가짜 화면을 만들지 않았습니다. 교훈 검토: 사용자 정정인 고정50% 누적을 프로젝트 규칙과 보고에 반영했습니다. 전역에는 기존 검증·UI 저장·원본 보존 규칙으로 충분하여 변경 없음.

남은 사항

실제 Unity Play에서 공중전·회피/난이도·격추·도착 판정·연속 출격 타이밍·대기열·건물 발사 위치·폭발 범위·HP/게이지 가독성·성능·씬 재열기·웹 실행·전후 화면은 미검증입니다. 기체는 다음 출격 때 보유 강화의 최대 체력으로 새로 준비됩니다. 실제 전투 밸런스 검증은 별도입니다.
