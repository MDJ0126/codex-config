성성장하는 도시작업 결과

드래그 경로를 따라 비행기가 순차 폭격

검증 대기

원클릭 공격을 드래그 경로 지정과 항공기 순차 폭격으로 바꿨습니다. 경로 예고·낙하·착탄을 기존 파괴와 점수에 연결했으며 독립64개 검사는 통과했습니다. 실제 Play는 미검증입니다.

2026년 11월 6일 오후 10:40 KSTv1.0.0작업 결과

작업 결과

도시 위에서 드래그한 직선이 예고선으로 표시되고, 손을 떼면 비행기가 진입해 경로에 폭탄을 순차 투하합니다. 폭탄이 지면에 도달할 때 파괴·붕괴·점수·발전도 감소가 발생합니다. 짧은 클릭은 공격하지 않습니다.

변경 내용

적용 내용

  • 마우스·기본 터치의 누름/이동/해제를 처리하고 드래그 중 카메라 이동을 멈춰 지면 경로가 흔들리지 않게 했습니다. ESC·포커스 이탈·일시정지·UI 위 또는 화면 밖 해제는 취소합니다.
  • 기존 에셋의 plane-passenger 프리팹을 씬에 직접 연결하고 런타임 인스턴스에만 크기·방향·재질 보정을 적용합니다. 원본은 수정하지 않았습니다.
  • 비행 시간표와 투하 위치를 순수 C# AirstrikePlan으로 분리했습니다. 정상 폭격은 경로 길이에 따라 최대24발, 핵은 더 넓은 간격으로 최대8발입니다. 비행2대·경로32칸으로 제한하고 프리뷰에도 같은 제한을 적용합니다.
  • 폭탄은 비행기가 목표 위를 통과할 때 나타나0.42초 후 착탄합니다. 정지와 배속을 공유하며 마지막 착탄 후 비행·폭탄 오브젝트를 정리합니다. NEW CITY도 진행 중 비행을 정리합니다.
  • 프리뷰는 건물에 가려지지 않는 프로젝트 소유 URP 셰이더·머테리얼을 사용합니다. 기존 도움말 Text는 씬의 DRAG TO BOMB 문구로 수정했으며 UI 폰트·배치 변경과 UI 생성 코드는 없습니다.
  • 여러 폭탄이 같은 프레임에 착탄하면 도로 메시 재계산을 프레임당 한 번으로 모읍니다.

검증

설치된 Unity6000.0.83f1의 실제 참조 어셈블리 대상으로 Runtime·Editor C# 컴파일 통과. 독립64개 시나리오 통과: 기존51개와 신규13개(클릭/짧은 경로/잘못된 수치 거부, 양끝점·역방향·대각선, 순차 시간표·진입 후 투하, 길이/개수 제한, 핵 간격, 마지막 착탄 후 정리, 경로 구역 파괴·먼 건물 보존·파괴 점수). 씬125개 오브젝트·253개 로컬 참조·78개 외부 참조·5개 버튼 이벤트 검사를 통과했습니다. 비행기 루트 참조·프리뷰 재질/셰이더 참조·정적 도움말·기존 UI RectTransform 유지·원클릭 Detonate 호출 제거를 소스와 저장된 씬으로 확인했습니다. 영문 폰트 실제 글리프 검사 누락0, 외부 원본5840개 파일 해시 변경0건입니다. 컴퓨터 유즈·GUI 실행·Play·전후 캡처는 사용자 조건에 따라 미실행입니다. 실제 비행 화면을 직접 캡처하지 못했으므로 가짜 화면으로 대체하지 않았습니다. 교훈 검토: 기존의 UI 직접 저장·원본 보존·화면 비간섭 규칙으로 충분하여 전역 지침 변경 없음.

남은 사항

실제 마우스/터치 입력, 비행기 전방 축·크기·가시성, 폭탄 낙하와 착탄 타이밍의 체감, 프리뷰 셰이더 컴파일과 렌더링, 실제 프레임 성능·씬 재열기·전후 화면·웹 실행은 미검증입니다. 독립 시간표 검사를 실제 Unity Play 통합 검증으로 보고하지 않습니다.
