성성장하는 도시작업 결과

드래그 방향으로 화면 밖 통과 비행과 폭격기·도시 성장 레벨

검증 대기

드래그 길이 대신 방향으로 화면을 통과하는 진입·폭격·이탈 경로를 연결했습니다. 폭격기 피해 레벨과 도시 성장 속도/새 건물 가치 레벨을 추가했고 독립122개 검사는 통과했습니다.

2026년 11월 7일 오전 12:37 KSTv1.0.0작업 결과

작업 결과

드래그는 비행 방향을 정하며, 비행기는 화면 바깥 진입점에서 폭격 구간을 지나 반대편 바깥 이탈점으로 이동하도록 구현했습니다. 폭격기 레벨은 피해를20%, 도시 성장 레벨은 생성 속도20%·새 건물 골드/발전 가치10%씩 높입니다.

변경 내용

적용 내용

  • 드래그 방향의 직선을 현재 화면 크기에 맞춰 확장하고 Unity 카메라 프러스텀으로 폭격 구간을 자릅니다. 실제 비행 고도의 투영 경로를 화면 정규 좌표로 옮겨 경계 바깥 여유 지점까지 늘립니다. 비행기 등급에 따라 여유를 넓히고 진입→폭격→이탈의 세 구간으로 이동합니다.
  • 드래그 길이에 묶이던32칸 제한을 방향 비행에서 해제했습니다. 폭탄 수의 기존 상한 일반24+강화·핵8+강화는 유지합니다. 프리뷰도 확장한 방향 구간을 표시하며 화면을 통과하지 않는 방향은 출격을 취소하고 안내합니다.
  • 비행 중 도시 자동 프레이밍을 잠시 유지하고 셰이크는 계속 적용합니다. 비행이 끝나면 성장·축소 추적을 재개하며 이전 구도 이동 속도가 남지 않게 초기화합니다.
  • UPGRADE BOMBER: 첫600G, 레벨당 피해+20%, 최대10레벨의3배 피해입니다. 출격 시 피해 수치를 고정하고 모델 크기도 단계당2.5% 키웁니다. 기존 범위·폭탄 수 강화는 유지합니다.
  • CITY GROWTH: 첫500G, 레벨당 생성 속도+20%·새 건물 골드와 발전 가치+10%, 최대10레벨에서 생성3배·새 가치2배입니다. 기존 건물의 가치를 소급해 바꾸지 않고 새로 생성/진화하는 건물에 적용합니다. 현재 대기 중인 다음 생성 시각도 앞당깁니다.
  • 두 강화는 각각 가격 상승·골드 차감·레벨/가격 표시·부족/상한 비활성화를 지원합니다. NEW CITY는 네 강화와 골드를 초기화합니다. 왼쪽 아래 두 버튼·정적 라벨·폰트·배치·Inspector 이벤트는 씬에 직접 저장했으며 UI 생성/재구성·런타임 폰트 대입은 없습니다.
