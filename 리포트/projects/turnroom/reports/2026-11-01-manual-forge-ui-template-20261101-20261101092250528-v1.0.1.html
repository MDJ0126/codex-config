남은 작업과 다음 반복

사용자께서 게임 종료 후 진행을 선택하셨으므로 화면 전환·신규 GUI 실행·재시작을 보류했습니다. 실제 Unity의 마우스·키보드 선택값·취소·라이트/다크·좁은 폭과 최종 캡처, 스크린샷 교체·현재 해시 등록은 미완료입니다. Unity 대상 캡처에 전면 게임이 나타났으므로 이를 제품 증거로 저장·게시하지 않았습니다. 자동 UI 이벤트 QA는 도메인 재로드 후 유틸리티 창 참조가 없어 실패했으며 통과 처리하지 않았습니다. 공통 변경의 다른 제품 실제 화면 회귀도 남아 있습니다. 교훈은 프로젝트 지침에 공통 Apply·선택 패널·패키징 검사·로고 슬롯 사용 규칙으로 통합했습니다. 전역 지침은 새 중복 규칙 없이 유지합니다.
