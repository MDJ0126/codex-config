검증 대기

제품·공통 명령·개발 도구로 TurnRoom 메뉴를 통합하고 중복 진입점과 문서 경로를 정리했습니다.

2026년 11월 1일 오후 11:03 KSTv1.0.0수정사항

작업 결과

소스 메뉴 정리와 관련15개 어셈블리 컴파일을 마쳤습니다. 실제 Unity 메뉴의 현재 화면·클릭 검증은 기존 화면 조작 제한으로 보류입니다.

변경 내용

적용 내용

TurnRoom 아래 Design Data Table, Pixora, Pixel Camera, Entity Forge를 먼저 등록하고 Settings·Windows·Install Product Package...·Development 순서로 우선순위를 정리했습니다. 실제 Unity의 렌더 순서·구분선은 별도 QA 대상입니다.

Tools/TurnRoom과 Window에 흩어진 중복 별칭11개를 제거했습니다. Pixora Ctrl+Shift+F5~F11은 새 경로에 보존했고 샘플 재생성과 검증 도구는 Development의 제품별 하위 메뉴로 이동했습니다. Pixel Camera·Entity Forge의 Documentation 항목을 추가했습니다. Asset 생성·컨텍스트 메뉴는 별도로 유지합니다.

9개 언어의 Pixora 안내 원본과 공통 메뉴 안내·현재 경로를 갱신했습니다. 메뉴 구조는 텍스트 설명이며 실제 실행 화면을 대체하는 이미지가 아닙니다.

검증

현재 등록51개, 수정36개 파일, 중복 별칭11개 제거, 단축키7개 보존, 기존 실행 본문과URP 검증 쌍 보존을 실제 원본과 현재 파일로 대조했습니다. 실제 설치 Unity6000.0.83f1의 Roslyn·참조 어셈블리로 제품·샘플·개발·URP15개 어셈블리를 컴파일했고 모두 exitCode0입니다.

공통9개 언어 문서와 제품36개 연결, UXML10개 이름 및 이전 캡처5개 매니페스트 보존 검사를 통과했습니다. BuildLocalizedDocs.py와 VerifyLocalizedDocs.py를 실행했으며 전체 가이드 검사는57개 이미지에서 현재 소스 불일치·기존 재캡처 대기479건으로 미통과입니다. 이를 현재 메뉴 실행 검증으로 취급하지 않았습니다.

파일5개에서 매핑 구역 열림으로 잘라쓰기 실패를 확인했습니다. 일부 쓰기를 성공으로 처리하지 않고 동일 볼륨 원자 교체 후 준비 원본과해시·실행 본문을 재대조했습니다. 프로세스를 종료·재시작하지 않았습니다.

검증 요약

남은 사항

현재 Unity 메뉴 순서·구분선·클릭·단축키·현재 화면 캡처는 보류. 전체 문서 검사479건의 불일치·재캡처 대기를 보존했습니다. 교훈 검토: 전역 지침 변경 없음. 프로젝트별 파일 매핑 오류와 검증한 원자 교체는 MenuLayout.md에 기록했습니다. 실제 화면 캡처는 기존 화면 조작 제한으로 미실행이므로 첨부하지 않았습니다. 사용자 제공 이전 메뉴 이미지를 수정 후 화면으로 사용하지 않았습니다.
