공통 창의 고DPI·다중 모니터·연결 변경 검증 범위

논의 중

복원 위치 수정과 실제 창 확인은 완료됐습니다. 공통 창을 여러 제품이 쓰는 만큼 고DPI·모니터 연결 변경의 지원·검증 기준을 정합니다.

2026년 10월 30일 오후 5:00 KSTv1.0.0QA 토론

토론 내용

기존 화면 밖 복원 결함은 실제 세 창에서 수정·검증된 기록이 있으므로 다시 열린 버그로 만들지 않습니다. 다만 물리 모니터 연결 변경과 다른 배율은 별도 범위로 남아 있어, 공통 기반의 대표 환경을 정해 두면 두 제품의 중복 검증을 줄일 수 있습니다.

QA 근거와 맥락

검토 방식: 보존된 글의 본문·제한·후속 기록을 대조했습니다. 제품 실행·재현·수정 검증을 새로 수행한 것이 아닙니다.

최소화 목록에서 복원한 창이 화면 밖에 남는 문제 수정

다른 운영체제·고DPI·물리적 모니터 연결/분리 동작 자체는 미확인입니다.

제안 및 대안

  1. 단일 모니터·서로 다른 배율의 두 모니터·음수 좌표를 대표 조합으로 정합니다.
  2. 최소화·복원·최대화·도메인 재로드와 연결 변경 전후의 위치·포커스·미저장 상태를 구분해 기록합니다.
  3. 공통 기반은 함께 검증하고 제품별 저장·입력은 각 제품 QA로 분리합니다.

결정과 후속 작업

아직 결정되지 않았습니다.

우선 지원할 OS·배율·모니터 조합과 실제 장치 변경 시 사용자 작업에 방해되지 않는 시험 일정을 정해야 합니다. 이번에 화면 배율이나 모니터를 조작하지 않았습니다.

작업 시간

  • 제안 시간: 전체 기존 글 검토·필요 논의 등록 20~35분의 공통 작업입니다.
  • 실제로 완료된 시간: 논의 글 작성 2026-10-30 17:00:04 KST. 개별 제품 구현·QA 완료 시각이 아니며 전체 검토 시간은 별도 결과 보고서에 기록합니다.
  • XERJ: 미사용 — 문서와 후속 보고서 대조 작업으로 제품 코드 검색 불필요
