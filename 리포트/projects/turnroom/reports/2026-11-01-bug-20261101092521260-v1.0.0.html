Entity Forge 기본 선택창 누락과 제목·라벨 배치 수정

접수

공통 필드 적용 시 선택 패널을 자동 연결하고 기본 명령 메뉴 직접 호출을 교체했습니다. 실제 화면 최종 QA는 게임 종료 후 대기입니다.

작업 결과

코드 수정·컴파일·정책 검사·문서 링크 검사 완료; 실제 입력·캡처 미완료

변경 내용

재현 조건

Unity 6000.0.83f1 / Windows / Entity Forge / UI Toolkit 공통 Templete

재현 순서

Entity Forge 창에서 제목·빌드 옵션·Paired player evidence 필드를 확인하고, 선택기 또는 Find command를 엽니다. 첨부 화면과 현재 소스 경로를 대조했습니다. 실제 최종 입력 재현은 게임 종료 후 대기입니다.

기대 동작

제품 선택·명령 패널은 공통 디자인과 소유 테마를 따르고 제목·긴 라벨이 겹치거나 생략되지 않아야 합니다.

실제 동작

사용자 첨부 화면에서 제목 겹침·긴 라벨 생략이 나타났습니다. 소스에서 직접 ObjectField에 공통 picker 바인딩이 없는 경로와 GenericDropdownMenu 직접 호출을 확인했습니다. 수정 후 실제 최종 팝업 화면과 물리 입력은 아직 미검증입니다.

원인

미확인

적용 내용

확인한 원인: ForgeWindow의 직접 생성 ObjectField는 기존 SerializedField의 공통 picker 연결을 거치지 않았고, UITemplate.CommandSearch는 GenericDropdownMenu를 직접 생성했습니다. 로고 크기의 brand 슬롯에 제품명 Label을 넣어 제목이 겹쳤으며 공통 필드의 고정 라벨 폭이 긴 문구를 생략했습니다.

수정: UITemplate.Apply 단계에서 ObjectField·ColorField·DropdownField·EnumField를 필드당 한 번 자동 연결합니다. 명령 검색과 제품 오류 안내는 공통 패널을 사용하며 소유 테마를 상속합니다. 로고 슬롯은 넘침을 가리고 제품명은 문서 제목에 배치합니다. 긴 옵션·에셋 라벨에는 공통 가독성 배치를 적용했습니다.

정적 UI를 편집 가능한 ForgeWindow.uxml/.uss와 TemplateSelectionPanel.uxml/.uss로 분리했습니다. 제품 패키징에 TemplatePickerPolicy.ValidateProduct를 연결해 명시된 기본 팝업 호출 패턴을 거부합니다. 별칭 등 모든 C# 구문을 분석하는 검사는 아닙니다. 기존 창·다른 제품 씬은 조작하지 않았습니다.

검증

공통 7개와 Entity Forge 4개 어셈블리 컴파일 통과 기록. 최종 공통 소스의 별도 재컴파일도 통과했습니다. 실제 TemplatePickerPolicy C#를 .NET에서 실행해 EntityForge 제품 소스 허용 및 직접 호출 10개 거부를 확인했습니다. UXML 파싱·이름 중복·C# 조회 이름 대조 통과. 9개 언어 문서·171개 로컬 링크 통과.

검증 요약

남은 사항

사용자께서 게임 종료 후 진행을 선택하셨으므로 화면 전환·신규 GUI 실행·재시작을 보류했습니다. 실제 Unity의 마우스·키보드 선택값·취소·라이트/다크·좁은 폭과 최종 캡처, 스크린샷 교체·현재 해시 등록은 미완료입니다. Unity 대상 캡처에 전면 게임이 나타났으므로 이를 제품 증거로 저장·게시하지 않았습니다. 자동 UI 이벤트 QA는 도메인 재로드 후 유틸리티 창 참조가 없어 실패했으며 통과 처리하지 않았습니다. 공통 변경의 다른 제품 실제 화면 회귀도 남아 있습니다. 교훈은 프로젝트 지침에 공통 Apply·선택 패널·패키징 검사·로고 슬롯 사용 규칙으로 통합했습니다. 전역 지침은 새 중복 규칙 없이 유지합니다.
