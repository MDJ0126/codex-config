변경 내용

적용 내용

최대화·원래 크기 복원에서 캡처·창 숨김·이미지 표면 생성·약 0.30초 뒤 표시하던 WorkbookWindowMotion.ToggleMaximize를 삭제했습니다. 공통 호스트, DataTable 최대화 버튼·제목줄 더블클릭·목록 명령은 WorkbookNativeWindow.Execute에서 잔여 복원 표면을 정리한 뒤 기존 ExecuteImmediate로 실제 창을 직접 전환합니다. 최소화 목록 복원 애니메이션은 보존했습니다. standalone 템플릿의 기존 직접 전환은 유지합니다.

검증

현재 소스와 해시가 일치하는 3개 어셈블리 컴파일 통과. 실제 Execute 메서드 본문을 컴파일해 최대화는 잔여 모션 정리 후 직접 호출, 최소화·잘못된 명령은 기존 분기 유지라는 3개 사례를 실행했습니다. 네이티브 호출은 stub이므로 실제 창 크기·프레임 지연 검증이 아닙니다. 최소화 목록 Restore 메서드가 수정 전과 동일함을 대조했습니다. 9개 언어의 안내 반영 검사 통과.

OS 자체 창 전환 설정은 변경하지 않았습니다. 실제 전·후 화면은 미확보이며 가짜 화면으로 대체하지 않았습니다. 전체 가이드 검증에는 오래된 캡처/소스 불일치 등 0개 오류가 남아 있습니다. 교훈 검토: 최대화는 캡처 기반 지연 전환을 사용하지 않는다는 제품 공통 동작 설명을 갱신했습니다. 전역 규칙 추가 없음.
