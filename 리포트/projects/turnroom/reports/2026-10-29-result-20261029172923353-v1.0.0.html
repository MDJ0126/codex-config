DataTable 기준 공통 UI 템플릿을 두 제품에 적용

검증 대기

제목줄·탭·리본·글자·아이콘을 하나의 템플릿 에셋으로 통합했습니다. 기존 DataTable 기본 스타일 대조와 실시간 갱신 등 78개 실행 검증을 통과했으며 실제 화면 비교는 보류 상태입니다.

2026년 10월 30일 오전 2:29 KSTv1.0.0수정사항

작업 결과

구현·독립 컴파일·비GUI 실행 검증·프로젝트 푸시를 완료했습니다. Tools > TurnRoom > UI Template에서 공통 에셋을 편집하면 열린 DataTable과 Pixora 창에 반영됩니다. 실제 운영체제 창의 시각 검증은 사용자 요청에 따라 보류했습니다.

변경 내용

적용 내용

기존 DataTable의 제목줄 34, 탭 30, 리본 91, 본문 글자 12, 리본 글자 11, 리본 아이콘 26, 빠른 실행 아이콘 18을 공통 기본값으로 지정했습니다. 서로 달랐던 Pixora 크기를 이 기준에 연결했습니다.

Common에 DefaultUITemplate.asset, 공통 UI Toolkit 부품 생성 함수, IMGUI 치수 API와 변경 알림을 추가했습니다. 열린 패널은 연결 동안만 변경을 구독하며 분리 시 해제합니다. DataTable의 기존 IMGUI 엔진은 유지하고 같은 에셋을 읽도록 연결했습니다.

라이트·다크 팔레트와 선택 가능한 공통 강조색을 한 곳에서 관리합니다. 강조색 덮어쓰기를 끄면 기존 제품·문서 색상을 유지합니다. 기존 창 목록·최소화·제품별 상태 계약을 유지했습니다. 문서 셀 글꼴과 제품별 콘텐츠 구성은 공통 창 템플릿의 범위와 구분합니다.

README, 공통 확장 안내, Pixora 개발 문서와 9개 언어 오프라인 가이드를 갱신했습니다. 제품별 패키지는 같은 Common GUID와 기본 템플릿을 포함하도록 기존 내보내기 구조를 유지합니다.

코드 변경 커밋

검증

Unity 6000.0.83f1의 숨겨진 배치 프로젝트에서 실제 UI Toolkit Panel.ValidateLayout을 실행해 78개 검증을 통과했습니다. 검증용 스타일 초기화는 배치 환경에서만 수행했습니다.

Pixora 라이트·다크의 실제 레이아웃 치수, 창 폭 960·1280·1600의 제목줄·최대화·닫기 버튼 경계, 기존 DataTable 수식줄과 그리드 시작 위치, 공통 에셋 실제 로딩을 확인했습니다.

변경 전 커밋 a8b46988836e313cdda19f8cf3d6825b37bb3fce의 원본 스타일을 같은 GUISkin으로 실행했습니다. 기본/대화상자 각각 7개 스타일의 치수·간격과 8개 상태의 글자색·배경 텍스처 전체 픽셀 배열을 대조했습니다. 기본값의 일치를 확인했습니다. 운영체제 화면 픽셀 비교를 의미하지 않습니다.

템플릿을 변경해 Pixora 제목줄·탭·리본·본문과 DataTable 글자·그리드 위치·보조 창 강조색이 함께 갱신되고 기본값으로 복원되는 것을 확인했습니다. 제품 전용 USS 없이 공통 부품을 구성하는 테스트와 패널 분리도 통과했습니다.

각 제품과 Common만 있는 별도 프로젝트에서 단독 컴파일을 모두 통과했습니다. Pixora 9개 가이드·54개 장·54개 코드 예제의 언어 이동 검사, 개발 문서 10개 장·5개 이미지 링크 검사와 Git 공백 검사를 통과했습니다. 이번 작업에서 DataTable 전체 데이터 처리 회귀 테스트를 다시 실행하지는 않았습니다.

남은 사항
