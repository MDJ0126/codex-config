작업 결과

공통 템플릿 제품 개발 체크리스트

작성일: 2026-11-01 (Asia/Seoul)

제품을 계속 추가할 때 재사용할 공통 템플릿의 작업 목록입니다. 새 제품을 시작하거나 공통 UI를 변경하기 전에 이 목록과 기존 템플릿 가이드 Docs/Development/TempleteGallery.md를 확인합니다.

이 문서는 요구사항과 검토 후보를 기록합니다. 체크되지 않은 항목은 구현 부재를 뜻하지 않으며, 현재 구현·검증 상태는 별도 확인이 필요합니다. 이번 기록 요청은 아래 기능 전체의 구현 지시가 아닙니다.

사용자 지정 필수 항목

  • 다큐먼트: 설치, 시작하기, 기능별 사용법, 확장 방법, 문제 해결을 정리합니다. 실제 UI와 안내를 대조하고, 지원하는 9개 언어의 설명·스크린샷 갱신 규칙을 따릅니다.
  • 샘플 씬 10개: 기능별 예제와 조합 예제를 구성합니다. 각 씬의 목적, 실행 절차, 기대 결과를 기록합니다. 구체적인 10개 주제는 추후 확정합니다.
  • 디자인 팝업 상속·공통 사용: 공통 부모, 호출 API, 입력·결과·취소 계약과 제품별 확장 방법을 정리하고 실제 제품 적용을 검증합니다.

추가 검토 후보

아래 항목은 대화에서 제안한 후보이며 개별 채택·우선순위는 미확정입니다.

  • 공통 윈도우 구조: 타이틀바, 툴바, 사이드바, 상태바, 창 수명 관리
  • 공통 UI 컨트롤: 입력창, 드롭다운, 슬라이더, 벡터, 색상·에셋 선택기
  • 디자인 시스템: 여백, 높이, 글꼴, 아이콘, 강조색, 라이트·다크 모드
  • 공통 상호작용: 마우스·키보드 선택, 포커스, 단축키, 드래그 앤 드롭
  • 설정·상태 저장과 복구: 사용자 설정, 창 상태, 미저장 변경 안내, 복구 흐름
  • 다국어 지원: 기본 영어, 번역 키 관리, 긴 문구의 레이아웃 검증
  • 안내·오류 처리: 툴팁, 빈 화면, 로딩, 진행률, 오류·확인 메시지
  • 확장용 기본 골격: 새 창·팝업·컨트롤을 추가하는 최소 코드와 예제
  • 패키지·배포 구성: 의존성, 지원 Unity 버전, 개발 도구 제외, 설치·업데이트 검증
  • 공통 회귀 QA: 실제 Unity에서 테마, 배율, 다중 창, 재시작, 입력값 반영 검증

제품 추가 시 사용 방법

  1. 필수 항목과 채택한 후보의 기존 구현·문서·실행 결과를 확인합니다.
  2. 제품 고유 기능과 공통 템플릿의 책임을 정하고 중복 구현을 피합니다.
  3. 실행 메뉴얼에 구현·제품 적용·문서 갱신·QA를 구분해 등록합니다.
  4. 실제 실행과 회귀 QA 근거가 확보된 범위만 완료 표시하고 관련 보고서를 연결합니다.

기록 검증

  • 원래 목록의 필수 3개와 추가 후보 10개를 보존했습니다.
  • 기능 구현 여부와 샘플 씬의 세부 주제는 이번 문서 기록 작업에서 검증하지 않았습니다.
  • 문서만 추가하므로 프로그램 실행 화면 캡처 대상은 없습니다.
  • XERJ: 미사용 — 코드 검색 불필요
  • 교훈 검토: 전역 지침 변경 없음. 지속 사용할 프로젝트 체크리스트와 참조 경로만 기록합니다.
