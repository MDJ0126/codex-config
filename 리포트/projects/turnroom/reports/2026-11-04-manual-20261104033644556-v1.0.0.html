목표와 완료 기준

큰 Inspector 버튼 선택 메뉴를 공통 검색 목록으로 교체하고 독립 제품 창을 Windows Alt+Tab 대상으로 등록한다.

공통 선택 경로 적용·관련 제품 컴파일·검색/선택/취소/테마/창 전환 회귀 검증·문서와 결과 공개. 제어 중단 동안 실제 UI QA는 보류로 유지한다.
