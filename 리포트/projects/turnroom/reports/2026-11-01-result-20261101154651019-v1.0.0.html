배포 주소 입력 제거 · Asset Store 제품별 업데이트 직접 확인

검증 대기

배포 목록 주소 입력·요청을 제거하고 제품별 Unity Asset Store 공개 페이지의 버전을 직접 확인하도록 변경했습니다.

2026년 11월 2일 오전 12:46 KSTv1.0.0수정사항

작업 결과

Templete1.7.1에 주소 없는 Store 업데이트 확인을 구현했습니다. 현재 확인된 등록 ID만 조회하며 Templete는 제품과 함께 제공, ID가 없는 제품은 등록 정보 없음으로 표시합니다. 이전4개 제품·영상 작업은 일시정지 상태를 유지합니다.

변경 내용

적용 내용

배포 목록 URL 입력란·해당 설정 읽기/쓰기·기본 별도 서버 주소·JSON 목록 요청을 제거했습니다. 제품 Version.json의 assetStoreId로 공개 Store 페이지를 순차 조회합니다. 현재 확인된 ID는 Design Data Table263724이며 다른 제품은 임의의 검색 결과나 ID를 연결하지 않았습니다.

공개 페이지의 canonical URL이 요청 제품 ID와 일치하는지 확인하고 관찰한 Next.js 데이터에서 유효한 latestVersion만 수집합니다. UI 번역 문자열인 Latest version을 버전으로 읽지 않으며 서로 다른 버전이 섞이면 확인 불가로 처리합니다. 네트워크 오류·로그인·누락·형식 변경 때 이전 성공을 버립니다. 오류 화면에 내부 주소나 원문 응답을 표시하지 않습니다. 자동 설치·Store 로그인·심사 제출은 하지 않습니다.

9개 언어 UI와 공통 가이드를 갱신했습니다. 영어 기본과 독립 주석·게임 데이터 언어는 유지했습니다.

검증

현재 소스9개 어셈블리를 실제 Unity6000.0.83f1 참조로 정적 컴파일했고 전부 통과했습니다. 실제 C# 파서·비교기·제품별 조회 코드를 격리 Unity 어댑터와 .NET에서 실행해98개 검사를 통과했습니다. 실제로 받은 Unity 공식 UPM Publishing Tools 제품5368745의 공개 페이지에서0.3.3을 추출했고 잘못된 제품·로그인·모호한 버전·오류·대용량·중복 요청·종료·SemVer 순서를 검사했습니다.

실제 Unity JsonUtility와 가져온 UXML에서도 버전 파싱·주소 입력란 제거·비동기 조회 종료·오류 시 빈 버전·씬/선택/포커스 보존을 검증했습니다. Design Data Table의 공개 버전은 이 환경에서 검증하지 못했으며 확인 불가 상태로 처리됐습니다. 이는 해당 제품이 최신이라는 판정이 아닙니다.

9개 공통 문서·36개 제품 연결과 UXML9개 이름 검사를 통과했습니다. 창을 활성화하지 않는 PrintWindow 캡처는 실패하여 새 이미지를 만들지 못했습니다. 사용자 제공 수정 전 이미지를 수정 후 화면으로 게시하지 않았고 기존 캡처 해시는 보존했습니다.

검증 요약

남은 사항

Store ID가 확인되지 않은3개 제품은 등록 ID를 확정한 뒤 조회할 수 있습니다. Store 사이트 형식·공개 접근이 바뀌면 확인 불가로 처리되며 공개 버전을 추측하지 않습니다. 실제 화면 캡처·물리 입력·전체 언어 배치 검증은 미완료입니다. 자동 컴파일 설정·마우스/키보드·창 활성화·GUI 신규 실행을 하지 않았습니다. 교훈 검토: 전역 지침 변경 없음. 실제 응답을 검증하는 기존 원칙으로 처리했습니다.
