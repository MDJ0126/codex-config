## 작업 결과

창을 처음 열 때와 언어 설정을 바꿀 때 같은 번역을 사용하도록 수정했습니다.

## 변경 내용

### 적용 내용

- 창을 열 때 고정 영어 제목 대신 전역 설정의 번역값을 사용합니다. 열린 창에서 언어 변경 이벤트가 발생하면 두 제목을 함께 갱신합니다.
- 대화 (시각 미기록): 사용자는 Alt+Tab에서 영어, 실제 창 안에서 한글이 보이는 두 화면을 제시하고 제목을 맞춰 달라고 요청했습니다.

## 검증

두 제목이 같은 Caption 값을 사용하고 기존 언어 변경 구독을 통해 함께 갱신되는 경로를 확인했습니다. Unity 6 참조 소스에서 titleContent가 독립 창의 제목으로 전달되는 조건을 확인했습니다.

## 남은 사항

수정 후 Unity 실제 Alt+Tab 화면과 열린 창에서 언어 전환은 미확인입니다. 전역 지침에 추가할 공통 교훈은 없었습니다.
