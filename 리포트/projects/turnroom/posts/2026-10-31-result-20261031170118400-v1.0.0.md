## 작업 결과

새 제품을 만들 때 해당 제품의 로고를 반드시 제작하고 적용·검증하도록 기록했습니다. 실제 Affinity의 편집 가능한 원본과 출력물을 제품 폴더에 보관하며 로고 누락 상태로 제품 전체 작업을 완료 처리하지 않습니다.

## 변경 내용

### 적용 내용

Docs/Development/TempleteRoadmap.md의 사용자 지정 필수 항목과 AGENTS.md에 로고 의무를 추가했습니다. 필수 항목은 4개, 추가 검토 후보는 10개입니다.

## 검증

두 문서의 추가 문구를 직접 확인하고 git diff --check를 실행했습니다. 기존 13개 항목을 보존했습니다. 문서 수정 요청이므로 로고 제작이나 UI 실행 검증은 수행 대상이 아닙니다. 실행 화면은 없습니다. 교훈 검토: 새 제품 로고 누락 방지 요구는 프로젝트 지침과 체크리스트에 반영했으며 기존 전역 Affinity 규칙은 유지했습니다.

## 남은 사항

후속 새 제품 작업에서 로고 제작·적용·검증을 실행합니다. 이번 요청은 해당 의무의 문서 기록입니다.
