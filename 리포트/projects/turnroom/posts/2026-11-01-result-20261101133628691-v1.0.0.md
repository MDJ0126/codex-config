## 작업 결과

구현과 정적/격리 실행 검증을 마쳤습니다. TurnRoom > Settings 및 제품의 전역 설정 버튼에서 언어와 제품 버전·업데이트 상태를 관리합니다. 실제 Unity 팝업 조작과 최신 화면 캡처는 기존 화면 조작 제한으로 실행하지 않았으므로 전체 UI 검증 완료가 아닙니다.

## 변경 내용

### 적용 내용

Templete 1.7.0의 공통 팝업과 UXML/USS를 추가했습니다. Data Table·Pixora 표시 언어를 공통 EditorPrefs로 연결하고 기존 설정은 공유 값이 없는 첫 접근에만 이전합니다. 다른 에디터의 변경은0.5초 간격으로 관찰합니다. 소스 주석·게임 데이터·런타임 예제 언어는 별도입니다. 번역이 없는 기존 영어 문구를 자동 번역하지 않습니다.

5개 제품의 Version.json을 읽고 HTTPS 배포 JSON을 SemVer로 비교합니다. 미설치·버전 누락·미확인·조회 실패·동일·더 새로운 설치본·업데이트 가능을 구분하고 조회 실패·주소 변경 뒤 과거 성공을 재사용하지 않습니다. 자동 설치는 하지 않습니다. Data Table2.0.2·Pixora1.0.0 메타데이터는 기존 제출 원고에 근거하며 공개 판매 버전이라는 뜻이 아닙니다.

[공개 배포 목록](https://mdj0126.github.io/codex-config/assets/updates/turnroom.json)은 확인된 공개 릴리스만 등록합니다. 현재 등록된 릴리스가 없어 제품 상태는 공개 버전 정보 없음입니다. 후보 버전을 최신 공개 버전으로 만들지 않았습니다.

## 검증

Unity6000.0.83f1의 설치된 실제 Roslyn 참조로 공통·제품·개발용9개 어셈블리를 현재 소스에서 컴파일했습니다. 공통 서비스의 실제 C#을 격리 Unity API 어댑터와 함께 .NET에서 실행해200개 검사를 통과했습니다. 언어 왕복·중복 알림·외부 저장값 변경·잘못된 입력·리스너 오류 격리, SemVer 순서, 잘못된/중복 목록·HTTPS·오프라인·대용량·주소 변경·종료 시 요청 정리를 포함합니다. 이는 native Unity 입력·레지스트리 동기화·UnityWebRequest 실행의 증명이 아닙니다.

9개 공통 가이드와36개 제품 가이드 연결, UXML 바인딩 이름10개 및 기존 캡처5개 매니페스트 보존을 검사했습니다. BuildLocalizedDocs.py와 VerifyLocalizedDocs.py를 실행했습니다. 전체 가이드 검사는57개 사용 이미지에서 기존 소스 불일치·재캡처 대기479건으로 실패했으며 통과로 처리하지 않았습니다.
