## 변경 내용

### 적용 내용

삭제 전 남은 미추적 메타 파일 8개가 TurnRoom에 동일한 SHA-256으로 복사되어 있는지 확인했습니다. 이전 Git 전체 이력을 WorkFiles/Backups/Pixora-BeforeRemoval-20261030.bundle로 보존하고 git bundle verify를 통과했습니다. 이전 폴더의 내용을 삭제한 후 빈 루트 디렉터리 잠금을 추가 조사했습니다. ChatGPT 프로세스의 해당 경로 디렉터리 핸들 3개를 확인해 경로 재검증 후 해제했으며 응용프로그램 전체를 종료하지 않고 폴더를 삭제했습니다.

## 검증

디렉터리 핸들의 최종 경로가 C:/Projects/Pixora와 정확히 일치함을 확인했습니다. 삭제 후 Test-Path C:/Projects/Pixora=False, 현재 Assets/TurnRoom/Pixora=True, 이전 Git bundle=True를 확인했습니다. 현재 프로젝트의 Packages JSON에는 이전 Pixora 경로 참조가 없었습니다. 제품 코드·에셋은 변경하지 않았습니다.

## 남은 사항

이 폴더 삭제 작업에 남은 사항은 없습니다. 이전 작업에서 보류한 실제 Unity UI 검증은 그대로입니다. Git 이력 백업은 로컬의 Git 제외 폴더에 보관했습니다.
