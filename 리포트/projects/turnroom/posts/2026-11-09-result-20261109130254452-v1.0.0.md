## 작업 결과

옵션을 끄면 기존 리스트에 숨은 창을 표시하고 새 최소화는 Windows 기본 동작을 사용합니다.

## 변경 내용

### 적용 내용

- 전역 설정에 9개 언어의 최소화 리스트 사용 토글을 추가했습니다.
- 대화 (시각 미기록): 사용자는 “최소화 리스트 사용 여부를 글로벌 옵션에 추가해줘 당연히 기본값은 True”라고 요청했습니다. AI는 기본 켜짐과 비활성 시 Windows 최소화를 연결했습니다.

## 검증

EditorPrefs 기본값 true, 토글 바인딩, 호스트·비호스트 분기와 기존 창 표시 흐름을 소스로 확인했습니다. UXML 파싱과 9개 문서 섹션을 확인했습니다.

## 남은 사항

Unity에서 실제 토글·작업 표시줄 복원·기존 창 복원과 화면 캡처는 미확인입니다. 전역 지침에 추가할 검증된 공통 교훈은 없었습니다.

## 작업 시간

- 제안 시간: 구현 및 코드 확인 3~5분
- 실제로 완료된 시간: 21:59:27 KST 시작, 22:02:19 KST에 코드와 설정 UXML 및 문서 정적 확인 (2분 52초).
- XERJ: 미사용 — 코드 검색 근거가 제공되지 않았습니다.
