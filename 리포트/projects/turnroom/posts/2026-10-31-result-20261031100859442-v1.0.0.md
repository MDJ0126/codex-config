TurnRoom-IconSource-20261030-1749, TurnRoom-IconWork-20261031 두 바탕화면 폴더는 삭제해도 됩니다. 원본 3개를 프로젝트 ArtSources/Templete/DesktopIconArchive-20261031 아래에 보존했습니다. 실제 삭제는 하지 않았습니다.

## 변경 내용

### 적용 내용

현재 사용 중인 RibbonAtlas PNG 두 개와 바탕화면 PNG의 SHA-256이 달랐으므로 단순 중복으로 간주하지 않았습니다. 바탕화면 자료를 폴더 이름 그대로 프로젝트 안에 별도 복사했습니다. SVG v3도 함께 보존하여 이후 재편집 시 복원할 수 있습니다.

## 검증

파일 3개 전체 SHA-256이 바탕화면 원본과 보존 사본에서 일치했습니다. RibbonAtlas.png 91201바이트, RibbonAtlasWhite.png 85129바이트, TurnRoom-Icons-Color-v3.svg 37822바이트입니다. verification.json에 파일별 해시와 결과를 기록했습니다. 파일 보존·대조 작업으로 프로그램 화면 변경이 없어 실행 화면을 억지로 첨부하지 않았습니다.

## 남은 사항

바탕화면 폴더는 사용자가 삭제할 수 있도록 남겨 두었습니다. 보존 사본은 로컬 프로젝트 내부에 있으며 이번 확인에서 Git 커밋·원격 업로드는 하지 않았습니다. 교훈 검토: 프로젝트 내부에 원본을 보존한다는 기존 전역 지침으로 충분하여 규칙을 중복 추가하지 않았습니다.
