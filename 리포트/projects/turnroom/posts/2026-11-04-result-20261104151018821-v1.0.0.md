## 변경 내용

### 적용 내용

Tools/Documentation/ProductGuide.mjs와 ProductGuideTemplate.html이 DDT 기준을 공유합니다. 패키지 안에 동일 CSS·글꼴·라이선스를 넣어 다른 제품 설치에 의존하지 않습니다. 확인된 제품명·실제 로고/파비콘·번역된 개요/빠른 시작·개요의 실제 이미지1장이 없으면 생성기가 거부합니다.

Templete/Documentation/ProductGuideExample.<언어>.html9개를 실제 DDT 내용·캡처로 생성했습니다. 이 페이지는 DDT를 보여주는 템플릿 예제이며 Templete나 새 제품의 공식 로고를 뜻하지 않습니다. 예제의 로고·이미지를 새 제품에 그대로 물려주지 않도록 작성 기준을 명시했습니다.

AGENTS.md, ProductDocumentation.md, TempleteGallery.md, TempleteRoadmap.md에 DDT 스타일·9언어·공통 첫 항목·고유 로고/파비콘·독립 배포 자산·실제 브라우저 QA 규칙을 반영했습니다. 이전 미사용 어두운 템플릿은 Tools에서 제거하고 QA 기록으로 보존했습니다.

## 검증

Pixora Studio9개·Entity Forge9개·템플릿 예제9개, 총27개 HTML의 실제 생성 JS를 최소 DOM 어댑터에서 실행했습니다. 전체 장/제품 이동·활성 목차·언어 변경과 로고/파비콘/예제 이미지 경로를 검사했습니다. 각 패키지 guide.css는 DDT 원본과 바이트가 같고 Inter/Pretendard 글꼴·라이선스도 동일 해시입니다. 이는 브라우저 시각 검증이 아닙니다.

글꼴과 기존 로고/캡처는 복사·연결만 했으며 재그리기·이미지 편집을 하지 않았습니다. 기존 Affinity 이미지 원본은 보존합니다.

실제 브라우저 화면·작은 화면·마우스/키보드·탭 파비콘 표시와 후 캡처는 미실행입니다. 기존 화면 조작 중단 및 file URL 브라우저 보안 정책 거부를 유지했고 우회·다른 브라우저·서버 실행을 하지 않았습니다. 열린 문서의 실제 표시를 갱신했다고 보고하지 않습니다. 확인하려면 기존 문서 탭 새로고침이 필요합니다. ScreenshotManifest의 촬영 시각·소스 해시는 바꾸지 않았습니다.

## 남은 사항

실제 브라우저의 공통 디자인·탭 아이콘·작은 화면 검증이 남아 있습니다. 변경된 AGENTS는 프로젝트 파일에 반영한 것이며 실행 중 다른 대화가 자동으로 읽었다고 주장하지 않습니다. 전역 로고 규칙은 사용자 최신 지침에 이미 있어 중복 추가하지 않았습니다.
