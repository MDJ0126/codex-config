Pixora Studio 제품 통합 — 모듈 창·식별자 보존

검증 대기

기존 세 모듈 창을 그대로 여는 공통 메뉴와 통합 패키지를 적용했습니다. 정적 검사·패키지 대조 통과, 실제 Unity 화면 검증은 보류입니다.

2026년 11월 4일 오전 12:11 KSTv1.0.0수정사항

작업 결과

제품 통합 구현과 정적 검사를 완료했습니다. 새 통합 편집창 없이 기존 Image Studio·Pixel Camera·Foliage 창을 각각 엽니다. 미구현 기능·실제 화면 검증·판매 페이지는 이후 순서입니다.

변경 내용

적용 내용

  • 기존 overview를 Pixora Studio로 변경하고 공통 메뉴 아래 세 모듈 진입 명령과 설치 여부 validator를 추가했습니다.
  • 기존 메뉴·클래스·assembly·폴더·GUID·설정 키를 유지했습니다.
  • primary SKU를 PixoraStudio로 설정하고 기존 review 출력 폴더를 재사용했습니다. 기존 Unity exporter에도 통합 출력을 추가했습니다.
  • 모듈별 창과 테마, 공유 언어 설정을 유지하고 overview 문구를9언어로 갱신했습니다.
  • 개발 코드·작업 데이터·exports 제외 정책을 review 패키지에도 반영했습니다.
  • 교훈 검토: 전역 지침 변경 없음. 기존 구조 재사용 원칙과 같은 내용이며, 독립 창 유지라는 제품별 확정은 PixoraStudio.md에 기록했습니다.

검증

  • 6개 어셈블리 정적 컴파일 통과. 기존 Unity exporter도 별도 정적 컴파일 통과.
  • 기존 에셋·의존성·다국어12검사 통과.
  • 3개 메뉴 대상·validator·기존 entry point·overview GUID/assembly 대조 통과. 단축키가 붙은 메뉴와 기존 dirty 변경을 가정한 최초 검사 실패 후 검사 범위를 수정해 재실행했습니다.
  • 통합 검토 패키지: 2644개 에셋, 42379566바이트. 실제 archive와 현재 소스·meta의 SHA256 전부 대조 통과.
  • 사용자의 화면 조작 금지를 유지했습니다. GUI 프로세스를 실행하지 않았고 현재 메뉴·화면 캡처와 native import/Play는 미실행입니다. 정적 검사를 실제 실행 검증으로 표시하지 않았습니다.

남은 사항

다음 순서: 미구현 기능 구현 → 실제 검증·예제·GIF → 로고·문서·Unity 판매 페이지 초안 수정. 실제 UI 선택·9언어 레이아웃·새 설치·공식 validator는 미검증입니다. 판매 페이지를 수정하거나 제출한 상태가 아닙니다. 전체 제품 출시 완료가 아닙니다.
