Pixora Studio 단일 문서·세 모듈 내부 카테고리 통합

검증 대기

Documentation 하나에서 Image Maker·Pixel Camera·Foliage를 전환하도록 9개 언어 가이드를 통합했습니다.

2026년 11월 4일 오후 11:24 KSTv1.0.0수정사항

작업 결과

통합 뷰어와 단일 메뉴를 구현했습니다. 생성된 JS의 카테고리·언어 전환 및 실제 Unity 메뉴 등록을 확인했고 브라우저 화면은 미검증입니다.

변경 내용

적용 내용

Tools/TurnRoom/Pixora Studio/Documentation 단일 메뉴가 StudioGuide.<언어>.html을 엽니다. 내부 왼쪽 카테고리 Image Maker·Pixel Camera·Foliage를 전환하고 오른쪽에서 기존 모듈별 목차와 내용을 읽습니다. 기존9언어 문서를 임베드해 내용·이미지·스크립트와 개별 가이드를 보존했습니다. 문서 외부 탭3개를 여는 구조가 아닙니다. 언어를 바꿔도 선택 카테고리를 유지합니다.

Tools/Pixora/BuildStudioGuide.mjs가 생성하며 기존 Image Maker 다국어 빌더에도 통합했습니다. Camera/Foliage가 없는 개별 설치는 원래 Image Maker 문서로 폴백합니다.

검증

9언어×3카테고리의 실제 생성된 JS를 최소 DOM 어댑터에서 실행해 전환·활성 표시·언어 변경·잘못된 hash 복귀를 검사했습니다. 임베드된 모듈 JS도 문법 검사를 통과했습니다. 이는 브라우저 렌더링·마우스 검증이 아닙니다. Unity 실제 Refresh와 로드 도메인에서 Documentation 한 메뉴만 등록된 것을 확인했습니다. 원문27개 가이드 파일을 보존했습니다.

포커스를 바꾸지 않는 브라우저 도구로 file URL을 열었으나 허용 프로토콜이 HTTP/HTTPS뿐이라는 보안 정책 거부를 받았습니다. 우회·다른 브라우저·서버 변환을 시도하지 않았습니다. 새 탭은 생성되지 않았고 실제 전후 화면을 확보하지 못했습니다. 화면 비교 및 가이드 스크린샷을 완료로 기록하지 않습니다. 기존 사용자 창은 보존했습니다.

프로젝트 문서에 단일 진입·내부 카테고리 생성 경로를 갱신했습니다. 전역은 기존 문서 접근·실제 검증 원칙으로 포괄돼 변경 없음.

남은 사항

브라우저 실제 렌더링과 마우스·키보드 이동, 작은 화면·언어별 배치 및 실제 문서 화면 캡처가 남아 있습니다. 기존 모듈 안내 내용의 오래된 캡처·모든 링크까지 이번 통합에서 재검증한 것은 아닙니다.
