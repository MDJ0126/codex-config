Pixora 초록색 강조색을 블랙으로 변경

검증 대기

기본 제목줄·선택·버튼·선택기 팝업 강조색을 중성 블랙#181818로 바꿨습니다. 라이트/다크 모드 선택은 유지합니다.

2026년 10월 30일 오후 10:11 KSTv1.0.0수정사항

작업 결과

Pixora 기본 강조색과 팝업 공급자 변경 및 무창 컴파일/값 검사 통과. aa6af968 푸시.

변경 내용

적용 내용

PixoraToolWindow.Accent에서 기본 RGB24/24/24를 제공하고 제품 창과 선택기 팝업이 같은 공급자를 사용합니다. 공통 템플릿에 명시적으로 지정한 사용자 강조색은 계속 반영합니다. DataTable의 기본 색상 경로·테마 모드 설정·로봇 그림 팔레트는 변경하지 않았습니다.

사용자의 블랙 요청은 테마 모드가 아닌 초록색 UI 강조색에 대한 정정으로 반영했습니다. 이 선호를 프로젝트 AGENTS에 기록했습니다. 전역은 기존 사용자 요구/증거 우선 규칙과 중복되므로 변경 없음입니다. 색상 상수와 공급자 연결 변경이며 신규 아트워크 작업은 없습니다.

검증

Unity6000.0.83f1 batchmode/nographics에서 컴파일 및 기본 무채색 RGB24/24/24, 명시적 공통 사용자 지정 반영을 확인했습니다. 최초 치환에서 EnableInClassList 인수 오류가 발생한 기록은 보존하고 해당 호출을 복구한 뒤 재검증했습니다.

화면 제어 중단 지시를 유지했습니다. 최종 블랙 UI 화면은 캡처하지 않았고 기존 초록색 화면을 검증 이미지로 제시하지 않았습니다. ScreenshotManifest에 재확인 대기를 추가했습니다.

남은 사항

실제 제목줄·선택 상태·팝업의 라이트/다크 화면 확인은 사용자 제어 보류로 남아 있습니다. 설치용 패키지 갱신과 별도 검사 결과는 저장소 Artifacts/BlackAccent에 기록합니다.

작업 시간

  • 제안 시간: 2~5분; 코드/값 검사 후 패키지·보고 배포 추가 약2분 안내
  • 실제로 완료된 시간: 7.1분 · 코드/무창 값 검사 완료 2026-10-30 22:11:46 KST. 최종 화면 확인은 사용자 제어 보류로 미완료.
  • XERJ: 사용 — XERJ LightTheme 검색 후 정정된 강조색 공급 경로를 현재 소스로 대조.
