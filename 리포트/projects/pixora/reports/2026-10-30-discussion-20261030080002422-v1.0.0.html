Pixora 외부 모델·렌더 파이프라인 검증 표본을 정할까요?

논의 중

자체 모델과 Built-in 기준 QA를 외부 모델·URP/HDRP까지 확대할 때 필요한 최소 표본과 지원 표시 범위를 논의합니다.

2026년 10월 30일 오후 5:00 KSTv1.0.0QA 토론

토론 내용

현재 보고서의 자체 예제 통과를 임의의 사용자 모델 호환으로 확대할 근거는 없습니다. 외부 모델의 리그·재질·통합 메시에 따라 어떤 결과를 지원하고 어떤 제한을 안내할지 정하는 QA 논의입니다. 공통 제목줄과 예제 UI에서 후속 확인된 수정 사항은 다시 결함으로 올리지 않습니다.

QA 근거와 맥락

최신 후속 기록: Pixora 실제 예제 씬 10개와 단계별 재생

다른 OS·렌더 파이프라인과 독립 플레이어 빌드는 검증하지 않았습니다.

검토 방식: 보존된 글의 본문·제한·후속 기록을 대조했습니다. 제품 실행·재현·수정 검증을 새로 수행한 것이 아닙니다.

Pixora 사용 예제 10개 구성과 실제 Unity 전체 QA

모든 외부 모델·셰이더 호환은 미확인입니다.

Pixora Unity 시제품 — 스프라이트·애니메이션·자동 격자

하나의 SkinnedMeshRenderer 안에 합쳐진 몸체·장비를 자동으로 나누지 않습니다.

제안 및 대안

  1. 정적 메시·분리된 Renderer·단일 SkinnedMeshRenderer·Humanoid를 구분한 표본을 고릅니다.
  2. Built-in과 URP/HDRP의 재질·투명도·장비 가림·방향별 출력 차이를 별도로 기록합니다.
  3. 자동 부위 분리와 의미 기반 배경 제거는 기존 지원과 혼동하지 않게 기능 제안으로 별도 판단합니다.

결정과 후속 작업

아직 결정되지 않았습니다.

어떤 파이프라인과 모델 유형을 우선 지원할지, 품질 비교에 사용할 동일 원본과 합격 기준을 정해야 합니다. 새 모델 변환·재생 검증은 이번에 하지 않았습니다.

작업 시간

  • 제안 시간: 전체 기존 글 검토·필요 논의 등록 20~35분의 공통 작업입니다.
  • 실제로 완료된 시간: 논의 글 작성 2026-10-30 17:00:02 KST. 개별 제품 구현·QA 완료 시각이 아니며 전체 검토 시간은 별도 결과 보고서에 기록합니다.
