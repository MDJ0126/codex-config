TurnRoom 공통 창과 Pixora 다중 작업 창

검증 대기

새 창·복제·저장 작업 복원과 창별 변환 상태 분리를 구현하고 통합 프로젝트로 이전했습니다.

2026년 10월 29일 오후 11:56 KSTv1.0.0수정사항

작업 결과

Pixora는 DataTable 제품을 직접 참조하지 않고 TurnRoom.Editor 공통 기반을 사용합니다. 함께 설치하면 DataTable의 기존 창 목록과 네이티브 최소화 엔진에 연결됩니다. 단독 설치에서는 공통 프레임과 Window/TurnRoom/Windows 목록을 사용합니다.

변경 내용

적용 내용

Assets/TurnRoom/Pixora로 이전했습니다. 입력·3D 캡처·톤·팔레트·배치·격자·출력 폴더·줌을 창별로 저장하고 복제 시 변경 가능한 값은 깊은 복사합니다. 서로 다른 스프라이트 시트 창도 각각 엽니다. 기존 Pixora 저장소는 원본으로 보존했습니다. 기본 UI 색상과 프레임을 DataTable 톤에 맞췄으며 기존 로봇 로고를 유지했습니다.

검증

별도 Unity 작업본에서 세션 독립성 18개, 기본 변환 88개, 프레임·톤·줌 403개 검증이 통과했습니다. 9개 언어 가이드의 54개 장·54개 코드 예제 구조 검증과 10개 프로젝트 문서의 5개 이미지 링크 검증이 통과했습니다. 기존 설치의 GUID 935개를 보존하며 자동 이동 후 단독 실행을 확인했습니다.

남은 사항

새 UI의 실제 화면 조작·라이트/다크 시각 비교·최소화 애니메이션은 사용자 요청으로 보류했습니다. Node VM 문서 검증을 브라우저 시각 검증으로 보고하지 않습니다. DataTable이 열려 있어 실제 통합 프로젝트의 추가 배치 실행은 중복 프로젝트 열기 오류로 거부됐습니다. 별도 작업본과 설치 테스트의 결과입니다.

작업 시간

  • 제안 시간: 60–100분. 공통 창 분리, Pixora 이전, 개별·동시 설치 및 필수 검증 기준.
  • 실제로 완료된 시간: 공통 작업: 2026-10-29T22:36:55+09:00 → 2026-10-30T00:00:26.005+09:00, 83분 30초. 구현·비GUI 검증·통합 브랜치 푸시·최종 문서 점검 기준 종료 시각입니다. UI 검증은 사용자 요청으로 보류했습니다. 중앙 보고서 생성·검사·공개 배포 확인은 별도로 진행합니다.
  • XERJ: 사용 — 기존 DataTable 최소화 목록을 XERJ로 검색하고 현재 소스와 대조했습니다. 광범위 색인의 frozen-mapping 오류 후 공통 7개·DataTable 234개·Pixora 34개 에디터 C# 소스를 독립 색인해 ToolWindow 통합 검색을 실행했습니다. 런타임·스타일·문서는 rg로 확인했으며 자동 watcher는 시작하지 않았습니다.
