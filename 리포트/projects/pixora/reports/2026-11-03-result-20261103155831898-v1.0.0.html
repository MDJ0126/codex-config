턴룸 › Pixora수정사항

Pixora Studio 실제 폴더 통합과 경로 이전

검증 대기

Pixora를 PixoraStudio로 변경하고 Camera·Foliage·Suite를 하위로 옮겼습니다. 파일·GUID 보존과 정적 컴파일·패키지 대조를 통과했습니다.

2026년 11월 4일 오전 12:58 KSTv1.0.0수정사항

작업 결과

실제 Assets 폴더 통합을 완료했습니다. 기존 Pixora는 PixoraStudio가 되었고 PixelCamera·PixelFoliage·기존 PixelTooler 진입창은 그 안으로 이동했습니다. 모듈별 창은 유지합니다.

변경 내용

적용 내용

  • 구조: Assets/TurnRoom/PixoraStudio/{Editor, Samples, Documentation, PixelCamera, PixelFoliage, Suite}. Suite는 이전 PixelTooler 진입창입니다.
  • Templete는 다른 제품도 사용하는 공유 기반이므로 기존 위치를 유지합니다.
  • 현재 소스·UXML·설정·개발 도구·문서의 고정 경로, 제품 발견 경로와 패키지 레시피를 갱신했습니다. 클래스·assembly·preference 식별자는 유지했습니다.
  • 기존 .meta를 그대로 이동했습니다. 폴더 GUID도 모든 모듈 패키지에서 공유합니다.
  • 교훈 검토: 전역 변경 없음. 제품명 통합과 실제 폴더 통합은 서로 다른 완료 기준임을 프로젝트에 기록했습니다.

검증

  • 이동 대조: 7278개 파일 존재, .meta 3746개 SHA256/바이트 보존.
  • 식생·진입창6개 및 공유·기존 모듈9개 정적 컴파일 통과. 에셋·언어12검사 통과.
  • 활성 코드·설정에서 이전 루트 경로 잔류 검색 결과 없음. 과거 캡처 manifest와 QA 이력은 과거 근거로 보존했습니다.
  • 최종 통합 검토 패키지 2644개 에셋의 archive·현재 source/meta SHA256 대조 통과.
  • 사용자 화면 조작 금지를 유지하여 실제 Unity Project 창 캡처, 새 설치·Play 검증은 미실행입니다. 스크린샷을 만들어 대체하지 않았습니다.
  • 직접 덮어쓰기 UNKNOWN 오류는 기록하고 임시 파일 교체 방식으로 복구했습니다. 기존 다른 작업의 변경은 덮어쓰지 않았습니다.

남은 사항

실제 Unity import·씬·문서 재열기·공식 Validator 검증은 보류입니다. 이동 전 기존 미구현 기능과 UI/GIF QA를 완료로 바꾸지 않았습니다. 과거 설치본을 새 경로 패키지로 업그레이드하는 별도 마이그레이션은 미검증이며, 현재 개발 프로젝트의 폴더 이동 결과입니다.

작업 시간

  • 제안 시간: 폴더 통합·경로 수정·컴파일·패키지 대조 10~20분
  • 실제로 완료된 시간: 폴더 통합·필수 정적 검증·패키지 대조: 2026-11-04 00:39:16~00:53:20 KST, 14분4초. 공개 보고와 추가 셀러 작업은 별도 후속.
  • XERJ: 사용 — XERJ 상태·기존 Pixora 경로 검색 실행 후 현재 소스로 대조. 고정 경로 전체 대조는 rg 사용. 이동된 Editor 검색 루트도 수정했으나 새 인덱스 재생성은 미실행.
