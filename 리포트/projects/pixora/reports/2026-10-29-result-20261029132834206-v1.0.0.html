Pixora검토

DataTable과 공유할 창 기반 및 Pixora 다중 창 구조 검토

완료

두 제품의 독립 판매를 유지하면서 창 프레임과 최소화 목록을 공통화하는 구조를 제안했습니다. 코드는 통합하지 않았습니다.

2026년 10월 29일 오후 10:28 KSTv1.0.0검토

작업 결과

소스를 대조한 구조 검토를 완료했습니다. 개발·통합 테스트 환경은 함께 두고, 배포는 공통 창 기반·DataTable·Pixora로 나누는 방향을 권합니다. 이번 작업은 검토이며 실제 패키지 분리·다중 창 구현은 수행하지 않았습니다.

공통 기반은 같은 이름의 패키지 한 벌로 관리하고 버전을 맞춰 테스트합니다. 각 판매물에 서로 다른 공통 코드를 복사해 넣는 방식은 피하는 편이 좋습니다. 두 제품은 서로를 필수 의존성으로 두지 않습니다. Unity 패키지 매니페스트는 고유 이름·버전·의존성을 표현하므로 이 분리에 적합합니다. 실제 배포 경로와 설치 방식은 판매 채널에 맞춰 별도 검증해야 합니다. Unity 6000.0 공식 문서

Pixora 다중 창

새 창·현재 작업 복제·열린 창 목록을 제공합니다. 새 창은 초기 상태, 복제는 입력 에셋 참조를 유지하되 변환 설정은 독립 복사합니다. 창마다 고유 ID, 입력·프로필·배치 목록·카메라·재생 위치·줌·출력 위치·창 좌표를 보관합니다. 출력 경로 충돌도 구분해야 합니다. 공통 테마·표시 언어는 전역으로 공유할 수 있지만 예제 주석 언어처럼 제품별 의미가 있는 설정은 제품 소유로 둡니다.

공통 최소화 목록은 같은 Unity 에디터 프로젝트에서 두 제품의 창을 함께 표시하고 제품 필터·썸네일·복원·닫기를 제공합니다. 최소화는 창을 파괴하지 않아 입력과 Undo 상태를 유지하는 방향입니다. 사용자가 앞서 요청한 본창 최소화 버튼 제외 정책은 유지할 수 있습니다. 목록 등록과 제목줄 최소화 버튼 표시는 별도 옵션으로 두면 됩니다.

적용 순서

  1. 공통 스타일·제목줄·창 등록 계약부터 분리합니다.
  2. DataTable 목록을 제품 독립적인 창 등록 구조로 바꾸되 기존 동작을 유지합니다.
  3. Pixora를 창 ID별 상태 저장으로 변경하고 새 창·복제를 추가합니다.
  4. 한 제품만 설치한 환경 두 종류와 동시 설치 환경을 각각 검사합니다.
  5. 마지막으로 두 제품 사이 데이터 연동을 추가합니다.

검증

현재 소스를 읽어 다음 사실을 확인했습니다. 실행·통합 테스트는 수행하지 않았습니다.

  • PixoraWindow.Open은 기존 standalone 창 하나를 찾아 복원하는 방식입니다.
  • PixoraWindowChrome.Open도 같은 타입의 기존 창을 먼저 재사용합니다.
  • StoreStudioSession은 studioSettings·studioCapture·studioSource 등 단일 세션 값에 저장합니다. 다중 창에서는 창별 저장으로 바꿔야 합니다.
  • PixoraWindowFrame.FindWindow는 현재 프로세스와 제목이 일치하는 Windows 창이 정확히 하나일 때만 선택합니다. 같은 제목의 다중 창에는 별도 식별이 필요합니다.
  • WorkbookMinimizedShelf.Entry.window와 activeWindow는 WorkbookViewer 타입입니다. 공통 목록으로 재사용하려면 제품 전용 의존성을 분리해야 합니다.
  • 관련 원본: PixoraWindow.cs, PixoraWindow.Ribbon.cs, PixoraWindowChrome.cs, PixoraWindowFrame.cs, DataTable의 WorkbookMinimizedShelf.cs와 WorkbookNativeWindow.cs.

남은 사항

실제 공통 패키지 추출, Pixora 다중 창 구현, 버전 호환·독립 설치·동시 설치·도메인 리로드·에디터 재시작·닫기·복원 검증은 후속 작업입니다. 서로 다른 Unity 프로젝트/프로세스 사이의 통합 목록은 별도 IPC가 필요한 범위이며 이번 권장안은 같은 Unity 프로젝트 안의 동시 설치를 기준으로 합니다. Unity 내부 창 API·Windows 전용 처리의 타 버전/OS 호환성은 미확인입니다.
