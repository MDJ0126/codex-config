## 작업 결과

주시점을 중심으로 방향을 바꿀 수 있고 하늘정원 시장은 지정된 오브젝트 픽셀 렌더링을 다시 사용합니다.

## 변경 내용

### 적용 내용

- 추적 대상이 없는 경우 카메라를 옮긴 만큼 주시점을 이동합니다. 방향과 오프셋은 주시점을 지나는 월드 Y축을 기준으로 동작합니다.
- 카메라의 Pixel Camera와 시장 루트의 Pixel Camera Object를 기존 프리셋에 연결했습니다. 예제의 픽셀 및 윤곽선 토글과 9개 언어 안내를 갱신했습니다.
- 대화 (발언 시각 미기록): 사용자는 “추적 대상이 없으면 카메라 위치도 옮길 수 있게” 요청하고, 이어 “픽셀도 다시 붙여줘”라고 요청했습니다. AI는 시점과 픽셀 처리를 구분한 예제 구성을 적용했습니다.

## 검증

예제 씬에서 프리팹으로 연결되는 GUID, 두 픽셀 컴포넌트의 소유 오브젝트, 9개 언어 안내 생성 결과를 정적으로 확인했습니다.

## 남은 사항

Unity에서 이동·회전 조작과 픽셀 효과의 실제 표시 및 전후 스크린샷은 미확인입니다. 전역 지침에 추가할 검증된 공통 교훈은 없었습니다.
