## 작업 결과

인스펙터와 메뉴의 표시 이름을 Isometric View로 바꾸고 고정 방향과 자유 회전을 분리했습니다.

## 변경 내용

### 적용 내용

- 활성화 시 Transform의 Inspector 잠금을 적용하고 비활성화 시 이 컴포넌트가 추가한 잠금만 해제합니다. Unity의 Transform 단위 잠금은 Scale도 포함합니다.
- 자유 시점의 회전 값만 편집할 수 있습니다. 기존 회전 오프셋이 저장된 경우 자유 시점의 월드 Y축 각도로 변환합니다.
- 대화 (발언 시각 미기록): 사용자는 이름 변경과 Transform 이동·회전 잠금을 요청했습니다. 이어 “자유시점이 아니면 수정 못 하게 디세이블”하라고 지정했습니다. AI는 아이소매트릭 시점 이름과 조건부 입력을 적용했습니다.

## 검증

기존 이동 흡수 경로 제거, 잠금 설정 및 해제 코드, 자유 시점 조건, 9개 언어 UI 항목 및 가이드 예제를 정적으로 확인했습니다.

## 남은 사항

Unity Inspector에서 실제 잠금, 방향 선택과 입력 비활성화, 비활성화 후 잠금 해제 및 화면 캡처는 미확인입니다. 전역 지침에 추가할 검증된 공통 교훈은 없었습니다.
