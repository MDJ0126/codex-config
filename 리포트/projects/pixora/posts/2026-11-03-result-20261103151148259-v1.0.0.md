- 기존 메뉴·클래스·assembly·폴더·GUID·설정 키를 유지했습니다.
- primary SKU를 PixoraStudio로 설정하고 기존 review 출력 폴더를 재사용했습니다. 기존 Unity exporter에도 통합 출력을 추가했습니다.
- 모듈별 창과 테마, 공유 언어 설정을 유지하고 overview 문구를9언어로 갱신했습니다.
- 개발 코드·작업 데이터·exports 제외 정책을 review 패키지에도 반영했습니다.
- 교훈 검토: 전역 지침 변경 없음. 기존 구조 재사용 원칙과 같은 내용이며, 독립 창 유지라는 제품별 확정은 PixoraStudio.md에 기록했습니다.
