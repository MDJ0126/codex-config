AI 동료 제거에 함께 누락된 기존 몬스터 행동 코드 복원

부분 완료

기존 MonsterAI와 MonsterBehaviorAction을 원본 GUID로 복원했습니다. AI 동료·대화·연결 기능은 복원하지 않았습니다.

2026년 11월 11일 오후 10:46 KSTv1.0.0수정사항

작업 결과

Pixora 통합 사본 컴파일에서 MonsterAI 누락을 발견해 앞선 제거 작업의 범위 오류를 확인했습니다. 기존 몬스터 순찰·감지·추격·공격 두 클래스를 백업 원본 그대로 복원했습니다.

변경 내용

적용 내용

앞선 보고서의 “기존 비-AI 작업은 보존” 주장은 이 두 클래스에는 맞지 않았습니다. 공용 AI 폴더를 통째로 제거한 범위 판단이 잘못됐습니다. MonsterAI.cs·MonsterBehaviorAction.cs와 원래 .meta GUID, 폴더 메타를 복원했습니다. 이들은 LLM 에이전트가 아닌 게임의 일반 적 행동 코드입니다.

복원 백업의 제거 경로 목록도 조정해 추후 AI 동료 복원 시 이 일반 몬스터 파일과 충돌하지 않도록 했습니다. 구현을 바꾼 코드가 아닌 원본 복원이므로 새 알고리즘 코드는 없습니다.

검증

원본·격리 사본 모두 백업의 4파일을 그대로 복원했습니다. Pixora 통합에서 Unity 컴파일과 몬스터 컴포넌트 타입 연결을 확인했습니다. AI 동료·대화·마이크·에이전트 서버는 복원하지 않았습니다. 복원 근거

AI는 사용자에게 “제가 범위를 넓게 잡아, 기존 몬스터의 순찰·공격 코드 2개까지 함께 제거”했다고 설명하고 복원했습니다(발언 시각 미기록). 화면 없는 소스 복원이므로 별도 가짜 전후 화면은 만들지 않았습니다. 게임 관련 대표 이미지로 실제 결과 화면을 사용합니다.

남은 사항

자연 순찰·전투 동작 재실행은 미확인입니다. 이번 픽셀 촬영에서는 위치를 고정하기 위해 행동을 일시 중지했습니다. 목록 카드 썸네일은 아카이브 기능 제한으로 미확인입니다. 기존 변경 범위 확인 지침과 중복되므로 지침 변경 없음, 신규 공용 후보 없음입니다.
