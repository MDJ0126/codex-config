사용자 PC의 Codex·Claude·Cursor가 같은 게임 동료에 참여하는 MCP 연결

부분 완료

실제 Codex CLI가 게임의 질문을 받고 자기 모델로 답변한 뒤 Unity 행동 적용을 확인했습니다.

2026년 11월 11일 오후 8:07 KSTv1.0.0작업 결과

작업 결과

사용자 PC의 에이전트가 자기 모델·기존 계정으로 동료를 맡습니다. 실제 Codex CLI가 루나의 게임 메시지함을 읽고 방패 역할 선호 기억을 사용해 답했으며, 대기 명령의 실제 Unity receipt를 확인하고 제어권을 해제했습니다.

변경 내용

적용 내용

stdio MCP와 셸 CLI는 같은 로컬 서비스를 사용합니다. Codex 전역 MCP와 Claude Code .mcp.json·Cursor .cursor/mcp.json 설정기를 제공합니다. 호스트별 절대 경로와 개인 기억은 Git에서 제외합니다. 같은 동료는 5~120초 독점 제어권 하나만 허용하고 다른 동료는 별도 에이전트가 맡을 수 있습니다. 외부 제어 중 일반 게임 대화는 Qwen 대신 해당 PC 에이전트에게 전달됩니다.

flowchart TD
 A[PC 에이전트가 관측] --> B[동료 제어권 획득]
 B --> C[게임 메시지 대기]
 C --> D[자신의 모델로 답변]
 D --> E[확인한 메시지 ID까지 처리]
 E --> F[유효 행동 요청]
 F --> G[Unity가 세션과 약속 재검사]
 G --> H[실제 receipt 확인 후 해제 또는 갱신]

서버의 접수 검사에 더해 Unity 메인 스레드에서 실제 상태를 다시 확인합니다. 다음은 AIAgentController.Conversation.cs의 완전한 적용 메서드와 허용 검사입니다.

private bool ApplyExternalCommand(CompanionCommand command, string sessionId)
{
    long age = DateTimeOffset.UtcNow.ToUnixTimeMilliseconds() - command.issuedAt;
    if (!_externalActive || command.owner != _externalControllerName || !_monster.IsAlive || command.sessionId != sessionId || age < -1000 || age > 8000 ||
        !IsActionPermitted(command.action) || float.IsNaN(command.seconds) || float.IsInfinity(command.seconds) || command.seconds < 1f || command.seconds > 6f)
    {
        return false;
    }
    Monster target = null;
    if (command.action == "attack")
    {
        target = Monster.ActiveMonsters.FirstOrDefault(candidate => candidate.GetInstanceID() == command.targetId && IsAllowedEnemy(candidate));
        if (target == null)
        {
            return false;
        }
    }
    else if (command.targetId != 0 || (command.action == "follow" && (_leader == null || !_leader.IsAlive)))
    {
        return false;
    }
    _action = command.action;
    _target = target;
    _leaseEnds = Time.time + command.seconds;
    _actionReason = command.owner + ": " + command.reason;
    return true;
}

private bool IsActionPermitted(string action)
{
    bool known = IsPromiseMode(action) && action != "auto" || action == "attack";
    return known && (_promise.mode == "auto" || _promise.mode == action) && (action != "attack" || _promise.allowAttack);
}

검증

Codex CLI v0.167.0-alpha.3.2가 실제 fantasia stdio MCP에 연결했습니다. 플레이어 메시지 저장 2026-11-11T10:30:26.428Z → Codex 답변 저장 2026-11-11T10:30:32.911Z, 서비스 기준 약 6483ms였습니다. 모델 추론·호스트 도구 왕복이 포함되며 화면 표시까지의 지연 보장은 아닙니다.

응답: “저장된 기억에는 플레이어님께서 방패 역할을 좋아하시고, 이번 모험에서는 동료와 함께 움직이기를 원하신다고 되어 있어요. 현재 실제로 방패 역할을 맡고 계신지는 아직 확인하지 못했어요. 저는 신중하게 주변을 살피는 정찰 동료 루나이고, 지금은 게임 밖의 Codex CLI가 저를 직접 제어하며 답하고 있어요. 신호하실 때까지 기다리겠다는 약속도 확인했으니, 조용히 대기하겠습니다.”

실제 명령 ID 0de11f9a-bb85-46a7-9041-d1f10b9200a3을 Unity receipt에서 확인했습니다. 동료의 실제 기록

두 실제 MCP 프로세스의 공유 기억과 제어권 충돌 테스트, 외부 대화 확인 시 새 미확인 메시지가 남는 테스트, 약속 위반·오래된 관측·잘못된 대상 거부가 통과했습니다. Claude/Cursor 설정은 재실행해도 보존됐지만 앱이 설치되지 않아 실제 호스트 접속은 미확인입니다.

설정: node Tools/AgentBridge/configure.mjs codex 또는 claude 또는 cursor. 새 MCP 세션에서 PLAYER_AGENT.md를 읽고 observe → claim → wait → say_as → act → 실제 receipt → release 순으로 참여합니다. 현재 연결 소스

공식 근거: Codex MCP, Claude Code MCP, Cursor MCP.

남은 사항

물리 마이크 녹음·사용자 발화 정확도, Claude/Cursor 앱의 실제 접속, 최대 32명 부하·네트워크 코업·게임 빌드 배포는 미확인입니다. 아카이브의 목록 카드 썸네일은 현재 템플릿이 지원하지 않아 표시 검증을 완료하지 못했습니다. 대표 실제 화면을 각 본문에 등록했고 이 제한 때문에 게시물 상태를 부분 확인으로 기록합니다. 앱이나 대화가 종료되면 외부 에이전트가 자동으로 계속 플레이하지 않습니다. 이 Codex 대화는 CLI를 통해 동일한 서비스에 연결하며 전체 채팅 기억을 자동 동기화하지 않습니다.
