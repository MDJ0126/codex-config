## 권장 범위

- 제가 셸에서 호출하기 쉬운 JSON 입력·출력, 종료 코드, 시간 제한을 제공하는 CLI로 구성합니다.
- 연결·버전·지원 기능 진단, 공식 SDK 문서 확인, 스크립트 실행, 결과 렌더링 확인을 기본으로 둡니다.
- 문서 생성·열기·저장·내보내기, 텍스트·도형·이미지·레이어 조작은 실제 SDK 지원을 확인한 범위에서 명령으로 제공합니다.
- 품질 검증은 출력 해상도·크기 등 기계적 확인과 렌더링 이미지의 시각 검토를 함께 수행합니다.
- 다른 문서 오조작 방지, 덮어쓰기 제어, 오류 반환을 포함합니다.
- 전역 지침에는 검증된 설치 경로와 호출 예시, 디자인 작업 시 우선 사용 규칙, 실행 실패 시 복구·대체 절차를 기록합니다. 개발 완료 후 설치·실행 검증과 지침 커밋·푸시까지 포함하는 범위입니다.

## 예상 시간

- 연결 검증과 최소 실행판: 30~60분. Affinity MCP에 연결하고 SDK 조회·스크립트 실행·렌더링을 실제 확인하는 단계입니다.
- 일상 사용판: 누적 3~6시간. 자주 쓰는 명령, JSON 인터페이스, 오류·파일 보호, 대표 디자인 작업 검증, 설치 및 전역 지침 연동을 포함한 권장 범위입니다.
- 확장·안정화: 누적 1~2일. 다양한 문서·기능, 재연결·실패 복구·일괄 처리와 추가 회귀 검증까지 넓히는 경우입니다.
- 위 수치는 작업 항목을 기준으로 한 조건부 개발 견적이며 실측 생산성이나 확정 마감이 아닙니다. 현재 설치 버전·MCP 연결·SDK 범위가 미확인이므로 첫 연결 검증 후 수정해야 합니다.

## 확인 결과와 미확인 사항

- 현재 프로세스 목록에서 이름에 Affinity·Designer·Publisher가 포함된 프로세스는 확인되지 않았습니다.
- 확인한 두 기본 설치 경로에서도 프로그램을 확인하지 못했습니다. 이 결과만으로 미설치라고 단정할 수 없습니다.
- 실행 중이지 않은 상태에서 MCP 연결 성공 여부를 검증하지 않았습니다. 프로그램을 실행하거나 화면을 전환하지 않았습니다.
- 공식 커넥터의 스크립트 실행·렌더링 도구는 이전 조사에서 확인했습니다. [공식 안내](https://claude.com/marketplace/connectors/affinity-106b90)
- CLI를 만들더라도 SDK가 노출하지 않는 기능이나 완전 헤드리스 실행까지 자동으로 확보되지는 않습니다. 포커스 비간섭과 구체적인 문서 조작 기능은 실제 테스트가 필요합니다.
- 사용자가 요청하신 이번 범위는 개발 시간 산정으로 해석했으며 개발·설치·전역 지침 변경은 아직 하지 않았습니다.
- 보고서는 로컬 생성이며 인터넷 배포하지 않았습니다.
