# 실제 Affinity 연결 복구

Affinity 서버가 초기화에 Unsupported protocol version을 반환한 것을 확인했습니다. 초기화 프로토콜을 2025-11-25로 바꾼 뒤 doctor·status에서 연결 성공과 Affinity 3.3.1.4940 Win32 버전을 확인했습니다. docs 명령도 동일 연결에서 preamble을 먼저 읽도록 수정해 문서 조회의 선행 조건 오류를 해결했습니다.

## 검증

- CLI 기존 회귀 테스트 22개 통과. 이는 CLI 검증이며 실제 디자인 품질 검증과 구분합니다.
- 실제 Affinity에서 Pixora 벡터 도형·문자 생성, 세션 ID 대상 채움·이동 수정, spread 렌더링 성공을 확인했습니다.
- 파일 저장·PNG 출력은 추가 SDK 파일 권한 없이 Affinity UI를 사용했습니다. SDK 파일 저장 기능이나 화면 포커스 비간섭까지 검증했다고 주장하지 않습니다.
- XERJ: 실패 — 연결 도구가 제공되지 않고 노드 중지 확인 후 rg로 CLI 소스를 확인했습니다.
