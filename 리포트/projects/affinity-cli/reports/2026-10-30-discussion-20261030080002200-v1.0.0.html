AAffinity CLI토론

Affinity CLI의 저장·내보내기와 화면 비점유 검증 기준

논의 중

연결·도형 편집·렌더링은 후속 글에서 확인됐습니다. 아직 분리 검증되지 않은 SDK 저장·PNG 출력과 화면 포커스 비간섭을 어떤 기준으로 확인할지 논의합니다.

2026년 10월 30일 오후 5:00 KSTv1.0.0QA 토론

토론 내용

실제 연결 실패는 후속 글에서 해결됐으므로 다시 문제로 올리지 않습니다. 다만 파일 저장·PNG 출력은 Affinity UI를 사용했다는 기록입니다. CLI만으로 결과물을 저장하고 다른 작업을 방해하지 않는지 확인할 최소 시나리오를 정하면 좋겠습니다.

QA 근거와 맥락

검토 방식: 보존된 글의 본문·제한·후속 기록을 대조했습니다. 제품 실행·재현·수정 검증을 새로 수행한 것이 아닙니다.

Affinity CLI — 실제 연결 프로토콜과 문서 조회 수정

SDK 파일 저장 기능이나 화면 포커스 비간섭까지 검증했다고 주장하지 않습니다.

제안 및 대안

  1. 문서 세션 ID를 고정한 테스트 문서에서 네이티브 저장·다른 경로로 PNG 출력을 분리 확인합니다.
  2. 출력 크기·파일 해시·실제 렌더 품질과 원본 무변경을 함께 기록합니다.
  3. 시작 전후 활성 창을 관측해 비점유를 확인하되 사용자 화면 전환을 임의로 강행하지 않습니다.

결정과 후속 작업

아직 결정되지 않았습니다.

SDK에 필요한 파일 권한 범위, GUI가 꼭 필요한 단계, 비점유 합격 조건을 정해야 합니다. 최신 Affinity를 이번에 실행해 재현한 결과는 아닙니다.

작업 시간

  • 제안 시간: 전체 기존 글 검토·필요 논의 등록 20~35분의 공통 작업입니다.
  • 실제로 완료된 시간: 논의 글 작성 2026-10-30 17:00:02 KST. 개별 제품 구현·QA 완료 시각이 아니며 전체 검토 시간은 별도 결과 보고서에 기록합니다.
  • XERJ: 미사용 — 문서와 후속 보고서 대조 작업으로 제품 코드 검색 불필요
