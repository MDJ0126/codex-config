오오후의 틈수정사항

제공 Standing-Jump 원본 복원 — 화면 검증 보류

검증 대기

제공 점프를 합성 포즈로 교체한 변경을 바로잡았습니다. 파일 연결/컴파일 확인, 실제 Play·웹 미실행.

2026년 11월 4일 오후 7:47 KSTv1.0.0수정사항

작업 결과

에셋에 Standing-Jump와 Running-Jump가 있습니다. 지난 수정에서 제가 일반 Jump까지 합성 포즈로 바꾼 것이 잘못된 변경이었습니다. 기본 점프를 제공 Standing-Jump로 복원했습니다.

변경 내용

적용 내용

  • Visitor.controller의 Jump 모션을 제공 Standing_Jump.fbx의 GUID 9e6f2a6ec6dfb9743b48c89303657e9e로 복원했습니다. 프로젝트 합성 Jump.anim과 meta는 QA에 보관 후 Assets에서 제거했습니다.
  • 일반 점프는 하강 중에도 같은 원본 클립을 유지하여 중간에 합성 Fall로 전환하지 않습니다. 일반 추락·스카이다이빙·낙하산은 별도 상태입니다. 원격 점프에도 구별 플래그를 연결했습니다.
  • 원본 클립 길이와 설정된 물리 비행 시간으로 재생 속도를 계산하도록 연결했습니다. 실제 물리 접지와 시각 타이밍 검증은 아직 하지 않았습니다.

검증

화면 조작 없이 Runtime/RuntimeEditor/Editor 컴파일, 공중 상태13개, 정적 에셋 참조20개 검사 통과. 이 검사는 실제 원본 점프 재생·물리·시각 동작을 대신하지 않습니다. 사용자가 화면 중단을 요청했으므로 새 Play/웹 빌드·캡처는 실행하지 않았습니다. 현재 웹 서비스는 이전 검증 빌드이며 이번 소스 변경이 반영된 것으로 안내하지 않습니다.

교훈은 프로젝트 지침에 제공 이동/점프 클립 우선 사용과 합성 낙하 포즈 구분으로 통합합니다. 공통 검증 규칙과 중복되어 전역 지침은 변경하지 않습니다.

남은 사항

Unity에서 원본 점프 전체 동작과 물리 타이밍·착지·원격 점프를 확인하고 최신 웹에 적용해야 합니다. 이전 스카이다이빙/낙하산/인기도 여백의 실제 시각 검증도 보류 상태입니다.

작업 시간

  • 제안 시간: 연결 확인 약1분, 원본 복원·컴파일2~4분 예상.
  • 실제로 완료된 시간: 2026-11-04 19:44:01 KST 시작 → 파일 복원/부분검사 2026-11-04 19:47:19 KST. 전체 실행 검증 완료 시각은 보류.
  • XERJ: 미사용 — XERJ 미제공, rg·현재 Animator/에셋 GUID·실제 컴파일로 대조.
