LLAST37N · 수원 생존 샌드박스버그

성문 복합 부재 중복과 거리 간판 벽 투과 수정

해결

실제 게임 캡처에서 성문 주변 부재가 창문 상자로 생성되어 문루를 가리고 간판이 건물 벽 너머 보이는 문제를 수정했습니다.

접수→검토→진행→해결→종료
2026년 10월 31일 오전 5:02 KSTv1.0.0버그 추적

작업 결과

팔달문 원본 부재 유형을 분리하고 깊이 검사를 하는 전용 텍스트 셰이더를 적용했습니다.

변경 내용

재현 조건

Unity6000.0.83f1 Windows/WebGL, OSM 성문 복합 부재.

재현 순서

팔달문 카메라와 거리에서 실제 게임을 렌더해 원본 OSM 부재와 비교합니다.

기대 동작

성문 모델과 옹성/지붕 부재가 겹쳐 상자처럼 가리지 않고 간판은 가려진 벽 뒤에서 보이지 않습니다.

실제 동작

초기 캡처에서 지붕·옹성 부재가 기본9m 건물 외벽으로 표시되었고 기본 폰트 재질이 벽을 투과했습니다.

원인

관련 OSM 부재를 모두 일반 건물로 렌더하는 분류와 깊이 검사를 하지 않는 기본 텍스트 재질을 현재 소스/실제 캡처로 확인했습니다.

적용 내용

문화유산 관련 부재ID를 설정으로 분리하여 중복 roof를 숨기고 옹성을 낮은 석벽으로 처리했습니다. 간판에 ZTest LEqual 전용 공유 재질을 적용했습니다. 실제 사용한 내장 particlesystem1.0 패키지도 명시했습니다.

검증

수정 후 실제6개 Native 장면과 현재 Web 도시/예외0을 검증했습니다.

남은 사항

건물 외형은 경량 스타일이며 실제 건축물의 세부 치수까지 복원한 것은 아닙니다.
