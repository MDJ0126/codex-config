WebGL 월드 ID 입력이 단축키로 처리되는 문제 수정

해결

실제 브라우저에서 입력한 월드 대신 기본 suwon-2에 접속하고 배낭이 열린 현상을 확인했습니다.

접수→검토→진행→해결→종료
2026년 10월 31일 오전 5:02 KSTv1.0.0버그 추적

작업 결과

브라우저 HTML 입력으로 전환하고 실제 두 월드 왕복·도시 재생성을 검증했습니다.

변경 내용

재현 조건

Unity6000.0.83f1 WebGL, Windows/Edge 헤드리스.

재현 순서

F2→월드 ID IMGUI 필드에 city-other 입력→접속 버튼→서버 월드와 화면 확인.

기대 동작

입력한 월드로 접속하고 해당 월드의 도시 상태를 표시합니다.

실제 동작

기본 suwon-2가 유지되었고 입력 중 i가 배낭 단축키로 처리되었습니다. 실패 화면/QA는 docs/qa/city/browser/attempt-01에 보존했습니다.

원인

기존 월드 ID만 IMGUI TextField를 사용했고 이름·채팅에 쓰는 브라우저 입력/키보드 캡처 전환을 사용하지 않았습니다. 실제 실패 화면과 GameClient.WorldPanel 소스로 확인했습니다.

적용 내용

OnBrowserWorld와 WorldInputControl을 추가하여 DOM 입력·UTF-8 콜백·키보드 캡처 복원을 적용했습니다. QA 마우스 누름도 실제 렌더 프레임에 걸치도록 유지했습니다.

검증

현재 실제 Web에서 city-other 접속/도시 재생성과 city-peers 복귀/도시 재생성을 확인했습니다. 같은 검사에서 두 클라이언트 한글 채팅·점프/숙이기·재접속과 오류0을 확인했습니다.

남은 사항

모든 브라우저·입력 장치 조합을 검증한 것은 아닙니다.
