선택형 모델의 실측 품질·메모리·GGUF 호환성 기준

논의 중

모델 없는 첫 실행과 전송·체크섬 검증은 완료됐습니다. 추천 모델과 직접 지정 모델의 실제 업무 성공률·메모리·호환성을 어떤 기준으로 확인할지 논의합니다.

2026년 10월 30일 오후 5:00 KSTv1.0.0QA 토론

토론 내용

다운로드와 초기 UI의 통과를 추천 모델의 작업 품질 보장으로 확대하지 않아야 합니다. 모델 크기·호환 구조·실제 메모리와 사용자 업무 유형을 함께 기록하는 작은 인수 검증 묶음을 정하면 추천 근거를 보완할 수 있습니다.

QA 근거와 맥락

검토 방식: 보존된 글의 본문·제한·후속 기록을 대조했습니다. 제품 실행·재현·수정 검증을 새로 수행한 것이 아닙니다.

최초 모델 미포함 설치와 선택형 AI 모델 다운로드

추천 모델 전체를 새로 다운로드해 실제 추론 품질·업무 성공률을 비교하지는 않았습니다.

RAM 권장값은 추정값입니다.

제안 및 대안

  1. 동일한 짧은 코드·계획·검토 업무를 모델별로 비교할 고정 과제로 정합니다.
  2. 초기 로드·최대 메모리·응답 시간·성공 여부를 실행 환경과 함께 기록합니다.
  3. 직접 지정 GGUF는 지원 구조별 표본을 분리하고 분할 GGUF·인증 모델 지원은 별도 기능 제안으로 우선순위를 판단합니다.

결정과 후속 작업

아직 결정되지 않았습니다.

우선 비교할 모델·업무·하드웨어와 정확도 합격 기준을 정해야 합니다. 이번 작업에서 모델을 새로 다운로드하거나 추론·별도 Windows 계정 설치를 실행하지 않았습니다.
