실행

완료 기준
실제 현재 버전·환경과 과거 보고의 미검증 범위를 구분한 근거 확보
QA 절차
원본 보고서·현재 소스·설정 또는 실행 로그를 대조하고 재현 가능한 조건을 기록합니다.

T02선택형 모델의 실측 품질·메모리·GGUF 호환성 기준대기QA 미실행
실행
연결 토론의 대안과 질문을 검토하고 현재 프로젝트에서 재현합니다. 추천 모델 전체를 새로 다운로드해 실제 추론 품질·업무 성공률을 비교하지는 않았습니다. / RAM 권장값은 추정값입니다.
완료 기준
토론에서 확인이 필요한 범위의 실제 판정과 필요한 수정·선택 기록
QA 절차
토론의 기대 결과와 실제 결과를 비교합니다. 미지원 환경은 통과하지 않고 차단·미확인으로 남깁니다. 수정했다면 변경 전 재현과 변경 후 동일 절차를 비교합니다.
순서·수정
T01 · r1 · 이번 회차 대상
T03영향 범위 회귀 QA와 결과·논의 연결대기QA 미실행
실행
수정된 동작 및 기존 정상 경로를 재검증하고 실제 화면·로그를 결과 보고서에 첨부합니다. 결정이 필요한 질문은 기존 토론에 근거로 연결합니다.
완료 기준
작업별 QA와 전체 최종 QA를 수행하고 실제 완료·남은 항목을 구분한 보고 등록
QA 절차
현재 버전에서 전체 작업의 기대값을 다시 비교하고 실패·차단을 보존합니다. 전체 통과한 경우에만 메뉴얼을 완료로 갱신합니다.
