## 작업 결과

씬·프리팹 분석 버튼이 나란히 놓이도록 가로 방향을 명시했습니다. 목록은 54px에서 36px로 줄이고 이름·상태의 기준선과 상태 열 너비를 고정했습니다. 둘째 줄은 경로 또는 미지원 사유, 전체 내용은 툴팁으로 제공합니다.

## 변경 내용

### 적용 내용

더블클릭 제한을 제거하고 한 번 클릭하면 대상 선택·Ping·SceneView 프레이밍/포커스를 실행하도록 연결했습니다. 프리팹은 분석 시 자식 sibling index 경로를 보존하고 Prefab Stage를 열어 해당 자식을 선택합니다. 프리팹 단계 진입 때문에 분석 목록이 지워지지 않도록 씬 전환 처리를 구분했습니다.

UXML ProgressBar를 추가했습니다. 씬은 빌드와 같은 검사기를 증분 소비하고, 프리팹은 처리 파일 수/전체 수를 표시합니다. 완료 시 분석 버튼이 다시 활성화되며 탭 전환·창 종료 시 갱신 콜백을 해제합니다. 게이지는 분석 진행률이며 성능 개선율이 아닙니다. 기존 빌드 동기 분석은 같은 검사기를 끝까지 소비합니다. 9개 언어 문서 설명도 갱신했습니다.

## 검증

Unity 6000.0.83f1 설치본 참조로 7개 어셈블리 Roslyn 컴파일 통과, 컴파일 입력 해시와 마지막 소스 일치 확인. UXML/USS 가로 배치·행 높이·단일 클릭·프리팹 자식 경로·게이지 연결 소스 검사, 450개 UI 키×9언어 치환 인자 및 문서 9개/126개 링크 검사 통과. 388개 에셋 미리보기 패키지를 재생성하고 원본/메타 byte readback 통과. [검사 근거](../assets/2026-11-02-analysis-interaction/verification.json)

## 남은 사항

사용자 화면 포커스 금지 조건을 유지해 Unity/플레이어를 새로 실행하거나 조작하지 않았습니다. 실제 가로 배치·스크롤·클릭 포커스·프리팹 단계·진행 게이지 재도색과 라이트/다크 화면은 네이티브 실행 미검증입니다. 따라서 수정 후 실행 화면 및 같은 상태의 전후 캡처는 미확보이며, 화면 검증 통과로 보고하지 않습니다. 기존 문서 캡처 해시는 보존합니다. 교훈 검토: 기존 실제 화면 검증/포커스 보호 지침을 적용했으며 새로운 전역 규칙 추가 없음.
