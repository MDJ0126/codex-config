샘플 미리보기의 HUD 카메라 선택 오류 수정

검증 대기

렌더 대상이 없는 HUD 초기화 카메라를 제외했습니다. 화면 조작 없이 컴파일과 씬 설정 검사를 수행했습니다.

2026년 11월 2일 오후 11:26 KSTv1.0.0수정사항

작업 결과

미리보기 카메라 선택에서 비활성 카메라와 Culling Mask=0을 제외하고 MainCamera 및 깊이 순서로 실제 렌더 카메라를 우선합니다. 미리보기 영역이 줄어들지 않도록 최소 높이를 지정했습니다.

변경 내용

적용 내용

세 샘플의 SceneRoots 첫 항목 990001은 HUD clear camera이며 Culling Mask=0입니다. 이전 FirstOrDefault는 이 카메라를 선택했습니다. 수정 조건은 세 씬 모두 마스크 4294967295인 Camera를 선택합니다. 미리보기 설명/오류 4개 키를 9개 언어로 반영하고 패키지를 갱신했습니다.

검증

실제 씬 설정과 선택 조건 대조 근거. 7개 어셈블리 Roslyn 컴파일 통과. 패키지 400개 에셋 원본 바이트 대조 통과. SHA-256 0370387993e9a7e6dd71927cad75b52e918f8e8e9470c90acb00594e771f8d28. 이번 수정에서는 화면 조작, Unity 신규 실행, 에디터 명령 실행, 플레이어 빌드를 하지 않았습니다.

남은 사항

실제 Unity 렌더 결과와 표시 화면은 미확인입니다. 사용자 화면 조작 금지 지시에 따라 전후 화면 캡처를 하지 않았으며, 화면 검증 완료로 표시하지 않습니다. 앞서 변경한 맵/취소 커서의 실제 화면 검증도 남아 있습니다. 교훈 검토: 여러 카메라가 있는 씬은 루트 순서 대신 렌더 가능 여부로 미리보기 카메라를 선택합니다. 프로젝트 메뉴얼에 반영하며 기존 검증/승인 범위 지침과 중복되는 전역 규칙은 추가하지 않습니다.
