검증 대기

씬 안내를 현재 씬을 분석합니다로 바꾸고 버튼을 오른쪽 위로 이동했습니다. 인라인 게이지 대신 Unity 진행 다이얼로그를 쓰며 완료 후 설명과 진행 표시를 숨깁니다.

2026년 11월 2일 오후 7:46 KSTv1.0.0수정사항

작업 결과

씬 설명은 현재 씬을 분석합니다. 분석 버튼은 씬/프리팹 탭 줄 오른쪽 위에 있습니다. 분석이 끝나면 설명 영역과 로딩이 사라지고 결과 목록·다시 분석 버튼을 유지합니다.

변경 내용

적용 내용

사용자의 명시적 요청에 따라 인라인 ProgressBar를 제거하고 EditorUtility.DisplayProgressBar를 사용합니다. 완료·중단·오류·모드 변경·창 종료 시 이 분석이 띄운 다이얼로그만 ClearProgressBar로 정리하도록 연결했습니다. 완료된 씬·프리팹 설명 영역은 숨기며 실패한 분석은 초기 상태로 돌아갑니다. 번역과 9개 언어 설명을 갱신했습니다.

검증

7개 어셈블리 설치본 참조 컴파일과 마지막 소스 해시 대조 통과. 인라인 ProgressBar 제거·Unity 표시/정리 호출·완료 시 설명 숨김·버튼 배치의 소스 검사, UI 455키×9언어/치환 인자·문서 9개/126개 링크 검사 통과. 388개 에셋 패키지 원본/메타 byte readback 통과. 검사 JSON

남은 사항

화면 포커스 금지 조건으로 Unity를 조작하지 않았습니다. 실제 진행 다이얼로그의 표시·종료, 완료 전후 레이아웃과 클릭 동작은 네이티브 미검증입니다. 수정 후 실제 캡처는 미확보이며 기존 캡처 해시를 갱신하지 않았습니다. 사용자 요청에 따른 기본 Unity 진행 다이얼로그 예외는 이 분석 흐름에 한정합니다. 교훈 검토: 제품별 후속 메뉴얼에 기록했으며 전역 지침 추가 없음.
