변경 내용

적용 내용

DDT와 같은 CSS·Inter/Pretendard·표·목차·제품 헤더를 적용했습니다. EntityForgeLogo.png를 헤더·제품 탭·파비콘에 연결합니다. 개요와 빠른 시작을 앞에 두고 개요에 실제 Drone Hangar 예제1장을 넣었습니다. 기존 HTML 원문은 Documentation/Source에 보존하고 기존9언어 내용을 공통 렌더러로 생성합니다. 원래 문서 빌드의 마지막 단계에도 연결했습니다. 제품 Runtime/Editor 기능·메뉴는 이번 문서 작업에서 변경하지 않았습니다.

검증

Pixora Studio9개·Entity Forge9개·템플릿 예제9개, 총27개 HTML의 실제 생성 JS를 최소 DOM 어댑터에서 실행했습니다. 전체 장/제품 이동·활성 목차·언어 변경과 로고/파비콘/예제 이미지 경로를 검사했습니다. 각 패키지 guide.css는 DDT 원본과 바이트가 같고 Inter/Pretendard 글꼴·라이선스도 동일 해시입니다. 이는 브라우저 시각 검증이 아닙니다.

기존 Entity Forge 문서 검사도 통과했습니다. 그 검사의 verified-release-window는 과거 제품 창 캡처의 동결 근거이며 새 문서 디자인을 촬영했다는 의미가 아닙니다.

실제 브라우저 화면·작은 화면·마우스/키보드·탭 파비콘 표시와 후 캡처는 미실행입니다. 기존 화면 조작 중단 및 file URL 브라우저 보안 정책 거부를 유지했고 우회·다른 브라우저·서버 실행을 하지 않았습니다. 열린 문서의 실제 표시를 갱신했다고 보고하지 않습니다. 확인하려면 기존 문서 탭 새로고침이 필요합니다. ScreenshotManifest의 촬영 시각·소스 해시는 바꾸지 않았습니다.

남은 사항

새 문서 실제 화면·탭 아이콘 검증이 남습니다. 기존 캡처는 보존했습니다. 프로젝트 공통 문서 기준을 적용하며 전역 변경 없음.
