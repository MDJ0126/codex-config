Entity Forge 구현 범위와 후속 개발 목록

완료

자동 렌더링 최적화와 명시적 ECS 동작을 구분하고 최신 검증 공백과 후속 개발 순서를 정리했습니다.

2026년 11월 3일 오후 12:35 KSTv1.0.0검토

작업 결과

현재 버전은 0.2.0-preview입니다. 자동 탐지/빌드 연결/렌더링 프록시와 명시적 ECS 이동·회전·스폰·수명, 분석·프리팹 사본·로그·샘플 UI가 구현되어 있습니다. 컴포넌트 없는 일반 스크립트 로직의 ECS 자동 변환과 근거 없는 신규 프로젝트 성능 예측은 미구현입니다.

변경 내용

적용 내용

현재 구현

  • 일반 Unity 빌드 연결: 프로젝트 옵션 ON일 때 빌드 콜백으로 처리. 기본 OFF. 일반 Build/Build And Run에는 CleanBuildCache 옵션을 준비합니다. CI 직접 BuildPipeline 호출은 별도 옵션 연동을 확인해야 합니다.
  • 컴포넌트 없는 자동 탐지: 호환 MeshRenderer/MeshFilter의 렌더링을 엔티티 프록시와 인스턴싱으로 묶습니다. GameObject·사용자 스크립트·물리는 유지합니다.
  • 명시적 ECS 동작: ForgeObject/ForgeSpawner의 이동·회전·스폰·수명 데이터를 Burst ECS에서 처리합니다. 이 경로는 명시적 컴포넌트가 필요하고 임의 MonoBehaviour 자동 변환은 없습니다.
  • 씬·프리팹 분석: 현재 씬과 프로젝트 전체/폴더 지정 프리팹 분석, 지원 여부·제외 사유·대상 선택, 한 줄 목록과 필터 구현.
  • 프리팹 빌드 사본: 직렬화된 프리팹/ScriptableObject 참조를 빌드 사본으로 연결하고 생성 인스턴스의 렌더러를 공유 백엔드에 등록하는 경로 구현. Resources/Addressables/AssetBundle 로더 연동은 미구현.
  • 날짜별 빌드 기록: 씬/프리팹 처리 수·제외 사유·진행률·예측값을 JSON/log/progress로 저장. CI 로그 경로 환경변수와 기록 탭 구현. 실제 기록의 unknown 최종 상태도 있어 결과 판정 회귀가 필요합니다.
  • 개선율 근거 계산: 동일 기기·씬·버전·입력의 전후 플레이어 자료를 검증해 프레임 시간 감소율을 계산. 근거 없는 신규 프로젝트 예상치는 제공하지 않습니다. 측정/가져오기 코드가 남아 있으나 현재 창에서의 간편 연결은 정리 필요.
  • 샘플 테스트와 UI: 드론·차량·광석 3개, 생성/회수/이동·물리·+100 부하·일시정지/속도/재시작, 샘플 선택 PC 빌드·저장 위치·씬 미리보기 코드 구현. Android/iOS 테스트 버튼은 사용자 요청대로 비활성. 9개 언어와 템플릿 UI 구현. 최신 네이티브 UI 회귀는 미검증.

후속 개발 우선순위

  • P0 · 최신 기능의 실제 변환·설치 검증: 현재 패키지를 새 프로젝트에 설치하고 일반 빌드 ON/OFF, 프리팹 생성/제거·씬 이동·렌더러 변경 폴백과 원본 보존을 대조합니다. 샘플 제거/개발 폴더 제거 및 선택 의존성 설치 전후를 확인합니다.
  • P0 · 최신 자동 경로의 성능 이득 입증: 같은 부하에서 CPU/GPU 프레임 시간·메모리·렌더링·생성/제거 비용을 비교합니다. 단순 PC 빌드 성공이나 지원 대상 비율을 개선율로 사용하지 않습니다.
  • P0 · 최근 UI와 로그 회귀 마감: 행 높이·리사이즈·패널 높이·호버/포커스·미리보기·언어 전환을 실제 입력으로 확인합니다. 빌드 완료/실패/중단의 최종 로그 상태와 CI 직접 호출 옵션을 검증·보강합니다.
  • P1 · 컴포넌트 없는 동작 변환: 지원 이동·회전·스폰·수명을 기존 GameObject 작성 흐름에서 ECS로 연결하는 동작 분석/어댑터를 설계·개발합니다. 현재 자동 모드는 스크립트 Update 비용을 제거하지 않습니다.
  • P1 · 런타임 로딩 프리팹 통합: Resources·Addressables·AssetBundle 별도 어댑터와 로드/해제·중복 등록·풀링 회귀를 개발합니다.
  • P1 · 성능 개선율 사용자 흐름: 별도 측정 탭/자동 이중 빌드를 다시 강요하지 않고 측정 근거 가져오기·실행 기록·예측 근거/범위를 연결합니다. 측정 자료 없이 추정하는 모델은 별도 설계·검증이 필요합니다.
  • P1 · 백엔드·빌드 시간 최적화: 현재 매프레임 소스 Transform 동기화와 데이터 복사, 즉시 Job 완료, CPU 행렬 구성 비용을 측정·최적화합니다. 대량 생성/해제, 증분 캐시, 렌더링 컬링/LOD와 Entities Graphics 등 대안을 비교합니다.
  • P2 · 지원 범위 및 제품화: 멀티 머티리얼/서브메시·비균일 스케일·프로브/라이트맵·SkinnedMesh/Animator 등의 우선순위별 어댑터와 URP/HDRP/버전 검증을 진행합니다. 모바일은 별도 범위로 유지하며 필요한 경우만 기기 QA를 추가합니다. 최신 가이드 캡처·호환표·패키지 검증과 버전 메타데이터를 맞춥니다.

검증

소스 해시와 검토 근거. 실제 자동 탐지·DOTS 백엔드·프리팹 사본·측정 가져오기·빌드 설정/로그 소스를 대조했습니다.

과거 2026-11-01의 명시형 BenchmarkGrid는 10,000개·각600프레임 원시 데이터 재계산에서 8.7512115ms → 2.5571143ms, 프레임 시간 70.7799% 감소 기록을 확인했습니다. 이 값은 해당 구버전/기기/부하의 기록이며 최신 자동 모드나 현재 샘플의 개선율이 아닙니다. 과거 3개 샘플 Play 관찰 기록도 있으나 이후 맵/UI 변경까지 검증하지 않습니다.

확인한 최신 PC 빌드 JSON은 conversionEnabled=false, 씬1개이며 최종 status=unknown입니다. 별도 과거 성공 기록과 구분하고 최신 자동 변환 성공으로 계산하지 않았습니다. 현재 패키지 400개 원본과 기록된 파일 해시는 모두 일치했습니다. 새 컴파일·Unity 실행·화면 조작·빌드는 하지 않았습니다. 이 보고서의 complete는 범위 검토의 완료이며 제품 개발/네이티브 QA 완료를 뜻하지 않습니다.

남은 사항

제품 후속 개발과 실제 검증 항목은 위 우선순위 목록에 있습니다. 실제 화면을 변경하거나 실행한 작업이 없는 소스/기록 검토이므로 새 실행 화면은 캡처하지 않았습니다. 교훈 검토: 구버전 명시형 측정과 최신 자동/프리팹 경로를 구분해 근거를 적용합니다. 기존 검증 범위 명시 지침과 중복되므로 전역 변경 없음.
