Entity Forge 0.3.1 반복 렌더링 보강과 비모달 분석

검증 대기

정지한 반복 오브젝트의 행렬 재수집을 줄이고, 분석을 분할 처리하며 창 하단에서 진행률을 표시합니다. 네이티브 재측정은 대기 중입니다.

2026년 11월 3일 오후 3:18 KSTv1.0.0수정사항

작업 결과

파일 구현·비GUI 검증과 0.3.1-preview 패키지 생성이 끝났습니다. 최신 성능 개선율은 아직 측정하지 않았습니다. 화면 조작·Unity/플레이어 실행·빌드는 하지 않았습니다.

변경 내용

적용 내용

분석 UI: 로딩 다이얼로그를 제거하고 버튼에 분석 중 상태를 표시합니다. 창 맨 아래 고정 영역에 작업·에셋 경로·진행률을 표시하고, 탭을 바꿔도 계속 진행합니다. 중복 실행을 막고 데이터 변경/재생 진입 시 오래된 작업을 정리합니다. 에디터 update에서 씬 오브젝트·참조 속성·프리팹 렌더러를 나누어 처리합니다. 미리보기의 전체 프로젝트 지문 계산은 생략하며 빌드 지문은 유지합니다.

렌더링: 정지 프록시의 지속 행렬 페이지를 재사용하고 변경된 슬롯만 갱신합니다. 동작 엔티티만 gather하며 변경된 재질만 복사합니다. 원래 스크립트·물리·활성 소스 호환성 검사는 유지합니다. 포그라운드·실제 Unity 타이밍 조건·선택 CPU/GPU 프레임 타이밍과 백엔드 구간별 진단을 추가했습니다.

설명: 같은 메시와 재질을 많이 쓸 때의 조건부 이점을 9개 언어 제품 설명/가이드에 반영했습니다. 실제 판매 초안 4개 언어의 수정문은 준비했으나 포털 Save는 아직 하지 않았습니다. Submit은 하지 않습니다.

검증

검증 요약 · 현재 컴파일 소스 해시 · 실제 렌더 페이지 로직 검사 · 측정 조건 정책 검사.

7개 어셈블리/97개 현재 소스 컴파일, 514개 항목×9언어 인자 검사, 9개 가이드/126개 로컬 링크, 407개 패키지 원본/메타 읽기 대조 통과. 순수 저장소 테스트의 워밍업 후 10만 회 add/set/remove에서 관리 할당 0바이트이며 전체 Unity 무할당이나 속도 향상의 증거는 아닙니다. 이전 0.3.0 패키지 해시는 보존했습니다.

과거 0.3.0 동일 10,000개 비교는 OFF 16.7871ms / ON 17.0593ms로 1.62% 느렸습니다. 포커스·CPU/GPU 시간은 기록되지 않아 원인은 미확인입니다. 메시 2,348삼각형×10,000개는 23,480,000삼각형이며 배칭이 기하량을 줄이지 않습니다. 새 패치 성능값으로 과거 결과를 사용하지 않습니다.

Unity API 접근은 Unity 6000.0 공식 문서에 따라 메인 스레드에서 처리합니다. 4ms는 협력적 분할 예산이며 개별 에셋 검색/로드/열거 호출의 시간 상한을 보장하지 않습니다.

이번 변경의 실제 전후 화면은 사용자 화면 조작 금지로 미확보입니다. 기존 캡처의 소스 해시를 새 버전으로 바꾸거나 과거 화면을 이번 검증으로 표시하지 않았습니다.

남은 사항

T04: 최신 네이티브 런타임/분석 UI·실측·문서 캡처. T11: 실제 판매 초안 Save/readback. 사용자 컴퓨터 유즈 금지로 실행하지 않음. 과거 -1.62% 결과는 보존하며 최신 개선율로 사용하지 않음. 교훈 검토: 기존 전역 근거/포커스 규칙 적용, 전역 변경 없음. 네이티브 분석 응답성·버튼·탭·취소·밝은/어두운 테마, 런타임 동등성·재질 CRC·프레임 타이밍·새 패키지 설치·샘플 제거 회귀를 재허용 후 확인합니다. 설치만으로 성능 개선을 보장하지 않습니다.
