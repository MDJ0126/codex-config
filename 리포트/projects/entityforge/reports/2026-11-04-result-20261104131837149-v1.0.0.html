Measure Active Scene·Build Player 메뉴만 제거하고 제품 창 내부 기능은 유지했습니다. 새 Unity 도메인에서 제거를 확인했습니다.

작업 결과

요청한 두 상단 메뉴 제거와 실행 중 Unity 반영 확인을 완료했습니다.

변경 내용

적용 내용

ForgeBenchmarkRunner.Start와 ForgePlayerBuild.Build의 MenuItem 속성만 제거했습니다. 기능 본체와 ForgeWindowActions.Measure/Build 연결은 유지합니다. DDT·나머지 Entity Forge 메뉴는 수정하지 않았습니다.

검증

Unity 내부 Refresh 후 실제 로드된 새 도메인을 2026-11-04T13:18:04.2342871Z에 조회했습니다. Entity Forge Editor 모듈 ID0a9fa4ea-b94e-4fd1-b81a-79c06ced4d82에는 Open·Documentation만 등록되고 샘플3개는 별도 모듈에 유지됩니다. Measure Active Scene·Build Player 등록0개를 확인했습니다. 첫 조회는 이전 모듈이어서 통과 처리하지 않고 DLL 생성과 도메인 재로드 이후 재조회했습니다. 실제 측정·빌드는 실행하지 않았습니다. GUI 조작·재시작 없이 기존 호스트를 사용했습니다.

화면 촬영은 하지 않았으며 실제 도메인 메타데이터로 검증했습니다. 기존 전역 실제 로드 검증 원칙을 적용하여 지침 변경 없음.

남은 사항

해당 두 메뉴 제거의 미확인 항목은 없습니다. 제품 창 내부 측정·빌드 기능의 이번 재실행은 요청 범위에 포함하지 않았습니다.
