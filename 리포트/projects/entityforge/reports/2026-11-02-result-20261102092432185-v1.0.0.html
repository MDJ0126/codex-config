Entity Forge 기본 OFF와 프로젝트/폴더 프리팹 범위·분석 분리

검증 대기

자동 변환 기본 OFF, 하위 옵션 활성 조건, 씬/프리팹 독립 분석과 공유 프로젝트/폴더 범위, 설정 사이드바를 구현했습니다. 컴파일·소스 검사는 통과했고 네이티브 UI/빌드는 미검증입니다.

2026년 11월 2일 오후 6:24 KSTv1.0.0수정사항

작업 결과

새 설치의 자동 빌드 변환 기본값은 OFF입니다. 켰을 때만 자동 탐지·엄격 검사 하위 옵션이 활성화됩니다. 기존에 저장한 사용자 선택은 강제 초기화하지 않습니다. 프리팹은 기본적으로 Assets 전체를 대상으로 하며, 선택적으로 폴더 목록의 하위 경로를 처리합니다. 개별 프리팹 선택이 필요하지 않습니다.

변경 내용

적용 내용

씬 분석과 프리팹 분석을 독립 작업 모드로 분리했습니다. 프로젝트 전체/지정 폴더 설정은 분석과 빌드가 같은 ForgePrefabScope를 사용합니다. 빈 사용자 폴더 목록은 아무 프리팹도 처리하지 않으며 전체 프로젝트로 조용히 되돌리지 않습니다. 폴더 추가·선택·제거와 분석 진행 표시, 에디터 종료 시 분석 취소를 연결했습니다. Editor 전용 자산은 플레이어 변환 대상에서 유지 사유를 표시합니다.

Pixora의 설정 사이드바 구조와 공통 템플릿의 surface/border 값을 사용해 왼쪽 설정, 오른쪽 분석 작업 영역으로 구성했습니다. 설명은 일반 텍스트를 유지하고 정상 안내를 헬프박스로 감싸지 않습니다. 빌드 범위와 에디터 분석은 미리보기임을 9개 언어 가이드에 반영했습니다.

검증

공통 템플릿·Runtime·DOTS·Editor·샘플 Runtime·샘플 Editor·개발 Editor 7개 어셈블리 컴파일 통과. 자동 변환 false/전체 프리팹 true 초기값, 부모 토글의 초기 및 변경 시 SetEnabled 연결, 단일 프리팹 선택 제거, 분석과 빌드의 동일 범위 함수 호출을 검사했습니다. UI 문구 450개×9언어와 치환 인자, 문서 9개·126개 링크/파비콘 검사 통과. 최종 패키지 파일/메타 readback 통과. 검사 JSON

남은 사항

사용자의 화면 포커스 금지 조건으로 Unity/플레이어를 실행하지 않았습니다. 실제 토글 입력·폴더 선택·분석 진행/취소·재열기·라이트/다크/언어 레이아웃과 전체 프로젝트 프리팹 빌드 실행은 미검증입니다. 수정 후 실제 실행 화면과 전후 캡처도 미확보이므로 시각 검증 완료라고 보고하지 않습니다. 기존 캡처 해시는 보존했습니다. Resources/Addressables/AssetBundle 직접 경로 로딩의 별도 통합 필요 조건은 유지합니다. 교훈 검토: 기존 일반 텍스트/자동 활성화 금지/설정 보존 지침으로 적용 가능하여 이번 회차 전역 규칙 추가 없음.
